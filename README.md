# KejyarBot

ڕۆبۆتی فێرکاریی سەرەتایی زمانی کوردی.

## تایبەتمەندییەکان

- کۆرسی ١: ٢١ وانەی ڕێنووسی سەرەتاییی زمانی کوردی
- کۆرسی ٢: ٤٢ وانەی وتووێژی ڕۆژانە؛ لە کۆدی `main` چالاکە
- کۆرسی ٣: ٦٦ وانەی ڕێنووسی یەکگرتوو؛ لە runtimeی `main` چالاکە، بەڵام ناوەڕۆکەکان هێشتا پێداچوونەوەی مرۆیییان پێویستە
- کۆرسی لاتینی ١: ١٢ وانەی ئەلفبێ و ڕێنووسی لاتینی، بە پشتبەستن بە کتێبی دکتۆر ئێفراسیاب شیکۆفتە؛ سەرچاوەکەی لە کۆرسی لاتینی ٢ جیاوازە
- کۆرسی لاتینی ٢: ١٢ وانەی گرامەری کرمانجی، بە پشتبەستن بە بەشی دووەمی کتێبی Celadet Alî Bedir-Xan؛ سەرچاوە و ناوەڕۆکەکەی لە کۆرسی لاتینی ١ جیاوازە
- کۆرسی ٤: ٢٢ وانەی ڕێزمان؛ لە دۆخی `active_owner_review_beta`. ناوەڕۆکی وانە نێردراوەکان بە پشکنینی زانستیی ناوخۆیی ڕێکخراون و گومانە دیالێکتی/مۆرفۆلۆژییەکان لە خودی وانەکاندا مەرجدار کراون.
- دۆخی runtime بە تەنها بەڵگەی پەسەندکردنی زانستی نییە؛ وانەکانی کۆرسی ٣ و هەردوو کۆرسی لاتینی تا پێداچوونەوەی سەرچاوەیی و مرۆیی کۆتایی لە دۆخی پێداچوونەوەدا دەمێننەوە
- ڕێڕەوی وانەکان بە قفڵی پێشکەوتن و کویز بۆ هەر وانەیەک
- تاقیکردنەوە بە هەڵبژاردنی وەڵام
- XP، ئاست، Coin، سەنوق و نیشانە
- ڕاهێنانی گفتوگۆی ڕۆژانە بە کوردی
- هەموو وانە و ڕاهێنان و تاقیکارییەکان بە شێوەی نووسراو کار دەکەن؛ ڕۆبۆتەکە هیچ دەنگێک نانێرێت و هیچ خزمەتگوزاریی دەنگ بەکارناهێنێت
- پاراستنی خەڵاتی تاقیکردنەوە لە دووبارەوەرگرتن
- SQLite بۆ هەڵگرتنی پێشکەوتنی بەکارهێنەر

## دامەزراندن

1. Python 3.10 یان نوێتر دابمەزرێنە.
2. لە فۆڵدەری پڕۆژەکەدا جێبەجێ بکە:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. فایلێک بە ناوی `.env` لە ڕەگی پڕۆژە دروست بکە و تۆکنی بۆتی خۆت تێدا دابنێ:

   ```dotenv
   TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
   ```

   تۆکنی ڕاستەقینە مەخە ناو GitHub و لەگەڵ کەسێکدا هاوبەشی مەکە.

4. بۆتەکە بەکاربهێنە:

   ```bash
   python bot.py
   ```

پڕۆژەکە هەروەها `BOT_TOKEN` وەک ناوی کۆنی گۆڕاوی ژینگە قبوڵ دەکات. گۆڕاوەکانی ژینگەی میوانخانە/سێرڤەر پێش فایلەی `.env` پێشینەیان هەیە.

## تاقیکردنەوە

```bash
python -m compileall -q .
python -m unittest discover -s tests -v
```

- لە منووی بۆتەکە «💬 گفتوگۆی ڕۆژانە» هەڵبژێرە و بە کوردی بنووسە؛ گفتوگۆی سادە لە سڵاو، بازاڕ، خواردن و قوتابخانە پشتگیری دەکرێت.
- هەموو پەیوەندییەکانی دەنگ لە runtime لابراون؛ نە دەنگی تۆمارکراو، نە دەنگی دروستکراو، نە APIی دەنگ بەکاردێت.
