# KejyarBot

ڕۆبۆتی فێرکاریی سەرەتایی زمانی کوردی.

## کۆرسەکان لە برانچی تاقیکردنەوە

- **کۆرسی ١ — ڕێنووسی سەرەتایی:** ٢٢ وانە.
- **کۆرسی ٢ — وتووێژی ڕۆژانە:** ٤٨ وانە؛ پێش‌نوس و لە پێداچوونەوەدایە.
- **کۆرسی ٣ — ڕێنووسی یەکگرتوو:** ١٢ وانە؛ پێش‌نوس و لە پێداچوونەوەدایە.
- **کۆرسی ٤ — ڕێزمان:** لە پلانداناندا؛ وانەی چالاکی نییە.

ڕێکخستنی کۆرسەکان لە `courses.json` ـە. ناسنامەی وانەکانی کۆرسی یەکەم بۆ سازگاری لەگەڵ پێشکەوتنی پێشووی خوێندکاران پارێزراون؛ کۆرسەکانی دیکە ناسنامەی جیاوازیان بەکاردەهێنن.

**تێبینیی گرنگ:** چالاکبوونی تەکنیکی لە ژینگەی پشکنین بە مانای تەواوبوونی پێداچوونەوەی زمانی و ناوەڕۆک نییە. کۆرسی ٢ و ٣ بە بنەڕەت بۆ خوێندکاران داخراون؛ هەندێک کویزی کۆرسی ١یش تا پێداچوونەوەی پێویست بەردەست نین.

## تایبەتمەندییەکان

- ڕێڕەوی وانەکان و کردنەوەی وانەی دواتر دوای تەواوکردنی وانەی پێشوو.
- جیاکردنەوەی پێشکەوتنی کۆرسەکان.
- تاقیکردنەوەی هەڵبژاردنی وەڵام و پاراستنی خەڵات لە دووبارەوەرگرتن.
- XP، ئاست، Coin، سەنوق و نیشانە.
- ڕاهێنانی گفتوگۆی ڕۆژانە بە کوردی.
- دەنگی ئێستای کەژیار؛ دەنگی دینامیکی بە بنەڕەت ناچالاکە.
- SQLite بۆ هەڵگرتنی پێشکەوتنی بەکارهێنەر.

## دامەزراندن و تاقیکردنەوەی ناوخۆیی

1. Python 3.10 یان نوێتر دابمەزرێنە.
2. لە فۆڵدەری پڕۆژەکەدا جێبەجێ بکە:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. فایلێک بە ناوی `.env` لە ڕەگی پڕۆژە دروست بکە و تۆکنی بۆتی تاقیکردنەوە تێدا دابنێ:

   ```dotenv
   TELEGRAM_BOT_TOKEN=YOUR_TEST_BOT_TOKEN
   KEJYAR_ENABLE_DYNAMIC_SPEECH=false
   KEJYAR_ENABLE_DRAFT_COURSES_FOR_REVIEW=true
   ```

   `KEJYAR_ENABLE_DRAFT_COURSES_FOR_REVIEW=true` تەنها بۆ تاقیکردنەوەی ناوخۆیی و پشکنینی کۆرسە پێش‌نووسەکانە. ئەم ڕێکخستنە لە ژینگەی بەرهەمهێنان دابنە مەکە. بۆ چالاکی ئاسایی، ئەم گۆڕاوە دابنە مەکە یان بیخە `false`.

   تۆکنی ڕاستەقینە مەخە ناو GitHub. تۆکنی بۆتی بەرهەمهێنان لە ژینگەی تاقیکردنەوە بەکارمەهێنە. بۆتەکە هەروەها `BOT_TOKEN` وەک ناوی کۆنی گۆڕاوی ژینگە قبوڵ دەکات؛ گۆڕاوەکانی ژینگەی سیستەم پێش فایلەی `.env` پێشینەیان هەیە.

4. بۆتەکە لە هەمان فۆڵدەر و هەمان ژینگەوە دەست پێ بکە:

   ```bash
   python bot.py
   ```

   ئەگەر گۆڕاوەکان لە PowerShell دانراون، دەبێت لە هەمان session ـەوە `python bot.py` جێبەجێ بکرێت. ئەگەر تۆکنی تاقیکردنەوە نەبێت، بۆتەکە دەست پێ ناکات.

## بەردەوام چالاکبوون لە سێرڤەر

ڕێنمایی worker و restart خۆکار لە Railway: [`docs/ALWAYS_ON_RAILWAY.md`](docs/ALWAYS_ON_RAILWAY.md). ئەم ڕێنماییە خۆی deploy ناکات؛ ڕێکخستنی سرویس و volume و پشکنینی Telegram پێویستن.

## تاقیکردنەوە

```bash
python -m compileall -q .
python -m unittest discover -s tests -v
```

## گفتوگۆ و دەنگی کەژیار

- لە منووی بۆتەکە «💬 گفتوگۆی ڕۆژانە» هەڵبژێرە و بە کوردی بنووسە.
- دەنگی دینامیکی تا ڕێگەپێدانی ڕوون ناچالاک بمێنێتەوە. دەنگی ڕەسەنی کەژیار مەگۆڕە و دەنگی جێگرەوە بەکارمەهێنە.
- کلیلی API و تۆکنی ڕاستەقینە مەخە ناو GitHub؛ تەنها لە `.env`ی ناوخۆ یان secret ـی سێرڤەر بەکاری بهێنە.
