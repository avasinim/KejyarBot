# KejyarBot

ڕۆبۆتی فێرکاریی سەرەتایی زمانی کوردی.

## تایبەتمەندییەکان

- کۆرسی ١: ٢٢ وانەی ڕێنووسی سەرەتاییی زمانی کوردی
- کۆرسی ٢: ٤٨ وانەی وتووێژی ڕۆژانە؛ لە کۆدی `main` چالاکە
- کۆرسی ٣: ١٢ وانەی ڕێنووسی یەکگرتوو؛ لە کۆدی `main` چالاکە
- کۆرسی ٤: هێشتا لە پلانداناندایە
- نیشانەی پێداچوونەوەی editorial لە ناوەڕۆکی هەندێک وانەدا ماوەتەوە، بەڵام ئیتر کۆرسەکان لە ڕووی runtime ـەوە قفڵ نین
- ڕێڕەوی وانەکان بە قفڵی پێشکەوتن و کویز بۆ هەر وانەیەک
- تاقیکردنەوە بە هەڵبژاردنی وەڵام
- XP، ئاست، Coin، سەنوق و نیشانە
- دەنگی سڵاو و تەواوکردنی وانە
- ڕاهێنانی گفتوگۆی ڕۆژانە بە کوردی
- وەڵامی دەنگیی خۆکار تەنها ئەگەر بە ڕێکخستن چالاک بکرێت؛ لە بنەڕەتدا ناچالاکە
- پاراستنی خەڵاتی تاقیکردنەوە لە دووبارەوەرگرتن
- SQLite بۆ هەڵگرتنی پێشکەوتنی بەکارهێنەر

## دامەزراندن

1. Python 3.10 یان نوێتر دابمەزرێنە.
2. لە فۆڵدەری پڕۆژەکەدا جێبەجێ بکە:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. فایلێک بە ناوی `.env` لە ڕەگی پڕۆژە دروست بکە و تۆکنی بۆتی خۆت تێدا دابنێ:

   ```dotenv
   TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
   # Dynamic speech stays OFF until the original voice and Kurdish quality are verified
   KEJYAR_ENABLE_DYNAMIC_SPEECH=false
   ELEVENLABS_API_KEY=YOUR_ELEVENLABS_API_KEY
   KEJYAR_VOICE_ID=THE_EXISTING_KEJYAR_VOICE_ID
   KEJYAR_APPROVED_VOICE_ID=THE_SAME_EXISTING_KEJYAR_VOICE_ID
   ```

   تۆکنی ڕاستەقینە مەخە ناو GitHub و لەگەڵ کەسێکدا هاوبەشی مەکە.

4. بۆتەکە بەکاربهێنە:

   ```bash
   python bot.py
   ```

پڕۆژەکە هەروەها `BOT_TOKEN` وەک ناوی کۆنی گۆڕاوی ژینگە قبوڵ دەکات. گۆڕاوەکانی ژینگەی میوانخانە/سێرڤەر پێش فایلەی `.env` پێشینەیان هەیە.

## تاقیکردنەوە

```bash
python -m compileall -q .
python -m unittest discover -s tests -v
```

## دۆخی چاکسازی

چاکسازییەکانی سەرەتایی لە برانچی `fix/kejyarbot-stability-2026-10-25` کار لەسەر دەکرێن. هێشتا پێویستە تاقیکردنەوەی ڕاستەقینەی Telegram بە تۆکنی پارێزراو و لە ژینگەی جیاوازدا بکرێت؛ ئەم چاکسازییانە بە مانای بڵاوکردنەوەی خۆکارانە نیە.

## گفتوگۆ و دەنگی کەژیار

- لە منووی بۆتەکە «💬 گفتوگۆی ڕۆژانە» هەڵبژێرە و بە کوردی بنووسە؛ گفتوگۆی سادە لە سڵاو، بازاڕ، خواردن و قوتابخانە پشتگیری دەکرێت.
- **پاراستنی دەنگی کەژیار:** دەنگی دینامیکی بە بنەڕەت ناچالاکە. بۆ چالاککردنی دواتر، `KEJYAR_ENABLE_DYNAMIC_SPEECH=true` و هەرسێ گۆڕاوی `ELEVENLABS_API_KEY`، `KEJYAR_VOICE_ID` و `KEJYAR_APPROVED_VOICE_ID` پێویستن. دوو ناسنامەی دەنگ دەبێت بە تەواوی یەکسان بن.
- تەنها ناسنامەی دەنگی ڕەسەنی کەژیار کە پێشتر هەڵبژێردراوە دابنێ؛ ئەگەر ناسنامەکە بەردەست نییە، دەنگی جێگرەوە هەڵمەبژێرە. تا تاقیکردنەوەی ڕاستەقینەی خوێندنەوەی کوردی و پشتڕاستکردنەوەی دەنگ تەواو نەبێت، گۆڕاوی چالاککردن لەسەر `false` بهێڵەوە. گفتوگۆی نووسراو کار دەکات و فایلە دەنگە تۆمارکراوەکان ناگۆڕدرێن.

- **تێبینیی زمانی:** لیستی فەرمی زمانی مۆدێلی دەنگی هەڵبژێردراو دەبێت بپشکنرێت؛ کوردی لە لیستی هەموو مۆدێلەکاندا بە ڕوونی ناونەهاتووە. پێش چالاککردنی بۆتەکە، چەند نموونەی کوردی تاقی بکەرەوە و دڵنیابە لە خوێندنەوەی ڕاستی وشەکان. ئەگەر کوالێتی کوردی باش نەبوو، دەنگی تۆمارکراوی ڕاستەقینەی کەژیار بەکاربهێنە تا چارەسەری گونجاو بدۆزرێتەوە.
- کلیلی API مەخە ناو GitHub؛ تەنها لە `.env`ی ناوخۆ یان secret ـی سێرڤەر بەکاری بهێنە. تێچووی خزمەتگوزاریی دەنگ بە پێی پلانی هەژمارەکەت دەبێت.
