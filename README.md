# KejyarBot

ڕۆبۆتی فێرکاریی سەرەتایی زمانی کوردی.

## تایبەتمەندییەکان

- وانەکان و ڕێگای فێربوون
- تاقیکردنەوە بە هەڵبژاردنی وەڵام
- XP، ئاست، Coin، سەنوق و نیشانە
- دەنگی سڵاو و تەواوکردنی وانە
- ڕاهێنانی گفتوگۆی ڕۆژانە بە کوردی
- وەڵامی دەنگیی خۆکار بە دەنگی ڕێکخراوی کەژیار، ئەگەر خزمەتگوزاریی دەنگ چالاک بکرێت
- پاراستنی خەڵاتی تاقیکردنەوە لە دووبارەوەرگرتن
- SQLite بۆ هەڵگرتنی پێشکەوتنی بەکارهێنەر

## دامەزراندن

1. Python 3.10 یان نوێتر دابمەزرێنە.
2. لە فۆڵدەری پڕۆژەکەدا جێبەجێ بکە:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. فایلێک بە ناوی `.env` لە ڕەگی پڕۆژە دروست بکە و تۆکنی بۆتی خۆت تێدا دابنێ:

   ```dotenv
   TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
   # Optional: enable dynamic speech in a voice you are authorized to use
   ELEVENLABS_API_KEY=YOUR_ELEVENLABS_API_KEY
   KEJYAR_VOICE_ID=YOUR_AUTHORIZED_VOICE_ID
   ```

   تۆکنی ڕاستەقینە مەخە ناو GitHub و لەگەڵ کەسێکدا هاوبەشی مەکە.

4. بۆتەکە بەکاربهێنە:

   ```bash
   python bot.py
   ```

پڕۆژەکە هەروەها `BOT_TOKEN` وەک ناوی کۆنی گۆڕاوی ژینگە قبوڵ دەکات. گۆڕاوەکانی ژینگەی میوانخانە/سێرڤەر پێش فایلەی `.env` پێشینەیان هەیە.

## تاقیکردنەوە

```bash
python -m compileall -q .
python -m unittest discover -s tests -v
```

## دۆخی چاکسازی

چاکسازییەکانی سەرەتایی لە برانچی `fix/kejyarbot-stability-2026-10-25` کار لەسەر دەکرێن. هێشتا پێویستە تاقیکردنەوەی ڕاستەقینەی Telegram بە تۆکنی پارێزراو و لە ژینگەی جیاوازدا بکرێت؛ ئەم چاکسازییانە بە مانای بڵاوکردنەوەی خۆکارانە نیە.

## گفتوگۆ و دەنگی کەژیار

- لە منووی بۆتەکە «💬 گفتوگۆی ڕۆژانە» هەڵبژێرە و بە کوردی بنووسە؛ گفتوگۆی سادە لە سڵاو، بازاڕ، خواردن و قوتابخانە پشتگیری دەکرێت.
- بۆ ناردنی وەڵامی دەنگیی خۆکار، `ELEVENLABS_API_KEY` و `KEJYAR_VOICE_ID` لە ژینگەی سێرڤەر دابنێ. `KEJYAR_VOICE_ID` دەبێت ناسنامەی دەنگێک بێت کە بە ڕەزامەندیی خاوەن دەنگ ئامادە کراوە؛ نموونەی دەنگی تەنها بە خۆی ناسنامەی TTS دروست ناکات.
- ئەگەر ئەو دوو گۆڕاوە دانەنرابن، گفتوگۆی نووسراو کار دەکات و بۆتەکە دەنگی نوێ دروست ناکات. دەنگە تۆمارکراوە پێشووترەکان هەر وەک خۆیان دەمێننەوە.
- کلیلی API مەخە ناو GitHub؛ تەنها لە `.env`ی ناوخۆ یان secret ـی سێرڤەر بەکاری بهێنە. تێچووی خزمەتگوزاریی دەنگ بە پێی پلانی هەژمارەکەت دەبێت.
