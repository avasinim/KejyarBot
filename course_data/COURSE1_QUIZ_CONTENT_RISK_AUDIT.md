## بڕیاری کار
- لەم قۆناغەدا هیچ پرسیارێک بە بێ سەرچاوەی پشتڕاستکراو بە شێوەی خۆکار ناگۆڕدرێت؛ تەنها مەترسییەکان دیاری کراون.
- پێش چالاککردنی کویز، پرسیارەکانی پلەی «بەرز» دەبێت بگۆڕدرێن یان بە سەرچاوەی ڕاستەوخۆ پشتڕاست بکرێنەوە.
- کۆرسی ١ لە manifest ـدا هێشتا `active` ـە؛ ئەم تۆمارە هیچ دۆخێک ناگۆڕێت. ئەگەر ئەم کویزانە لە runtime ـدا بەکاردێن، پێویستە بە پشکنینی جیاواز دیاری بکرێت کام فایلە کویزی runtime ـە.
- کۆرسی ٢ و ٣ بە `draft_for_review` بمێننەوە، کۆرسی ٤ `planned` بمێنێتەوە.
- `main`، بۆتی زیندوو، توکنی بۆت، داتابەیس و دەنگی دینامیک دەستکاری نەکرێن؛ `KEJYAR_ENABLE_DYNAMIC_SPEECH=false` بمێنێتەوە.


## خاڵی گرنگی runtime (پشکنین دوای نووسینی تۆمار)
پشکنینی `bot.py` لە هەمان برانچدا پشتڕاستی کردەوە کە:
- `ORTHOGRAPHY_QUIZ_DRAFT` لە `course_data/orthography_foundations_quiz_draft.json` دەخوێنرێتەوە.
- پرسیارەکان بۆ `QUIZ_DATA` دەگوازرێنەوە، و دوگمەی تاقیکردنەوە لەسەر بنەمای `QUIZ_DATA.get(lesson)` پیشان دەدرێت.
- لەم کۆدەدا بۆ کویزی کۆرسی ١ هیچ گەیتێکی سەربەخۆی `draft/source-review` نابینرێت؛ بۆیە ئەو کویزەی بە ناوی draft هەڵگیراوە لە runtime ـی ئەم برانچەدا بەکاردێت.

ئەمە کێشەیەکی جیاوازە لە دروستیی JSON: پرسیارێک دەتوانێت لە ڕووی کۆد و index ـەوە دروست بێت، بەڵام هێشتا لە ڕووی سەرچاوە و پەروەردەییەوە پێویستی بە پشکنین هەبێت.

### پێشنیاری چارەسەر
پێش چالاککردنی ئەم کویزانە لە بۆتی زیندوو، یەکێک لەم ڕێگایانە بە هەڵبژاردنی ڕوون جێبەجێ بکرێت:
1. کویزەکان بە تەواوی لەگەڵ سەرچاوە و نموونەکان پشکنین بکرێن و پاشان بۆ runtime ئامادە بکرێن؛ یان
2. بۆ کویزی کۆرسی ١ status ـێکی editorial جیاواز و گەیتێکی runtime دروست بکرێت، بە شێوەیەک کە خوێندکار نە بتوانێت کویزی پێداچوونەوە-نەکراو وەک تاقیکردنەوەی کۆتایی بکات.

هیچ یەکێک لەم گۆڕانکارییانە لەم commit ـەدا جێبەجێ نەکراوە. گۆڕینی runtime دەبێت لە branch ـدا، بە تاقیکردنەوەی regression بۆ Course 1، و پێش هەر deployment ـێک بە ڕەزامەندیی بەکارهێنەر بکرێت. `main` و بۆتی زیندوو دەستکاری نەکراون.


## گۆڕانکاریی پاراستن لە برانچی کاری
لە کۆمیتەکانی پاش ئەم تۆمارەدا گەیتێکی editorial بۆ کویزەکانی وانەکانی ٢، ٤، ٨، ١٣، ١٤، ١٦، ١٨، ١٩ و ٢١ زیاد کرا:
- ئەم کویزانە لە منووی تاقیکردنەوەکاندا نیشان نادرێن.
- دەستپێکردنیان بە callback ـی کۆنیش ڕەت دەکرێتەوە.
- وانەکان خۆیان ناچالاک ناکرێن و پێشکەشکردنیان بەردەوامە.
- کویزەکانی کۆرسی ٢ و ٣ بەهۆی ئەم گەیتەوە ناگیرێن.
- تاقیکردنەوەی یەکەیی بۆ لیستی گەیت و پاراستنی ناسنامەکانی کۆرسەکانی تر زیاد کرا.

ئەم گۆڕانکارییە تەنها لە `fix/four-course-structure-2026-10-27` ـە. تا تاقیکردنەوەی CI پشتڕاستی نەکاتەوە، وەک تەواوبوو ڕاپۆرت ناکرێت. هیچ گۆڕانکارییەک لە `main` یان بۆتی زیندوو نەکراوە.


## پشکنینی وردی پرسیارەکانی وانەکانی مەترسیدار
پشکنینی JSONی هەمان برانچ ئەم خاڵە وردانەی پشتڕاست کردەوە:

- **وانەی ٢:** پرسیاری ١ پەیوەندیی نێوان پیت و دەنگ دەناسێنێت؛ پرسیارەکانی ٢ و ٣ بانگەشە ڕەهایەکانی وانەکە دەهێننەوە، بەڵام explanation ئاگاداریی پێویستی بە پشکنین دەدات. هەرچەند وەڵامەکان بە دەقی وانەکە دەگونجێن، ئەمە بەڵگەی دروستیی یاساکان نییە.
- **وانەی ٤:** پرسیاری ٣ شێوەی «اِیمان» بەکاردەهێنێت، لە کاتێکدا دەقی ئەسڵی نموونەی «ایمان = ئیمان»ی هەیە. ئەم جیاوازییەی نووسین پێویستی بە ڕێکخستنەوەی پرسیار لەگەڵ نموونەی ئەسڵی هەیە.
- **وانەی ٨:** سێ پرسیارەکە هاوتاکردنی نیشانەکانی فارسی و پیتەکانی کوردی لە دەقی وانەکەوە دەهێننەوە؛ پێش چالاککردن دەبێت بۆ هەر هاوتاکردنێک سەرچاوەی ڕاستەوخۆ و مەودای بەکارهێنان هەبێت.
- **وانەی ١٣:** پرسیاری ١ بە شێوەی ڕەخنەیی داوا دەکات ئەرک و سەرچاوە پشتڕاست بکرێنەوە؛ پرسیاری ٢ تەنها ناسینەوەی «ڵ» لە لیستی دەقە؛ پرسیاری ٣ بانگەشەی واتاگۆڕینەوە لە دەقەکەوە دەهێنێتەوە. دوو پرسیاری دوایی هێشتا بەڵگەی سەرچاوەیی تایبەتییان نییە.
- **وانەی ١٤:** پرسیاری ١ و ٢ ناسینەوەی پیت/وشەی نموونەن؛ پرسیاری ٣ یاسای «ڵ لە سەرەتای وشە نایەت» بە دەقی وانەکەوە دەبەستێتەوە، نە بە سەرچاوەی سەربەخۆ.
- **وانەی ١٦:** پرسیاری ١ تەنها دوو نووسەی «و» لە «سوور»دا دەناسێنێت؛ پرسیاری ٢ پێناسەی «وو» وەک یەک پیت وەردەگرێت؛ پرسیاری ٣ وشەی «کەرکووک» لە لیستەکە دەناسێنێت. پێویستی بە ڕوونکردنەوەی جیاوازیی نووسە/دەنگ/دیگراف هەیە.
- **وانەی ١٨:** پرسیارەکە دابەشکردنی «کەژیار» وەک «کەژ / یار» تاقی دەکاتەوە، کە تەنها لە دەقی وانەکە وەرگیراوە و پشتڕاستیی دەنگناسییەکە جیاوازە.
- **وانەی ١٩:** پرسیارەکە «یا / ری» وەک دابەشکردنی وشە دەهێنێتەوە؛ ناونیشانی «پیتی (ی)» و ڕوونکردنەوەی وانەکە لەگەڵ ئەم نموونەیەدا پێویستی بە ڕوونکردنەوەی سەرچاوەیی هەیە.
- **وانەی ٢١:** پرسیاری ١ بە سنووری توێژینەوە ئاماژە دەکات و explanation هەمان سنوور دەپارێزێت؛ پرسیاری ٢ تەنها «gi / yan» لە دەقی وانەکە دووبارە دەکاتەوە؛ پرسیاری ٣ ئاگادارییەکی بەسوود دەهێنێتەوە. بەڵام پێش چالاککردن دەبێت سەرچاوەی پەیوەندیدار و پێناسەی «ڕێنووسی ئارامی/لاتینی» ڕوون بکرێتەوە.

### بڕیاری کۆتاییی ئەم قۆناغە
هیچ پرسیارێک لەسەر بنەمای ئەم پشکنینە بە خۆکار «زانستیی پشتڕاستکراو» ناوترێت. گەیتەکە بۆ ٩ وانەی دیاریکراو دەمێنێتەوە تا بەڵگەی پەڕەیی یان فەرهەنگیی گونجاو بۆ هەر بانگەشەیەک تۆمار بکرێت. پرسیاری ٣ی وانەی ٤ و ناونیشان/نموونەی وانەکانی ١٨–١٩ لە لیستی پێشینەی ڕێکخستنی دەقی پرسیار و ئامانجی فێرکردندن.
