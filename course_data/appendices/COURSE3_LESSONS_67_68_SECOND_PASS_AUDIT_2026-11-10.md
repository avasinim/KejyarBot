# ڕاپۆرتی پشکنینی دووەم — کۆرسی ٣، وانەکانی ٦٧ و ٦٨

- بەروار: 2026-11-10

- دۆخ: پشکنینی candidate؛ هیچ runtime یان production دەستکاری نەکراوە.

## ١. ئەنجامی پشکنینی ئۆتۆماتیکی

- ژمارەی وانەکانی سەرچاوە: ٦٦.
- ژمارەی وانەکانی candidate: ٦٨.
- یەکسانیی وانەکانی ١–٦٦ لە candidate لەگەڵ سەرچاوە: بەڵێ، هەموو ٦٦ وانەکە بە تەواوی هاوتان.
- ژمارەکردن: ١–٦٨ بەبێ بڕانەوە.
- ناسنامەی وانەکانی ٦٧ و ٦٨: جیاوازن.
- تاقیکاری: ١٢ پرسیار بۆ هەر وانەیەک؛ هەموو index ـەکانی وەڵامی ڕاست لە سنووری هەڵبژاردەکانن.
- پرسیاری دووبارەبووەوە لە ناو تاقیکاریی هەر یەک لە دوو وانەکەدا نەدۆزرایەوە.
- خانە سەرەکییەکانی ئامانج، خاڵەکان، نموونە، ڕاهێنان، تێگەیشتن، تاقیکاری و role-play بەتاڵ نین.

## ٢. کێشەی schema و پێویستیی سازگاری

شێوەی وانە ئەسڵییەکانی ١–٦٦ ئەم خانانەی هەیە:
`number, title, objective, key_points, examples, exercises, comprehension, quiz, role_play, review_status, source`

بەڵام وانەکانی ٦٧ و ٦٨:
- خانەی `source`یان نییە؛
- `source_note`یان هەیە؛
- `id` و `activities`یان زیادکراوە.

ئەمە جیاوازییەکی ڕاستەوخۆی schema ـە. تا loader، adapter و validator ـی runtime نەخوێندرێنەوە و نەسەلمێندرێن، نابێت بڵێین candidate ـەکە لەگەڵ سیستەمی کۆن سازگارە. چارەسەری پێشنیارکراو: پاشکۆ و چالاکییە زیادەکان بپارێزرێن، بەڵام candidate ـی runtime بە شێوەیەکی ڕوون و تاقیکراوە لەگەڵ schemaی پەسەندکراوی کۆرس یەکبخرێتەوە؛ هیچ خانە یان ناوەڕۆکێک بەبێ پاراستنی هاوتای ئەسڵی لابەرنەبرێت.

## ٣. پشکنینی زانستیی وانەی ٦٧ — «ئەرکی ە»

پێویستە ئەم جیاوازییانە بە نموونە و شیکردنەوەی مۆرفۆلۆژی ڕوون بکرێنەوە:
1. «ئەو مامۆستایە»: پێویستی بە جیاکردنەوەی پێکهاتەی ئاماژەیی/دیاریکەر هەیە؛ بە تەنیا نابێت وەک نموونەی هەواڵی وەسفی پیشان بدرێت.
2. «کوڕەکە»: پێویستە پێکهاتەی تەواوی پاشگری ناسراویی `-ەکە` شیکار بکرێت؛ نابێت «ە» لە پاشگرەکەدا بەبێ بەڵگە وەک مۆرفیمێکی سەربەخۆ ناوببرێت.
3. «خاڵە، وەرە»: بەکارهێنانی بانگکردنە؛ پێویستە لەگەڵ نموونەی ناسراویی بەراورد بکرێت.
4. «بخوێنە»: فۆڕمی فەرمانی تاکی دووەمە؛ سنووری ئەرکی «ە» لە فۆڕمی کرداردا بە وردی دیاری بکرێت.
5. «دەچێتە بازاڕ»: پێویستی بە شیکردنەوەی پێکهاتەی کردار و نیشانەی ئاراستە/شوێن هەیە؛ نابێت تەنیا بە ناونانی گشتی ڕوون بکرێتەوە.
6. «ئەو ڕۆیشتووە»: «ە» لە فۆڕمی کردارییەکەدا دەردەکەوێت؛ پێویستە لە پێکهاتەی تەواوی فۆڕمەکە جیا بکرێتەوە.
7. «ڕەشەبا» و «دەستە»: پێویستیان بە پشتڕاستکردنەوەی وشەسازی/فەرهەنگی هەیە؛ تەنیا هاوشێوەییی دەنگی بەڵگەی یەکسانیی مۆرفۆلۆژی نییە.
8. «کچە جوانەکە» و «ئەو کچە جوانەیە»: پێویستە پەیوەندیی ناو و هاوەڵناو، دیاریکەر و هەواڵ بە پارچەکردنی مۆرفۆلۆژی ڕوون بکرێتەوە.

ڕێنماییی بنەڕەتی: «ە» لە هەموو ئەم شوێنانەدا بە یەک ئەرک و یەک مۆرفیم ناژمێردرێت؛ هەر شیکردنەوەیەک دەبێت بە بەستێن، پێکهاتە و بەڵگە پشتگیری بکرێت.

## ٤. پشکنینی زانستیی وانەی ٦٨ — «نەرێکردن»

1. «نە، نا، مە، نی» نابێت وەک چوار پێشگری یەکسان پیشان بدرێن؛ جیاوازیی نەرێکەری کردار، فەرمان و پەیوەندیی وەسفی دیاری بکرێت.
2. «نی» لە نموونەکاندا بە شێوەی «نییە» هاتووە؛ پێویستە ڕوون بکرێتەوە کە فۆڕمی بەکارهاتوو چییە و ئایا «نی» بە تەنیا یەکەیەکی سەربەخۆی نەرێیە یان نا.
3. «ناخۆش/نەخۆش» نابێت بە شێوەی دوو وشەی سادەی یەک بنەما و دوو پێشگری بەرهەمدار فێر بکرێن؛ جیاوازیی واتا و وشەییبوونیان پێویستی بە پشتڕاستکردنەوەی فەرهەنگی هەیە.
4. پێشگری «بەد» و نموونەکانی «بەدشکڵ/بەدخواز» پێویستیان بە بەڵگەی فەرهەنگی و بەکارهێنانی ستاندارد هەیە.
5. «نەدەکرد/نەدەنووسی» دەبێت بە پارچەکردنی فۆڕمی کردار و دیاریکردنی کات/ڕەگەزی کرداری شیکار بکرێن.
6. «تێرنەخۆر» و «چاونەشۆر» وەک پێکهاتەی وشەیی/وشەی جێگیر بپشکنرێن؛ لەسەر بنەمای ئەم نموونانە یاسای گشتیی دروستکردنی وشە دروست نەکرێت.
7. «بێسوود» و «نادروست» نموونەی وشەسازیی نەرێن، بەڵام «نەهات» و «ناکەم» نەرێکردنی کردارین؛ ئەم دوو ئاستە لە وانە و تاقیکاری جیا بکرێنەوە.

## ٥. سنووری ئەم پشکنینە

- ئەم پشکنینە پشکنینی ناوەڕۆک و پێکهاتەی فایلەکانە؛ بەڵگەی پەسەندکردنی زانستیی کۆتایی نییە.
- schemaی runtime و adapter هێشتا پشتڕاست نەکراونەتەوە.
- لە کاتی پشکنینەوە هیچ workflow run و هیچ CI status ـێک بۆ commit ـەکە نەگەڕایەوە؛ ئەمە بە مانای سەرکەوتنی CI نییە.
- دۆخی Botkeep بەهۆی کێشەی infrastructure ـی پێشوو هێشتا release gate ـە.
- هیچ merge، deployment، restart، sync، گۆڕانکاریی database یان چالاککردنی Telegram ئەنجام نەدراوە.

## ٦. ڕێڕەوی پێشنیارکراوی دواتر

1. دۆزینەوە و خوێندنەوەی loader/adapter و schemaی فەرمیی وانەکان.
2. دروستکردنی candidate ـێکی schema-compatible بە پاراستنی هەموو پاشکۆ و چالاکییە زیادەکان.
3. پشکنینی زمانەوانیی نموونە هەستیارەکان و پشتڕاستکردنەوەی فەرهەنگی.
4. جێبەجێکردنی JSON/schema tests و CI لە ژینگەیەکی سەلامەت.
5. چالاککردن تەنیا دوای پشتڕاستکردنەوەی ستافی Botkeep لە سەلامەتیی host.



## ٧. پاشنووس و ڕاستکردنەوەی خاڵی schema — 2026-11-10

لە پشکنینی candidateی دوایین (دوای زیادکردنی runtime adapter) ئەم ڕاستکردنەوەیە پێویست بوو:

- وانەکانی ٦٧ و ٦٨ **خانەی `source`یان هەیە**؛ پێکهاتەکە `book`, `source_policy`, `pages` ـە. لەگەڵیدا `source_note` ـیش پارێزراوە. بۆیە ئەو بڕگەیەی پشکنینی دووەم کە دەڵێت «خانەی sourceیان نییە» بۆ candidateی ئێستا دروست نییە و بە پاشنووس ڕاست دەکرێتەوە.
- جیاوازیی schema هێشتا لە بوونی خانە زیادەکانی `id` و `activities` لە وانە نوێیەکاندایە؛ ئەمە بە تەنیا هەڵە نییە ئەگەر loader/adapter خانە زیادەکان قبوڵ بکات. adapterی candidate ئێستا `activities` بە شێوەی structured object دەخوێنێتەوە و بە دەقی خوێندنەوەیی پیشانی دەدات.
- تاقیکارییە زیادکراوەکان ئەم پەیوەندییە پشکنین دەکەن، بەڵام چونکە جێبەجێ نەکراون، سازگاریی runtime بە شێوەی ئەنجامی تاقیکاری پشتڕاست‌کراوە ناژمێردرێت.
- ئەو خاڵانەی audit ـەکە سەبارەت بە پێویستیی پشکنینی زانستیی نموونەکان، ژمارەی وانەکان، پاراستنی ٦٦ وانەی سەرەتا، و release gate هێشتا بەردەوامن.

ئەم پاشنووسە بڕگەی نادروستیی `source` ڕاست دەکاتەوە؛ هیچ ناوەڕۆکی وانە یان پاشکۆیەک ناسڕێتەوە.
