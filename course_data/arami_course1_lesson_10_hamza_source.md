# وانەی ١٠: هەمزە (ئـ)

## 🎯 ئامانجی وانە
لە کۆتایی ئەم وانەیەدا فێرخواز بتوانێت:
- شێوەی هەمزە لە زمانی کوردی بناسێت.
- جیاوازیی بەکارهێنانی هەمزە لە کوردی و فارسی و عەرەبیدا تێبگات.
- ڕۆڵی هەمزە لە جیاکردنەوەی دوو بزوێنی بەدوای یەکدا بناسێت.
- لە وشەکاندا شوێنی پێویستی هەمزە دیاری بکات.
- لە وشەی لێکدراو و داڕێژراودا یاسای قرتاندنی هەمزە بناسێت.

## ١. هەمزە لە زمانی کوردیدا
هەمزە لە زمانی عەرەبی و فارسیدا بە چەند شێوەی جۆراوجۆر بەکاردێت، وەک:
(أ، ٌإ، لأ، لإ، ؤ، ء، ئـ)
بەڵام لە زمانی کوردیدا تەنیا شێوازی (ئـ) بەکاردەهێنرێت. ئەرکی ئەم شێوازە ئەوەیە کە ڕێگری بکات لەوەی دوو بزوێن بەدوای یەکتردا بنووسرێن.
بۆیە نابێت بڵێین هەمزە لە زمانی کوردیدا وەک فارسی و عەرەبی بەکاردەهێنرێت؛ چونکە شێوازی بەکارهێنانەکەی جیاوازە.

## ٢. هەمزە و بزوێنەکان
هەمزە لە زمانی کوردیدا هەمیشە لەگەڵ بزوێنێک دێت:
- ئــا
- ئــە
- ئــو
- ئــۆ
- ئــوو
- ئــی
- ئــێ

لە هەندێک وشەی وەک «ئــنـجا» و **«ئـــسفەهان»**یشدا هەمزە دەبینرێت. لەو وشانەدا بزوێنێک هەیە، بەڵام بزرۆکەیە و نانووسرێت. ئەگەر بزرۆکەش بنووسرێت، دیسان هەمزە لەگەڵ بزوێنێکدا دێت.
لەبەر ئەوە، ئەگەر بمانەوێت بە کوردی ناوێک بۆ هەمزە دابنێین، دەتوانین ناوی «ئاوەڵبزوێن» بەکاربهێنین.

## ٣. هەمزە بزوێنە یان نەبزوێن؟
هەندێک لە زمانزانان هەمزە بە بزوێن دادەنێن و لای هەندێکی دیکەش بە نەبزوێن دەناسرێت.
بەڵام لە ڕاستیدا، کورد هەمزەی بە شێوازی (ئـ) بەکارهێناوە و بڕیاری داوە وەک نەبزوێنێک چاوی لێ بکات، بۆ ئەوەی:
- دوو بزوێن بەدوای یەکتردا نەیەن.
- هەندێک بزوێن لە سەرەتای وشەدا بە شێوەی پێویست بنووسرێن.

### نموونەکان
| شێوەی سەرەتایی | شێوەی نووسینی کوردی |
|---|---|
| نــاازاد | نــائــازاد |
| او | ئــاو |
| ه‌و | ئـــەو |
| ۆخه‌ی | ئــۆخەی |
| ورووپا | ئــورووپا |
| ێـجگار | ئــێجگار |

## ٤. قرتاندنی هەمزە (ئـ)
کورد لە کۆنەوە تا ئەو جێیەی بۆی کرابێت، هەمزەی تەنیا لە کاتی پێویستدا بەکارهێناوە؛ ئەگینا قرتاندوویەتی.
بۆ نموونە، لە کۆنەوە ئەم شێوازەی بەکارهێناوە:

| پێکهاتە | شێوەی بەکارهێنان | شێوەی بەکارنەهێنان |
|---|---|---|
| ترش + ئاو | ترشاو | ترشئاو |
| کوڵ + ئاو | کوڵاو | کوڵئاو |
| بار + ئاش | باراش | بارئاش |
| گۆلک + ئاو | گۆلکاو | گۆلکئاو |

تێبینی: کوڵاو واتە ئاوێک کە کوڵاوە.

## ٥. قرتاندنی هەمزە لە وشەی لێکدراو و داڕێژراودا
دەتوانین ئەم بنەمایە لە وشەی لێکدراو و داڕێژراوی نوێشدا بەکاربهێنین؛ واتە بە پێی ئەم یاسایە هەمزە بقرتێنین.

### نموونەکان
| شێوەی بەکارنەهێنان | شێوەی دروستی نووسین بەپێی وانەکە |
|---|---|
| ڕۆژئاوا | ڕۆژاوا |
| خۆرئاوا | خۆراوا |
| ماڵئاوایی | ماڵاوایی |
| کارئاسانی | کاراسانی |
| بانئەفشار | بانەفشار |
| کارئەندامزانی | کارەندامزانی |
| تووڵئامراز | تووڵامراز |

### ڕوونکردنەوەی هەندێک نموونە
- بانەفشار: ناوی گەڕەکێکە لە شاری قەسری شیرین، لە پارێزگای کرماشان.
- کارەندامزانی (physiology).
- تووڵامراز (toolbar):
  - تووڵ = شیش، bar
  - ئامراز = کەرەستە، tool

## ٦. وشەکانی دیکە کە بەبێ (ئـ) دەنووسرێن
هەروەها ئەم وشانەش بەبێ هەمزە (ئـ) وا دەنووسرێن:
- کەمـەندام
- چاوه‌سمه‌ر
- چاوه‌ستێره‌
- گوڵـه‌ندام
- گوڵـه‌ستێره‌
- شێره‌ندام
- خاکـەناز
- ڕۆژاوا
- خۆراوا

## ٧. پوختەی وانە
- لە زمانی کوردیدا تەنیا شێوازی (ئـ)ی هەمزە بەکاردێت.
- هەمزە لە زمانی کوردیدا لەگەڵ بزوێنێکدا دێت.
- هەمزە بۆ ڕێگرتن لە نووسینی دوو بزوێن بەدوای یەکتردا بەکاردێت.
- لە هەندێک وشەدا هەمزە پێویستە و لە هەندێکی دیکەدا قرتێندرێت.
- لە وشەی لێکدراو و داڕێژراودا دەتوانرێت بەپێی ئەم بنەمایە هەمزە بقرتێنین.

## ⭐ کۆتایی وانە
ئافەرین! لەم وانەیەدا فێربووین کە هەمزە لە ڕێنووسی کوردیدا شێواز و ئەرکی تایبەتی هەیە؛ هەندێک جار بۆ ڕێگرتن لە کۆبوونەوەی دوو بزوێن بەکاردێت و هەندێک جاریش لە وشەی لێکدراو و داڕێژراودا قرتێندرێت.
