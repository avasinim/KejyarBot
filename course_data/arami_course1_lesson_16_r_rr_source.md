# وانەی ١٦: پیتی «ر» و «ڕ»

## پیتی (ڕ)

- پیتی (ڕ) چەڵەمەی هەیە و قەڵەو بێژە دەکرێت.
- چەڵەمەکەی لە ژێرەوەی پیتەکەیە.
- لە سەرەتا و نێوەڕاست و کۆتاییی وشەدا دێت.
- هەر وشەیەک لە زمانی کوردیدا بە (ڕ) دەست پێ بکات، دەبێت ئەم ڕ چەڵەمەدارەی تێدا بنووسرێت.

### نموونەکان

- ڕێگا
- ڕێبوار
- ڕامان
- پەڕۆ
- مەڕ
- دڕاو

## پیتی (ر)

- پیتی (ر) وەک (ر) لە زمانی فارسیدا بێژە دەکرێت.
- بەڵام قەت لە زمانی کوردیدا لە سەرەتای وشەدا نایەت.
- لە نێوەڕاست و کۆتاییی وشەدا دێت.

### نموونەکان

- رێگا ❌ — ڕێگا ✅
- دار
- دیوار
- دەرگە
- کورد

## جیاوازیی نووسین و واتا لە نێوان (ڕ) و (ر)

ئەگەر بەجێی پیتی (ڕ)، پیتی (ر) بنووسرێت، لە هەندێک وشەدا واتای وشەکە دەگۆڕدرێت.

- بڕا = بریدە شد؛ برا = برادر
- دڕاو = پارەشدە؛ دراو = پووڵ، پارە
- ئاور = ئاگر و ئاتەش؛ ئاوڕ = گەڕانەوە و تەماشاکردنی پشت سەر
- بڕۆ = داخوازیی ڕۆیشتن؛ برۆ = ئەبرۆ
- فڕیو = چۆلەکەیەک کە فڕیوە؛ فریو = فەریب و فریوخواردن

## تێبینیی دەنگزانی: دوو فۆنیمی جیاواز

ئەم دوو پیتە لە زمانی کوردیدا دوو نرخی جیاوازیان هەیە و دوو فۆنیمی جیان؛ چونکە لە سیستەمی دەنگزانیی زمانی کوردیدا دوو نرخی جیاوازیان پێ دراوە.

فۆنیم چییە؟ هەڵبژاردنی چەند دەنگ بۆ زمانێک کە بە شێوەی پیت خۆیان دەنوێنن. کاتێک پیتێک لە ناو وشەیەک بسڕینەوە و پیتێکی تر لە جێگای دابنێین و واتای وشەکە بگۆڕێت، ئەو دوو پیتە جیاوازیی فۆنیمییان هەیە. بۆ نموونە، بەجێگۆڕکێی (ڕ) و (ر) لە وشەکانی وەک بڕا/برا و فڕیو/فریو، واتا دەگۆڕێت؛ بۆیە ئەم دوو پیتە دوو فۆنیمی جیاوازن.

### نموونەی زیادە

- ئاور / ئاوڕ
- بڕۆ / برۆ
- بڕا / برا
- دڕاو / دراو
- فڕیو / فریو

## دەنگەکان

- دەنگی پیتی ڕ: دەنگی ڕ
- دەنگی پیتی ر: دەنگی ر
