# دەورەی ١: ڕێنووسی زمانی کوردی
## وانەی ٤ — یەکخستنی هەندێک پیت لە ڕێنووسی کوردیدا

### ئامانجەکانی فێربوون
- جیاوازیی نێوان پیت، دەنگ و ڕێنووس بناسێت.
- تێبگات کە وشەی وەرگیراو دەتوانێت لە ڕێنووسی کوردیدا شێوەی نووسینی جیاوازی هەبێت.
- پیتە هاوشێوەکان لە خشتەدا بەراورد بکات.

### ١. وشەی وەرگیراو چییە؟
وشەی وەرگیراو وشەیەکە کە لە زمانێکی ترەوە هاتووە و لە زمانی کوردیدا بەکاردێت. لە کاتی وەرگرتنی وشەدا، شێوەی نووسین و خوێندنەوە ڕەنگە بەپێی ڕێنووسی کوردی بگۆڕێت.

**گرنگ:** پیت، دەنگ و ڕێنووس یەک شت نین. بۆیە نابێت هەموو وشەیەک تەنها بە گۆڕینی یەک پیت بە پیتێکی تر بنووسین؛ شێوەی باوی وشەکە فێر ببە و لە نموونەکاندا جیاوازییەکان بناسە.

### ٢. خشتەی بەراوردی پیتەکان
لە نووسینی هەندێک وشەی وەرگیراودا ئەم هاوتاکردنانە ڕوودەدەن:

| پیتەکان | شێوەی زۆر باو لە کوردیدا |
|---|---|
| ت، ط | ت |
| س، ص، ث | س |
| ز، ذ، ض، ظ | ز |

ئەم خشتەیە یارمەتیت دەدات پیتەکان بناسیتەوە، بەڵام هەر وشەیەک دەبێت بە شێوەی نووسینی باوی خۆی فێر بکرێت. وشەکانی «قطار»، «ثمر»، «صدف»، «غذا»، «ضربان» و «نظر» لە خشتەی ڕاهێناندا بەکاربهێنە و پیتە جیاوازەکان نیشانە بکە.

### ٣. چۆن وشەیەک بپشکنین؟
١. وشەکە بخوێنەوە.
٢. پیتە نووسراوەکانی بنووسە.
٣. پیتە هاوشێوەکان لە خشتەکەدا بناسەوە.
٤. شێوەی نووسینی کوردیی وشەکە لە نموونەکانی وانەکەدا بەراورد بکە.
٥. وشەکە بە شێوەی ڕاستەوخۆ وەک نموونەی یاسای گشتی بەکارمەهێنە، مەگەر لەگەڵ نموونەکانی تر بگونجێت.

### ٤. ڕاهێنانی فێرخواز
بۆ هەر وشەیەک لە خشتەی خوارەوە، پیتە ئامانجەکان نیشانە بکە:

| وشە | پیتی ئامانج |
|---|---|
| قطار | ت / ط |
| ثمر | ث / س |
| صدف | ص / س |
| غذا | ذ / ز |
| ضربان | ض / ز |
| نظر | ظ / ز |

پاشان دوو وشەی وەرگیراوی تر هەڵبژێرە و بنووسە. بۆ هەر یەکێک، شێوەی نووسین و خوێندنەوەی بەراورد بکە.

### ٥. خۆت تاقی بکەرەوە
- وشەی وەرگیراو چییە؟
- جیاوازیی نێوان پیت و دەنگ چییە؟
- لە خشتەکەدا «س، ص، ث» زۆرجار بە کام پیت دەنووسرێن؟
- بۆچی نابێت یاسایەکی گشتی لەسەر تەنها یەک وشە دابنێین؟

**کورتەی وانە:** لە وشەی وەرگیراودا ڕێنووس دەتوانێت بەپێی زمانی وەرگر بگۆڕێت. پیتە هاوشێوەکان بناسەوە، بەڵام شێوەی نووسینی هەر وشەیەک بە جیا فێر ببە.
