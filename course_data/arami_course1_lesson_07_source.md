## بەشی پێشەکی: جیاوازیی ڕێنووسی فارسی و کوردی

هەروەک دەزانن لە زمانی فارسیدا ئێمە چەند پیتمان هەیە کە بە یەک شێوە دەخوێنرێنەوە، بەڵام یەک جۆر نانووسرێن.

وەکوو: س، ص، ث

وەکوو: ز، ذ، ض، ظ

وەکوو: ت، ط

بەڵام هەر بۆ ئەم پیتانە لە کوردیدا تەنیا (س، ت، ز)مان هەیە.

یانی ئەگەر بمانەوێت وشەکانی ژێر بە ڕێنووسی کوردی بنووسین، بەم شێوەیەن.

| وشەی فارسی | نووسینی کوردی |
|---|---|
| ثنا | سەنا |
| سامان | سامان |
| صابر | سابێر |
| ذرت | زۆررەت |
| ظاهر | زاهێر |
| ضربە | زەربێ |
| توت | تووت |
| طاهر | تاهێر |

ئەمەش بزانن کە لە کوردیدا تشدید(گیرەدار)مان نییە.

یانی پیتێک کە گیرەدارە دەبێت دوو جار بنووسرێتەوە.

محمّد= محەممەد

لە زمانی کوردیدا ئێمە وشەکان چۆن بڵێین، ئاواشیان دەنووسینەوە.

بۆ نموونە:

| وشەی فارسی | نووسینی کوردی |
|---|---|
| موسی | مووسا |
| کبری | کوبڕا |
| خواهر | خاهەر |
| خویش | خیش |

مانای وشەکان بە فارسی:

گیرەدار= تشدید

وەکوو:

| وشەی فارسی | نووسینی کوردی |

| ثانیە | سانیه |

لە کۆتایی ئەم وانەیەدا فێرخواز بتوانێت:

- نموونەکانی ئەم وانەیە بە ڕێنووسی کوردی بخوێنێتەوە.

### ١. پیتی (س) لە زمانی کوردیدا

لە زمانی کوردیدا تەنیا یەک پیتی **«س»**مان هەیە، کە بە لاتینی بە دوو شێوەی گەورە و بچووک دەنووسرێت:

**س = S, s**

پیتەکانی **(ث ـ ص)** لە ڕێنووسی کوردیدا بەکارناهێنرێن، بەڵکو بە پیتی **«س»** دەنووسرێن.

### ٢. گۆڕینی (ث) و (ص) بۆ (س)

بۆ ئەوەی ئەم یاسایە باشتر تێبگەین، ئەم نموونانە بخوێننەوە:

| وشە بە نووسینی فارسی | نووسین بە ڕێنووسی کوردی |
|---|---|
| ثابت | سابت |
| ثانیە | سانیه |
| میراث | میراس |

| قصە | قسه |
| قصر | قەسر |

**تێبینی:** لە هەموو ئەم نموونانەدا، پیتی (ث) و (ص) بە پیتی (س) گۆڕدراون.

### ٣. پوختەی وانە
- لە زمانی کوردیدا تەنیا یەک پیتی (س)مان هەیە.
