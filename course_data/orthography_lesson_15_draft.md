# دەورەی ١: ڕێنووسی زمانی کوردی
## وانەی ١٥ — جیاوازیی «ڕ» و «ر»

### ئامانجەکانی فێربوون
- دوو پیتی «ر» و «ڕ» لە نووسین جیا بکاتەوە.
- لە وشەکاندا پیتی ئامانج دیاری بکات.
- بزانێت گۆڕینی پیت دەتوانێت شێوەی نووسینی وشە بگۆڕێت.

### ١. دوو پیتی جیاواز
«ر» و «ڕ» دوو پیتی جیاوازن. لە کاتی نووسینی وشەدا پێویستە هەر وشەیەک بە شێوەی دروستی خۆی بنووسرێت؛ نابێت ئەم دوو پیتە تێکەڵ بکرێن.

### ٢. نموونەکانی «ڕ»
ئەم وشانە بخوێنەوە و «ڕ» نیشانە بکە:
- ڕۆژ
- گۆڕ
- بڕیار
- سڕ
- کەڕ

### ٣. نموونەکانی «ر»
ئەم وشانە بخوێنەوە و «ر» نیشانە بکە:
- بارین
- چنار
- بارانە
- بەهار
- مردن

### ٤. بەراوردی نووسین
جوتەکانی خوارەوە بخوێنەوە و تەنها جیاوازیی پیتەکە دیاری بکە:
- برۆ / بڕۆ
- کەر / کەڕ

لە هەر جوتەیەکدا پیتە جیاوازەکە نیشانە بکە. پاشان وشەکان بە دەنگ بخوێنەوە و تێبینی بکە کە گۆڕینی پیت دەتوانێت خوێندنەوە و واتای وشە بگۆڕێت.

### ٥. خشتەی ڕاهێنان

| وشە | پیتی ئامانج | شوێنی پیت |
|---|---|---|
| ڕۆژ | ڕ | سەرەتا |
| گۆڕ | ڕ | کۆتایی |
| بڕیار | ڕ | ناو وشە |
| بارانە | ر | ناو وشە |
| بەهار | ر | ناو وشە |
| مردن | ر | ناو وشە |

### ٦. ڕاهێنانی فێرخواز
١. لە «ڕۆژ، گۆڕ، بڕیار» پیتی «ڕ» نیشانە بکە.
٢. لە «بارانە، بەهار، مردن» پیتی «ر» نیشانە بکە.
٣. جوتی «برۆ/بڕۆ» بەراورد بکە و پیتی جیاوازەکە نیشانە بکە.
٤. دوو وشە بنووسە کە بە «ڕ» دەست پێ دەکەن.
٥. دوو وشە بنووسە کە «ر»یان تێدایە.

### ٧. خۆت تاقی بکەرەوە
- جیاوازیی نووسینی «ر» و «ڕ» چییە؟
- دوو وشە بنووسە کە «ڕ»یان تێدایە.
- دوو وشە بنووسە کە «ر»یان تێدایە.
- لە «بڕیار»دا کام پیت دوو جار دەبینرێت؟

**کورتەی وانە:** «ر» و «ڕ» دوو پیتی جیاوازن. لە نووسین و خوێندنەوەدا بە وردی جیاوازییان بناسەوە.
