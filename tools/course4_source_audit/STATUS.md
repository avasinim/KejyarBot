## پشتڕاستکردنەوەی باینەری و ناسنامەی چاپ
دوو PDFی بارکراوی بەکارهێنەر لە ژینگەی کاردا خوێندرایەوە و Git blob SHA ـیان بە وردی لەگەڵ SHAی چاوەڕوانکراو یەکسان بوو:

پشکنینی وێنەی لاپەڕەی سەرەتا و ناونیشانی چاپکراو ئەمانەی پشتڕاست کردەوە:
- فایلەکەی بەرگی ١ لە کۆمیتی بەرگی ١، لە ڕاستیدا **بەرگی یەکەمی ڕێزمانی کوردی، وشەسازی، بەشی دووەم: جێناو** ـە.
- فایلەکەی بەرگی ٣ لە کۆمیتی بەرگی ٣، **بەرگی یەکەمی ڕێزمانی کوردی، وشەسازی، بەشی سێیەم: ئاوەڵناو** ـە. لەسەر پەڕەی ناونیشانی چاپکراودا «بەشی سێیەم — ئاوەڵناو» بە ڕوونی نووسراوە.

**ئاگاداریی گرنگی پشکنین:** لە `extract_books.py`دا ئێستا بەرگی ١ بۆ وانەکانی ١–٦ (ناو) و بەرگی ٢ بۆ وانەکانی ٧–١٢ (جێناو) دانراوە. ئەمە لەگەڵ ناسنامەی چاپکراوی PDFی بەرگی ١ ناکۆکە. پێش هەر گۆڕانکارییەک لە وانەکان، دەبێت لاپەڕەی سەرەتای PDFی بەرگی ٢ بپشکنرێت و دڵنیایی لە دابەشکردنی بەشەکان وەربگیرێت. هیچ وانەیەک لەسەر ئەم گومانەدا نەگۆڕدراوە.

## دۆخی OCR و workflow
- پێنج کۆمیتەی سەرچاوە لە script ـدا بە SHAی blob دیاریکراون.
- هەوڵەکانی OCRی تەواوی ١٣٤٨ لاپەڕە لە یەک jobدا لە هەنگاوی OCR ماونەتەوە و artifact ـیان بەرهەم نەهێناوە.
- بۆ ڕێگریکردن لە دووبارەبوونەوەی job ـی درێژ، trigger ـی خۆکار لەسەر push لابرا و workflow تەنها بە دەستی دەکرێت دەستپێبکرێت.
- workflow تا دابەشکردنی OCR بۆ مەودای لاپەڕەی سنووردار و پشکنینی دابەشکردنی ڕاستی بەرگەکان dispatch ناکرێت.

٤. هیچ دەقی وانە، زاراوە یان نموونەیەک بەبێ بەڵگەی سەرچاوە ناگۆڕدرێت.

## پشکنینی نوێی بەشی جێناو — بەرگی ١

وێنەی چاپکراوی پەڕەکانی ٣–٢٠ بەشێوەی ڕاستەوخۆ بینرا و بە دڕافتەکانی وانە ٧–١٢ بەراورد کرا. دەرکەوت:
- جێناوی کەسی لە پەڕە ١٤ دەست پێ دەکات؛ سەرچاوەی ئێستای وانە ٩ (پەڕە ١٠–١١) پێویستی بە چاککردنەوەی ئاماژەی پەڕە هەیە.
- جێناوی پرسیاری لە پەڕە ١٥ و جێناوی نەفی لە پەڕە ١٦ دیارە؛ سەرچاوەی وانە ١٠ (پەڕە ١١–١٢) هەڵەیە.
- پەڕە ١٧–١٩ بۆ بەشی پێکهاتە/دەستەواژە و ڕستەسازی بەڵگەی سەرەتایین؛ ئاماژەی وانە ١٢ (پەڕە ١٣–١٥) ناگونجێت.
- پەڕە ١٦–١٧ بۆ وانە ١١ی جێناوی نیشانە پێویستی بە خوێندنەوەی وردتر هەیە؛ لاپەڕەسەرچاوەی ئێستا هێشتا پشتڕاست نەکراوەتەوە.
- وانە ٨ بە پەڕە ٦–١٠ پەیوەستە، بەڵام چوارچێوەی مرجع/کۆنتێکست/ئەرکی سینتاکسی لە دڕافتدا ڕوونکردنەوەی ئامادەکەرە، نەک پۆلێنکردنی ڕاستەوخۆی نووسەر.

ئەنجامەکان لە `docs/GRAMMAR_COURSE4_QA_REVIEW.md` تۆمار کراون. هیچ دڕافتێکی وانە لە شاخه‌ی بنەڕەتیی دڕافتدا دەستکاری نەکراوە.


### پشتڕاستکردنەوەی وردی پەڕەکانی ١٤–١٩
بە وێنەی گەورەکراوی لاپەڕە چاپکراوەکان:
- پەڕە ١٤: دەستپێکی جێناوی کەسی.
- پەڕە ١٥: بەشی جێناوی پرسیاری (کێ، چی).
- پەڕە ١٦: بەشی جێناوی نەفی و جێناوی نیشانە.
- پەڕە ١٧: «تایبەتمەندی جێناو لە ڕووی پێکهاتەسازییەوە»؛ پەڕەکانی ١٨–١٩ بەردەوامی بابەتەکەن.

لەبەر ئەمە، لاپەڕەسەرچاوەی پێشنیارکراوی دڕافتەکان بریتییە لە: وانە ٩ (١٤–١٥)، وانە ١٠ (١٥–١٦)، وانە ١١ (١٦)، وانە ١٢ (١٧–١٩). ئەم پەڕەسەرچاوە نوێیانە لە QA تۆمار کراون؛ دڕافتەکانی وانە هێشتا دەستکاری نەکراون.


## گۆڕینی OCR بۆ پشکنینی سنوورداری لاپەڕەی سەرەتا

لە کۆمیتی `8039dacc8780170c2c4d438061b07d4ef7a4a290`:

- Git blob SHAی هەر پێنج PDF پێش خوێندنەوە پشتڕاست دەکرێتەوە.
- وێنەی پەنج لاپەڕەکە لە contact sheet و دەقی OCR لە artifact ـدا هەڵدەگیرێت.

لە کۆمیتی `85dfa04a77214e79b6c1836dce5b8c920f10e3aa`:

- workflow لە ئێستادا بەهۆی سنووری دەستڕاگەیشتن بە dispatch ـی GitHub لەم گفتوگۆیەوە دەستپێنەکراوە؛ بۆیە هیچ artifact ـێکی نوێ بەرهەم نەهاتووە.

**هەنگاوی داهاتوو:** لە GitHub Actions، workflow ـی `Course 4 source PDF cover audit` لە شاخه‌ی `audit/course4-source-pdf-extraction` بە دەستی Run workflow بکە؛ artifact ـی `course4-source-cover-audit` پێنج وێنەی contact sheet و دەقی OCRی پێنج لاپەڕەی سەرەتای هەر بەرگێک دەگرێتەوە. پاش بەدەستهێنانی ئەو artifact ـە، ناونیشانی چاپکراوی بەرگەکانی ٢، ٤ و ٥ دەخوێندرێنەوە و نەخشەی وانەکان تەنها بە بەڵگە ڕاست دەکرێتەوە.

هیچ وانەیەک، PR #115، `main`، چالاککردنی کۆرس، deploy، production DB یان Botkeep sync دەستکاری نەکراوە.


## پشتڕاستکردنەوەی ناونیشانی بەرگی ٣ — پشکنینی وێنەیی
لە پشکنینی وێنەی پەڕەی ناونیشانی PDFی بەرگی ٣ (کۆمیت `c20d44b7c4833e28eda51702e17d430816ef72b3`)دا ئەم زانیارییانە بە ڕاستەوخۆ خوێندرایەوە:
- «ڕێزمانی کوردی»؛ بەرگی یەکەم، وشەسازی.
- «بەشی سێیەم — ئاوەڵناو».
- لە خوارەوە ساڵی چاپی ١٤١٢ ک/١٩٩١ ز دیارە.

بەمەوە ناونیشانی بەرگی ٣ و پەیوەندیی بە وانەکانی ١٣–١٨ لە ڕووی بابەتەوە پشتڕاست دەبنەوە. بەڵام ئەمە بە تەنها ناونیشانی بەرگەکانی ٢، ٤ و ٥ یان پەڕەسەرچاوەی هەموو وانەکانی بەرگی ٣ پشتڕاست ناکاتەوە. هەروەها ناکۆکیی بەرگی ١ لەگەڵ نەخشەی کۆن هێشتا چارەسەر نەکراوە؛ بۆیە نەخشەی `extract_books.py` هێشتا نابێت وەک نەخشەی پشتڕاستکراو بەکاربهێنرێت.

## پشکنینی ڕاستەوخۆی بەرگەکانی ١ و ٣ — ٥ی ١١ی ٢٠٢٦

وێنەی پەڕەی بەرگی PDF ـە بارکراوەکان لە ژینگەی پشکنیندا بە ڕاستەوخۆ خوێندرایەوە:

- **فایلی کۆمیتی بەرگی ١** (`2fb363f0abf3ebd4e753bd71f7c3d22d97cb7f55`، ٣٢٠ پەڕە): پەڕەی بەرگ بە ڕوونی دەڵێت «بەرگی یەکەم (وشەسازی)، بەشی دووەم (جێناو)». واتە ناوی فایل/کۆمیت «بەرگی ١» نابێت بە مانای «بەشی یەکەم: ناو» وەربگیرێت. ئەم فایلە بەشی جێناوە.
- **فایلی کۆمیتی بەرگی ٣** (`c20d44b7c4833e28eda51702e17d430816ef72b3`، ١٥٤ پەڕە): پەڕەی بەرگ دەڵێت «بەرگی یەکەم (وشەسازی)، بەشی سێیەم — ئاوەڵناو» و ساڵی ١٤١٢ ک/١٩٩١ ز نیشان دەدات. ئەمە بەشی ئاوەڵناوە.

ئەم دوو بەڵگەی وێنەییە ناهاوتاییی نەخشەی کۆنی extract_books.py پشتڕاست دەکەنەوە: فایلی ژمارە ١ لەو سکریپتەدا بۆ وانەکانی ناو دانراوە، بەڵام بەرگەکەی جێناوە. بۆ ڕێگریکردن لە بەرهەمهێنانی دەرئەنجامی هەڵە، هەڵسەنگاندنی لاپەڕە-وانە بە سکریپتی کۆن نابێت بەردەوام بێت تا هەموو پێنج بەرگ و پەڕەی بەرگیان پشتڕاست نەکرێنەوە و نەخشەی دروست جێگیر نەکرێت.

## سنووری workflow ـی پشکنینی بەرگ

Workflow ـی workflow_dispatch لە شاخه‌ی audit هەیە، بەڵام GitHub تەنها workflow ـی workflow_dispatch لە default branch بۆ دەستپێکردنی دەستی دابین دەکات. لەبەر ئەوەی سنووری پڕۆژە ڕێگە بە گۆڕینی main نادات، نابێت بانگەشە بکرێت کە ئەم workflow ـە لە ئێستادا بەبێ هەنگاوی دەستی/دەستکاریی default branch دەستپێدەکات. تا workflow لە default branch بە ڕێگەی ڕەزامەندیی خاوەن پڕۆژەدا دانەنرێت، یان سێ PDF ـی ماوە بە شێوەی بارکراو بەردەست نەبن، پشکنینی بەرگی ٢، ٤ و ٥ چاوەڕێ دەکات.

**بڕیاری پاراستن:** هیچ نەخشەیەکی نوێ بۆ وانەکان دانانرێت بە تەنها لەسەر بنەمای ژمارەی فایل. کۆرس ناچالاک دەمێنێتەوە؛ merge، deploy، main و Botkeep دەستکاری ناکرێن.

### بڕیاری کاتی و سنووری دڵنیایی
1. ناونیشانی بابەتی بەشی ٤ و ٥ لە سەرچاوە دەرەکییەکان پشتڕاست کراوەتەوە؛ بەڵام هێشتا نەمانتوانیوە پەڕەی بەرگی PDFی هاوتای blob ـەکانی کۆمیتەکە لە GitHub بخوێنینەوە.
2. بۆ بەرگی ٢، بەڵگەی کاتەلۆگ جێناو و ناو وەک دوو بەشی جیاواز پشتڕاست دەکاتەوە، بەڵام بەستنەوەی بەشی ناو بە blob ـی بەرگی ٢ هێشتا پێویستی بە بینینی پەڕەی بەرگی خودی فایلەکە هەیە.
3. بەرگی ١ و ٣ بە پشکنینی وێنەییی پێشووتر پشتڕاست کراونەوە: بەرگی ١ = جێناو؛ بەرگی ٣ = ئاوەڵناو.
4. نەخشەی فایل/بەرگ بۆ وانەکان تا پشتڕاستکردنەوەی blob ـەکانی ٢، ٤ و ٥ و پەڕەی ناونیشانیان وەک نەخشەی کۆتایی دانانرێت. هیچ وانەیەک لەسەر ئەم بەڵگانە نەگۆڕدراوە.
