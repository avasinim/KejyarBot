## ڕیزبەندیی کار

### پێشینەی ١ — بەڵگەی سەرچاوە
بۆ هەر وانەیەک تۆمار بکە:
1. ناوی تەواوی کتێب/سەرچاوە و نووسەر.
2. چاپ و ساڵی چاپ، ئەگەر بەردەستە.
3. ژمارەی لاپەڕە یان بەشی دیاریکراو.
4. دەقی بانگەشەی زمانەوانی و نموونەی سەرچاوە.
5. جیاوازیی نێوان دەقی سەرچاوە، ڕوونکردنەوەی دەستکار و بڕیاری پشکنەر.
6. دۆخ: پشتڕاستکراوە / ناکۆک / پێویستی بە بەڵگەی زیاتر.

هیچ لاپەڕە، سەرچاوە یان نموونەیەک مەخەڵقێنە. ئەگەر بەڵگە بەردەست نییە، دۆخەکە «پێویستی بە سەرچاوە» بمێنێتەوە.

### پێشینەی ٢ — پشکنینی تایبەتی
- وانەی ٤: یاساکانی ت، ط / س، ص، ث / ز، ذ، ض، ظ؛ سنووری زمان و ڕەچەڵەکی وشەکان ڕوون بکەوە.
- وانەی ١٣: ناوی «چەڵەمە»، نیشانەی ٚ، و ئەرکی ڕاستەقینەی لە سەرچاوەدا.
- وانەی ٢٠: پێناسەی «بزرۆکە» و پەیوەندیی ڕێنووس و دەنگناسی.
- وانەی ٢١: خوێندنەوە و بڕگەبەندیی «گیان» و «شوان» بەپێی شێوەزاری ئامانج و سەرچاوە.
- وانەی ٢٢: جیاکردنەوەی «و» و «ی» وەک بزوێن/نەبزوێن بە نموونەی پشتڕاستکراوە.

### پێشینەی ٣ — کویز
بۆ هەر پرسیارێک:
- پرسیار و وەڵامی ڕاست لەگەڵ وانەی پشکنراو بگونجێت.
- هەڵبژاردە هەڵەکان بەڕوونی هەڵە بن، نەک بەهۆی ناڕوونیی پرسیار.
- ڕوونکردنەوە بەڵگەی وانەکە باس بکات؛ بۆ بانگەشەی تایبەت، سەرچاوە/لاپەڕە تۆمار بکرێت.
- تا تەواوبوونی پشکنین، دۆخی draft بپارێزرێت.

### پێشینەی ٤ — پێکەوەبەستن بە runtime
تەنها دوای پشکنینی ناوەڕۆک:
- بارکردنی وانەکان لە کاتێکی هەڵبژاردنی وانە، نەک تەنها لیستی ناونیشانەکان.
- پاراستنی جیاوازیی کۆرسی نوێی ٢٢ وانەیی لە کۆرسی کۆنی ١٠ وانەیی.
- کویزەکان لە ڕێڕەوی جیاواز و بە پشکنینی دروستی وەڵامەکان بەکاربهێنرێن.
- هیچ دەنگێکی نوێ یان سیستەمی دەنگی دینامیک چالاک نەکرێت؛ تەنها workflow و دەنگی ئێستای پڕۆژە بپارێزرێت.

## دەرگای بڵاوکردنەوە
هیچ بڵاوکردنەوەیەک بۆ production یان گۆڕانکاریی `main` تا ئەمانە هەموویان بە بەڵگە تەواو نەبن:
- [ ] هەموو ٢٢ وانە پشکنینی سەرچاوەیان تەواوە.
- [ ] کویزەکان لەگەڵ وانەی پشکنراو یەکدەگرنەوە.
- [ ] تاقیکردنەوەی runtime و callback و ڕێڕەوی خوێندکار سەرکەوتووە.
- [ ] کۆرسی کۆنی ١٠ وانەیی هیچ تێکچوونێکی نییە.
- [ ] دەنگی ئافرەت و ڕێڕەوی دەنگی ئێستا پارێزراون.
- [ ] تاقیکردنەوەکانی CI بۆ commitی کۆتایی سەرکەوتوون.
- [ ] ڕێگەپێدانی ڕوونی بەکارهێنەر بۆ هەر گۆڕانکاریی production/main و بڵاوکردنەوە وەرگیراوە.

## پاراستنی نەگۆڕ
