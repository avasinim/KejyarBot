## ١. مەبەست و یاسای پشکنین

ئەم ماتریسە بۆ ئەوەیە هیچ وانەیەکی سەرچاوە بە هەڵە ون، دووبارە، یان بەبێ بەڵگە لەگەڵ وانەیەکی runtime یەکسان نەژمێردرێت. ژمارەی ٤٦ وانەی سەرچاوە و ژمارەی ٣١ وانەی runtime دوو ژمارەی جیاوازن. هەبوونی بابەتێکی هاوشێوە لە وانەیەکی runtime بەڵگەی ئەوە نییە کە وانەی سەرچاوە بە تەواوی تێدا یەکخراوەتەوە.

**پێوەری دۆخ:**
- **تۆمارکراوی runtime:** وانەکە لە `course_data/grammar_course4_lessons.json` هەیە.
- **پارێزراوی سەرچاوە:** دەقی سەرچاوە لە فایلێکی archive هەیە.
- **پەیوەندیی پشتگیرکراو:** بەڵگەی ڕوون هەیە کە بابەتەکە لە وانەیەکی runtime باس کراوە؛ ئەمە بە مانای یەکخستنی تەواو نییە.
- **پشتڕاست نەکراوە:** بەڵگەی بەس بۆ دانانی هاوتایی نییە.
- **پێشنیار:** ڕەشنووسە و پێویستی بە پەسەندکردنی خاوەن پڕۆژە هەیە.

## ٢. وانەکانی ١–٣١

## ٤. ئەنجامی پشکنین

1. وانەکانی ١–٣١ لە JSON ـی runtime تۆمارکراون.
2. وانەکانی ٣٢–٣٨ لە فایلێکی سەرچاوەی ١٥٤٨ هێڵی پارێزراون و بە ٧ وانە داڕێژراون.
3. وانەکانی ٣٩–٤٥ لە فایلێکی سەرچاوەی ٣١١٢ هێڵی پارێزراون و بە ٧ وانە داڕێژراون.
4. وانەی ٤٦ لە دوو فایلدا پارێزراوە: دەقی سەرچاوە و ڕەشنووسی پشکنراو. ڕەشنووسەکە runtime نییە.
5. بۆ وانەکانی ٣٢–٤٦ هیچ یەکخستنێکی تەواو و ڕاستەوخۆ بە وانەکانی ١–٣١ لەم ماتریسەدا دانەنراوە؛ تەنها پەیوەندییە بابەتییە پشتگیریکراوەکان نیشان دراون.
6. پاشکۆ مێژووییەکانی وانەکانی ٣٩–٤٥ بە ID ـی WritingBlock ناسراون، بەڵام دەقی تەواوی ئەو پاشکۆیانە لە داتای ئەم پشکنینەدا بە شێوەی فایلەی سەربەخۆ پشتڕاست نەکراوەتەوە. نابێت ID بە دەقی پاشکۆ بگۆڕدرێت.

## ٥. کاری داهاتوو بە ڕیزبەندی

1. دەقی تەواوی پاشکۆکانی ٣٩–٤٥ لە مێژووی چاتەوە بگەڕێندرێتەوە؛ هەر پاشکۆیەک بە فایلێکی جیاواز، بە پاراستنی دەقی خاو و بەرواری ڕەشنووس.
2. فایلەکانی سەرچاوەی ٣٢–٣٨ و ٣٩–٤٥ بە بەشی وانە بە وانە بپشکنرێن، بۆ دڵنیابوون لەوەی هیچ دەقی نێردراوی خاوەن پڕۆژە لە ترانسکریپتەکاندا نەماوەتەوە.
3. پەیوەندیی وانەی ٣٢–٤٦ بە وانەکانی ١–٣١ تەنها دوای بەراوردی دەقی وانە بە وانە بگۆڕدرێت بۆ «یەکخراو»؛ تا ئەو کاتە دۆخی «پەیوەندیی بابەتی» یان «پشتڕاست نەکراوە» بمێنێتەوە.
4. وانەی ٤٦ تا پەسەندکردنی خاوەن پڕۆژە لە ڕەشنووسدا بمێنێتەوە.
