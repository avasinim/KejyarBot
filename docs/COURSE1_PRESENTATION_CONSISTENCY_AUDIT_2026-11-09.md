# پشکنینی یەکگرتوویی پێشکەشکردنی وانەکانی کۆرسی ١ — ٩ی تشرینی دووەمی ٢٠٢٦

## سنوور و پاراستن

- پشکنین لەسەر سەرچاوە و ڕێڕەوی پێشکەشکردنی Telegram لە HEADی برانچی `work/course1-round1-review-2026-11-09` ئەنجام درا.
- ئەمە پشکنینی دیزاین و renderer ـە؛ پەسەندکردنی زانستیی ناوەڕۆک نییە.
- هیچ فایلێکی وانە، وشە، نموونە، یاسا، پرسیار، ڕیزبەندی یان ژمارەی بەشێک نەگۆڕدرا.
- هیچ دەنگ، پەخشکردنی دەنگ یان فایلێکی دەنگی زیاد نەکرا.

## دۆخی پێشکەشکردنی هاوبەش

فەرمانی خوێندنەوەی هاوبەش لە `arami_course1_telegram.py` ئەم شتانە دەکات:

1. ناونیشانی سەرەکیی Markdown بە شێوەی سەرەکیی وانە پێشکەش دەکات.
2. سەردێڕەکانی ئاستی دوو بە جیاکەرەوەی بینراو و ئاستی سێ و زیاتر بە نیشانەی لاوەکی پیشان دەدات.
3. سەردێڕی ڕاهێنان، تاقیکردنەوە، ئامانج و پوختە بە نیشانەی تایبەت جیا دەکاتەوە.
4. خشتەی Markdown دەگۆڕێت بۆ بۆکسەی هێڵ‌به‌هێڵی (ناوی ستوون: بەها)، بۆ ئەوەی لە شاشەی بچووکدا بەردەست بێت و بەهاکان ون نەبن.
5. دەقە درێژەکان بە پارچەی جیاواز دەنێرێت و هەوڵ دەدات سنووری درێژیی Telegram بپارێزێت.

ئەم شێوازە بۆ خوێندنەوەی مۆبایل گونجاوە؛ گۆڕینی renderer بۆ خشتەی HTML یان شێوازی نوێ لەم قۆناغەدا پێویست نییە، چونکە دەکرێت شێوەی هەندێک دەقی ڕەسەن بگۆڕێت.

## وێنە فێرکارییەکان

- شەش PNGی پەسەندکراو بە وانەکانی ١، ٢، ٣، ٤، ٦ و ٧ پەیوەستن.
- `lesson_infographic_path` تەنها ئەم ژمارانە ڕێگەپێدەدات.
- `send_lesson_infographic` وێنەی وانەی هەڵبژێردراو دەنێرێت و ئەگەر وێنە نەبوو، خوێندنەوەی وانە ناوەستێنێت.
- تاقیکردنەوەکان پشتڕاست دەکەنەوە کە شەش فایلەکە بە ناوی دروستیان دەنێردرێن و وانەی ٥ و وانەکانی دیکە وێنەی ساختەیان بۆ دانانرێت.
- وانەی ٥ و وانەکانی ٨–٢١ لەم کۆگایەدا وێنەی فێرکاریی پەسەندکراویان نییە؛ نابێت وێنەی وانەیەکی تر بۆیان بنێردرێت.

## بڕیار و هەنگاوی داهاتوو

1. ڕێڕەوی هاوبەشی renderer بپارێزرێت؛ لەم پشکنینەدا گۆڕینی کۆدی renderer پێویست نەبوو.
2. لە قۆناغی داهاتوودا دەتوانرێت تەنها لە لایەنی wrapperی پێشکەشکردنەوە، سەردێڕی کۆرس/دەورە و ناسنامەی وانە بە شێوەیەکی یەکسان زیاد بکرێت؛ بەڵام دەبێت پێش جێبەجێکردن لەگەڵ تاقیکردنەوەی HTML و درێژیی Telegram پشتڕاست بکرێتەوە.
3. هیچ سەردێڕ، ژمارە، بەش، وشە یان نموونەی سەرچاوە بە مەبەستی «یەکسانکردن» دەستکاری نەکرێت.
4. پەیوەندیی وێنەکان بە وانەکان وەک خۆی بمێنێتەوە تا وێنەی نوێی پەسەندکراو بۆ وانەیەک بەردەست بێت.

## سنووری پشتڕاستکردنەوە

ئەم پشکنینە لەسەر کۆد، فایلەکان و تاقیکردنەوەی خۆکارە. ناردنی ڕاستەوخۆ لە Telegram و دەرکەوتنی وێنەکان لە مۆبایلی فێرخواز تاقی نەکراوەتەوە، چونکە Botkeep هێشتا لە دۆخی Offline/Import-paused ـدایە.
