# پشکنینی ڕاهێنان و شیکاریی پێڕستە — وانەی ٣٢
**بەروار:** 2026-11-08  
**سەرچاوە:** ترانسکریپتی وانەکانی ٣٢–٣٨، بەشی وانەی ٣٢، هێڵی 1308–1552.  
**دۆخ:** پشکنین؛ هیچ دەقی خاو یان runtime نەگۆڕدراوە.

## ١. سنووری بەڵگە
لە ترانسکریپتەکەدا دەقی پێشنیارکراوی تەواوی وانەی ٣٢ و چوار ڕاهێنانی دیاریکراو هەیە. بۆ وانەکانی ٣٣–٣٨ پلانی دابەشکردن و ماددەی پشکنین هەیە، بەڵام دەقی وانەی سەربەخۆی تەواو و کلیلی وەڵامی ڕاهێنانەکانیان لەم بەڵگەیەدا بە شێوەی پشتڕاستکراو نییە. بۆیە کلیلی وەڵام بۆ ٣٣–٣٨ دروست نەکراوە.

## ٢. ڕاهێنانی یەکەم — وشە، دەستەواژە، ڕستە
| ژمارە | نموونە | وەڵامی پێشنیارکراو |
|---:|---|---|
| ١ | «کتێبێکی کوردی» | دەستەواژەی ناوی |
| ٢ | «قوتابییەکە خوێند.» | ڕستە و یەک پێڕستەی سەربەخۆ |
| ٣ | «لە ناو پۆلەکەدا» | دەستەواژەی پێشبەندی |
| ٤ | «من وانەکە دەخوێنمەوە.» | ڕستە و پێڕستەی سەربەخۆ |
| ٥ | «منداڵی زیرەک» | دەستەواژەی ناوی |

**تێبینی:** «قوتابییەکە خوێند» هەم ڕستەیە و هەم پێڕستەیەکی سەربەخۆ؛ ئەم دوو ئاستە نابێت وەک دوو پۆلی دژبەیەک پیشان بدرێن.

## ٣. ڕاهێنانی دووەم — دۆزینەوەی پێڕستەکان
1. «کەژیار هات.» — یەک پێڕستەی سەربەخۆ.
2. «کاتێک باران باری، ئێمە گەڕاینەوە.» — «کاتێک باران باری» پێڕستەی پشتبەستەی کاتی؛ «ئێمە گەڕاینەوە» سەربەخۆ.
3. «من دەزانم کە تۆ خوێندنت تەواو کردووە.» — «من دەزانم» سەرڕستە؛ «کە تۆ خوێندنت تەواو کردووە» پێڕستەی پشتبەستەی تەواوکەری ناوەڕۆکی زانین. ئەمە نابێت بە پێڕستەی هۆکاری یان کاتی تێکەڵ بکرێت.
4. «ئەگەر کاتمان هەبێت، سەردانی کتێبخانە دەکەین.» — پێڕستەی مەرجی پشتبەستە + پێڕستەی سەربەخۆ.

## ٤. ڕاهێنانی سێیەم — سەربەخۆ یان پشتبەستە؟
| نموونە | وەڵامی پێشنیارکراو |
|---|---|
| «کەژیار کتێبەکەی خوێندەوە.» | سەربەخۆ |
| «چونکە کاتمان نەبوو.» | پشتبەستە |
| «ئەگەر مامۆستا بگات.» | پشتبەستە |
| «وانەکە دەستی پێکرد.» | سەربەخۆ |

تێبینی: «چونکە» پێڕستەکە لە پەیوەندیی گوتاردا پشتبەستە دەکات؛ سەربەخۆیی پێڕستە لە ئاستی پێکهاتە و پەیوەندیی واتایی جیاوازە.

## ٥. ڕاهێنانی چوارەم — دروستکردنی ڕستە
ئەم ڕاهێنانە کراوەیە و پێویستی بە ڕێنمایی هەڵسەنگاندن هەیە:
- پێڕستەی سەربەخۆ بە تەنیا دەربڕینێکی تەواو پێکبهێنێت.
- پێڕستەی پشتبەستە بە پێڕستەیەکی دیکەوە پەیوەندیی ڕێزمانی/واتایی هەبێت.
- ڕستەی کۆتایی هەردووکیان بە شێوەیەکی سروشتی و بە ئامرازی گونجاو پێکەوە ببەستێت.

## ٦. خاڵە زانستییەکان
- پێناسەی پێڕستە نابێت بە «هەر کردارێک = یەک پێڕستە» سادە بکرێتەوە؛ پێکهاتە و پەیوەندییەکانی دەبێت بپشکنرێن.
- لە «من دەزانم کە تۆ خوێندنت تەواو کردووە» پێڕستەی تەواوکەری ناوەڕۆکی زانین جیاوازە لە پێڕستەی کاتی، هۆکاری و مەرجی.
- ڕستە و پێڕستە بە پێی ئاستی شیکاری پێناسە بکرێن؛ ڕستە دەتوانێت یەک یان چەند پێڕستە لەخۆ بگرێت.
- فۆڕمی کردار و ئەرکی جێناوی لکاو دەبێت لەگەڵ وانەکانی پێشوو یەکسان بێت.

## ٧. بڕیاری پشکنین
چوار ڕاهێنانی وانەی ٣٢ پشکنران؛ بۆ ڕاهێنانەکانی ١–٣ وەڵامی پێشنیارکراو دیاری کرا، ڕاهێنانی ٤ پێویستی بە rubric هەیە. لە بەڵگەی بەردەستدا کلیلی وەڵامی تەواوی وانەکانی ٣٣–٣٨ نییە؛ نابێت بە گریمانە دروست بکرێت. هیچ دەقی خاو، JSON، runtime، DB، .env، Botkeep، PR یان branchی چالاک نەگۆڕدراوە.
