**بەروار:** 2026-11-08  
**برانچ:** `feat/course4-clean-port-main-20261106`  
**جۆری بەڵگە:** تۆماری کۆکردنەوەی پشکنینە پێشوەکان؛ نەک دەقی وانەی نوێ، نەک پەسەندکردنی وانەکان، نەک گۆڕینی runtime.

## ١. ئامانج و سنوور
ئەم بەڵگەنامەیە ئەنجامی پشکنینەکانی وانەکانی ١–١٨، ١٩–٣١ و ٣٢–٤٦ لە یەک شوێندا کۆدەکاتەوە. بنەمای کار پاراستنی دەقی خاو، جیاکردنەوەی ئاستی مۆرفۆلۆژی و سینتاکس و پراگماتیک، و دیاریکردنی خاڵە پێویستەکان بۆ پشکنینی زیاترە.

ئەم تۆمارە بەڵگەی پشکنینی وشە بە وشەی هەموو دەقی خاو نییە. لە بەشێک لە وانەکانی ١–٣١ پشکنین لەسەر JSON/metadata و کویزەکانە؛ لە وانەکانی ٣٢–٤٦یش جۆری بەڵگە و تەواوی دەقی سەرچاوە لە وانەیەکەوە بۆ وانەیەکی تر جیاوازە. ئەوەی سەرچاوەی تەواوی نەدۆزرایەوە بە «پێویستی بە بەڵگەی زیاتر» دەمێنێتەوە، نەک بە «سڕاوەتەوە».

## ٢. دۆخی پشکنینی ساختاری
| بەش | چالاکی | ڕاهێنان | پرسیاری تێگەیشتن | کویز | دۆخی پشتڕاستکردنەوە |
|---|---:|---:|---:|---:|---|
| وانەکانی ١–١٨ | ٥٤ | ٩٠ | ١٨٠ | ١٤٤ | هەموو answer index ـەکانی کویز لە سنووری هەڵبژاردەکاندا؛ exercise answer key لەو JSON ـەدا نەبوو |
| وانەکانی ١٩–٣١ | ٣٩ | ٦٥ | ١٣٠ | ١٠٤ | هەموو answer index ـەکان لە سنووری هەڵبژاردەکاندا |
| وانەکانی ٣٢–٤٦ | بە پێی سەرچاوە و ترانسکریپت | بە پێی سەرچاوە | بە پێی سەرچاوە | پشکنینی بابەتی/زاراوەیی | پشکنینی وردی وانەکان بە بەڵگەی جیاواز؛ هەموو وانەکان یەکسان بە runtime تۆمار نەکراون |

**کۆی بەشی ساختاریی پشتڕاستکراو بۆ وانەکانی ١–٣١:** ٩٣ چالاکی، ١٥٥ ڕاهێنان، ٣١٠ پرسیاری تێگەیشتن و ٢٤٨ کویز. ئەم ژمارانە تەنها بۆ داتای JSON ـی برانچی پشکنراون و بە مانای پەسەندکردنی زانستیی هەموو پرسیار و وەڵامەکان نین.

## ٣. بنەمای یەکسانیی زاراوە و جیاوازیی چەمک
ئەم جیاوازییانە دەبێت لە هەموو وانەکاندا بپارێزرێن:

| چەمک | جیاوازیی پێویست |
|---|---|
| پۆلی وشە / ئەرکی ڕستەیی | Noun, adjective, adverb و pronoun پۆلی وشەن؛ subject, object, complement و adjunct ئەرک/پێکهاتەی ڕستەیین |
| بکەر / ئەنجامدەری کردار | بکەر = Subject (ئەرکی ڕێزمانی)؛ ئەنجامدەری کردار = Agent (ڕۆڵی واتایی) |
| بەرکار / تەواوکەر | بەرکار ئەرکێکی دیاریکراوە؛ تەواوکەر چەمکێکی فراوانترە و نابێت هەر گرێی پێشگر‌دار بە بەرکار ناوبنرێت |
| تەواوکەر / هاوەڵکاری | پێویستی/هەڵبژاردنی کردار و پێکهاتە لە زانیاریی زیادە و هەڵبژێردراو جیا بکرێتەوە |
| کاری تێپەڕ/تێنەپەڕ | لە active/passive جیاوازن؛ پێوەری تێپەڕی بە پێکهاتە و هەڵبژاردنی کردار پەیوەستە |
| چالاک/نەچالاک | لە تێپەڕ/تێنەپەڕ جیاوازن؛ ڕستەی نەچالاک بە خۆکارانە تێنەپەڕ نییە |
| بابەتکردن / جەختکردن | Topicalization و Focus دوو چەمکی پەیوەستن بەڵام یەک نین |
| بابەتی ڕستە / بابەتی گوتار | Grammatical subject لە Discourse topic جیا بکرێتەوە |
| ڕستە / پێڕستە | Sentence لە Clause جیا بێت؛ لە وانەکانی ٣٢–٣٨ و ٤٦دا بە ئاستی جیا شیکاری دەکرێن |
| سەربەخۆ/پشتبەستە؛ سەرڕستە/بەرڕستە | Independent/dependent لە Main/subordinate بە پێناسە و ئاستی شیکاری جیاوازن |
| سادە/لێکدراو | هەمیشە ئاستی شیکاری دیاری بکرێت: ڕستەی سادە/لێکدراو یان کرداری سادە/لێکدراو |
| پێشبەند / گرێی پێشبەندی | Preposition یەکەیە؛ Prepositional phrase گرێیەکەیە کە پێشبەند تێیدایە |
| ئامرازی پەیوەندی / پارتیکڵ / لکاو | ئەمانە ناوی یەک پۆل نین؛ فۆڕمی هاوشێوە بە ئەرک و سیاق پۆلێن دەکرێت |
| بانگکردن / سەرسووڕمان | Vocative لە Interjection و Exclamation جیا بکرێتەوە |
| جێناوی لکاو / نیشانەی خاوەندارێتی / نیشانەی ڕێکەوتن | فۆڕمی دەرەکی بە تەنها ئەرک دیاری ناکات؛ پێکهاتە و سیاق پێوەرن |
| چاوگ / ڕەگ / بنج / بنەما | Infinitive, root, stem/base و word بە یەکدی ناگۆڕدرێن |
| وشەداڕێژ / وشەگەردان | Derivation لێکسیەمی نوێ دروست دەکات؛ inflection فۆڕمی ڕێزمانیی هەمان لێکسیەم دەگۆڕێت |
| دەم / ڕووی کردار / ڕەوشی کردار | Tense, aspect و mood سێ ئاستی جیاوازن |

## ٤. خاڵە پێشەنگەکانی پشکنین و چاکسازی
### A — پێشەنگیی بەرز: کاریگەری لەسەر مانا و وەڵامی ڕاهێنان
1. **وانەی ١٢ و ١٨:** سیاقی «ـیان» و «ـی» بۆ جیاکردنەوەی خاوەنداری، بکەر و نیشانەی کردار پێویستە تەواو بێت.
2. **وانەی ١٥–١٧:** ڕابردووی بەردەوام لە عادەتی جیا بکرێتەوە؛ شیکردنەوەی «دەکەم» و «ـن» بە پارادایمی کردار پشتڕاست بکرێتەوە.
3. **وانەی ٢٥:** ئیزافەی کراوە/داخراو و فۆڕمی «ی» بە بەڵگەی مۆرفۆسینتاکسی و دیالێکتی دیاریکراو پشکنرێن؛ «ـەکە» بە تەنها بەڵگە نییە.
4. **وانەی ٣١:** grammatical subject لە discourse topic جیا بکرێتەوە؛ ئیزافەی «ـی» لە خاوەنداریی «ـمان» جیا بێت.
5. **وانەی ٣٩–٤٠:** پێناسەی بەرکاری ناڕاستەوخۆ لەگەڵ وەرگر/تەواوکەری پێشگر ڕوون بکرێتەوە؛ لە «ئەو نان خوارد»دا کردارە فەرهەنگییەکان لە بەرکاری ڕاستەوخۆ جیا بکرێنەوە.
6. **وانەی ٤٢–٤٣:** فۆڕمەکانی جێناوی لکاو تەنها بە سیاق و پارادایم شیکاری بکرێن؛ نموونەی ناتەواو بە یاسای گشتی پێشکەش نەکرێت.
7. **وانەی ٤٥:** گواستنەوەی بەرکار لەگەڵ مۆرفۆلۆژیی کردار و جێناوی لکاو هاوتا بێت؛ بابەتکردن لە جەخت جیا بێت.

### B — پێشەنگیی مامناوەند: یەکسانیی زاراوە و پێناسە
1. وانەکانی ١–٢: «پۆلی وشە»، «بەشی ئاخاوتن»، «پریپۆزیشن»، «ئامرازی پەیوەندی» و «پارتیکڵ» بە یەکدی تێکەڵ نەکرێن.
2. وانەکانی ٦–٨: هاوەڵناو، هاوەڵکار و دیارخەر؛ هەروەها پلەی بەراورد و جەخت جیا بکرێنەوە.
3. وانەکانی ١٩–٢١: هاوەڵکار لە گرێی پێشبەندیی بە ئەرکی هاوەڵکاری جیا بێت؛ داڕشتنی «بەـ» بە نووسینی پێکەوە/جیا بە تەنها پۆلێن نەکرێت.
4. وانەکانی ٢٢–٢٤: پێشبەند، ئامرازی پەیوەندی و بانگکردن؛ فۆڕمی هاوشێوە بە ئەرکی خۆی شیکاری بکرێت.
5. وانەکانی ٢٦–٢٧: discourse particle، clitic، interjection، vocative و exclamation لە یەکتر جیا بکرێنەوە.
6. وانەکانی ٢٨–٣٠: چاوگ و بنج بە پارادایمی تەواو پشتڕاست بکرێنەوە؛ کردارە سووکەکان تەنها بە بوونی ناو + «کردن» دیاری نەکرێن.
7. وانەکانی ٣٢–٣٨ و ٤٦: Sentence/Clause، چوار جۆری ڕستە، independent/dependent و main/subordinate بە دوو ئاستی پێناسە بکرێن؛ ناکۆکیی ناونیشان و پۆلێنی وانەی ٣٧ و ٤٦ پێویستی بە بڕیاری خاوەن پڕۆژە هەیە.

### C — پێشەنگیی بەڵگەی سەرچاوە
1. نموونە و بانگەشەکانی وانەی ٣ لەبارەی دەنگ، دووپاتەکردن و پاشگرەکان.
2. پێکهاتە و بەرهەمهێنیی نموونەکانی وانەی ٧.
3. جیاوازیی هەزار/دووشەممە لە ئاستی هاوچەرخ و مێژوویی لە وانەی ٩.
4. فۆڕمەکانی «گرتمن»، «گرتمی»، «گرتنی» و هاوشێوەکانیان بە زار و سیاق.
5. لیستی «یی خستنەپاڵ» و جۆرەکانی لە وانەی ٢٥؛ تا دەقی سەرچاوە و پێناسەی تەواو نەبێت، پێناسەی خەمڵێنراو دروست نەکرێت.
6. هەر نموونەی دیالێکتی لە وانەکانی ٢٤–٢٥ و ٤٢–٤٣ بە زار/شێوەزاری خۆی سنووردار بکرێت.

## ٥. بەراورد لەگەڵ کتێبی «وشەناسیی زمانی کوردی»
کتێبی سەعید کەرەمی سەرچاوەی بەراوردی مۆرفۆلۆژییە؛ بابەتەکانی مۆرفیم/مۆرف/شێوەمۆرف، بنەما و بنەچەوشە، وشەسازی، گیرەکی وشەداڕێژ و وشەگەردان، گەردانی کردار و ناو و ڕیزبەندیی مۆرفیمەکان لەخۆدەگرێت. نابێت وەک سەرچاوەی یەکلاکەرەوە بۆ پێناسەی بەرکار، تەواوکەر، جۆرەکانی ڕستە، بابەتکردن و جەخت بەکاربهێنرێت.

بابەتە پێشنیارکراوەکانی کتێب کە پێویستیان بە پشکنینی دووبارەکاری لەگەڵ وانەکانی ١–٣١ هەیە:
- مۆرفیم، مۆرف و شێوەمۆرف.
- جیاوازیی ڕەگ، بناغە، بنەچەوشە، لێکسیەم و وشە.
- گیرەکی وشەداڕێژ و وشەگەردان.
- پێڕەوەکانی وشەسازی: گیرەک‌لکاندن، لێکدان، دووپاتەکردن، بزوێنگۆڕین و ڕاگوێزان.
- بەرهەمهێنی و سنوورەکانی.
- گەردانی ناو و هاوەڵناو.
- گۆڕینی توانای کردار (valency change).
- ڕیزبەندیی مۆرفیم لە کردار.

**بڕیار:** تا پشکنینی بابەت بە بابەت لەگەڵ وانەکانی ١–٣١ تەواو نەبێت، هیچ وانەی نوێی ٤٧+ زیاد نەکرێت. هەر بابەتێک ئەگەر لە وانەیەکی ئێستادا هەبێت، تەنها پاشکۆی ڕوونکەرەوەی پێویست بۆی دروست بکرێت؛ ئەگەر بە تەواوی نەبوو، پاشان پێشنیاری وانەی نوێ بکرێت.

## ٦. دۆخی سەرچاوە و سنووری دڵنیایی
- وانەکانی ١–٣١ لە JSON ـی برانچی پشکنراودا هەن، بەڵام ئەمە بەڵگەی runtimeی چالاکی ئەمڕۆ نییە؛ دۆخی برانچ و manifest دەبێت جیا بخوێندرێتەوە.
- بۆ وانەکانی ٣٢–٣٨، فایلێکی ئەرشیفی سەرچاوە و پلانی دابەشکردن هەیە؛ هەموو وانەکان دەقی خاوەنی تەواویان نییە.
- بۆ وانەکانی ٣٩–٤٥، ترانسکریپتی سەرچاوە هەیە؛ بەڵام هەموو WritingBlock ـە مێژووییەکان وەک فایلەی سەربەخۆ پشتڕاست نەکراونەتەوە.
- بۆ وانەی ٤٦، دەقی خاوەن پڕۆژە و پێشنیاری جیاواز پارێزراون؛ پێشنیار بە وانەی پەسەندکراو ناژمێردرێت.
- هیچ خاڵێکی نادۆزرایەوە بە سڕینەوە یان لەناوچوون لێک نەدرێتەوە.

## ٧. ڕیزبەندیی کارەکانی داهاتوو
1. پشکنینی وردی answer key و ڕوونکردنەوەی وەڵامەکانی وانەکانی ١–٣١، بە تایبەتی ١٢، ١٤، ١٥، ١٨ و ٢٥.
2. پشکنینی نموونە و وەڵامەکانی وانەکانی ٣٢–٣٨، بە تایبەتی بکەر/نیهاد و جۆرەکانی ڕستە.
3. چارەسەری کێشەی کلیلی وەڵامی وانەی ٤٠ و فۆڕمەکانی ٤٢–٤٣.
4. هاوتاکردنی پۆلێنی ڕستەی وانەی ٣٧ لەگەڵ وانەی ٤٦.
5. پشکنینی بابەتە مۆرفۆلۆژییەکانی کتێبی سەعید کەرەمی لەگەڵ وانەکانی ١–٣١ بۆ دیاریکردنی بابەتی نوێی ڕاستەقینە.
6. دوای ئەوە، تۆماری کۆتاییی زاراوە و تاقیکردنەوەی regression بۆ هەموو زنجیرەکە ئامادە بکرێت.

## ٨. پاراستن
- ئەم فایلە تەنها پاشکۆی کۆکردنەوەی پشکنینە.
- دەقی خاو، JSON، کویز و answer key نەگۆڕدراون.
- هیچ وانەیەک پەسەندکراو یان runtime-ready ناژمێردرێت.
- هیچ merge، deploy، Botkeep Sync/Restart، migration، دەستکاریی DB یان `.env` ئەنجام نەدراوە.
