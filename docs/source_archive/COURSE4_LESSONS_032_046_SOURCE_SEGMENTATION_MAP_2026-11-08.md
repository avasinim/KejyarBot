## ٥. کێشە و پێویستییەکانی پشکنین

- بکەر و نیهاد نابێت بەبێ ڕوونکردنەوە وەک یەک زاراوە بەکاربهێنرێن.
- بکەر هەمیشە ئەنجامدەری کردار نییە.
- کاری بەستەر و شێوەکانی «ـە»، «بوو» و «دەبێت» دەبێت لە پێکهاتە و واتای جیاوازدا شیکاری بکرێن.

- «بۆیە»، «کەوایە» و «هێشتا» نابێت بەبێ شیکاریی ئەرکی ڕێزمانی هەموویان بە هاولکی پۆلێن بکرێن.

## ٦. یاسای پاراستن و جێبەجێکردن

1. هیچ دەقی خاو لە فایلە سەرچاوەکاندا overwrite ناکرێت.
2. ڕەشنووسی یارمەتیدەر و پاشکۆی پشکنین لە دەقی خاو جیا دەکرێنەوە.
3. هەر وانەیەک پێش runtime پێویستی بە دەقی تەواو، ئامانج، نموونە، ڕاهێنان، کلیلی وەڵام، پشکنینی زاراوە و پشکنینی schema هەیە.
4. هیچ وانەیەک بە تەنیا بەهۆی بوونی ڕەشنووسەوە پەسەندکراو ناژمێردرێت.
5. ئەم نەخشەیە تەنها بەڵگە و ڕێکخستنی سەرچاوەیە؛ هیچ JSON، manifest، DB، `.env`، Botkeep، Sync، Merge، Deploy، Restart یان Migration ناگۆڕێت.
