## ٤. کێشە و پێویستییەکانی هەر وانەیەک

- **٣٢:** سەرچاوەکە بابەتە جیاوازەکان لە ژێر یەک سەردێڕ کۆکردووەتەوە؛ دابەشکردنی ٣٢–٣٦ بە پێی پلانی دواترە، نەک سەردێڕەکانی سەرچاوەی سەرەتایی.
- **٣٣:** ناوی نموونەکان لە سەرچاوەدا ناکۆکن (ئاڕگەش/سابیر، کەژیار/شیرین، فەرزانە/نەسرین). بڕیاری خاوەن پڕۆژە بۆ یەکسانکردنی ناوەکان تەنها لە پاشکۆ و پێشنیارەکان جێبەجێ کراوە؛ دەقی خاو وەک خۆی ماوەتەوە.
- **٣٤:** Subject/بکەر و Predicate/گوزارە نابێت بە خۆکار یەکسان بکرێن بە «نیهاد» و «گوزارە» بەبێ دیاریکردنی ڕێبازی شیکاری؛ کاری بەستەر و واتای `دەبێت` لە پێکهاتە جیاوازەکاندا پشکنین دەوێت.
- **٣٥:** پۆلێنی دەربڕین لە پۆلێنی پێکهاتە جیاوازە؛ هێمای کۆتایی بە تەنیا پێناسەی جۆری ڕستە نییە.
- **٣٦:** هەموو وشەیەکی دەرەوەی بکەر و کار تەواوکەر نییە؛ دەبێت تەواوکەری ناو، تەواوکەری کردار، سیفەت و هاوەڵکار جیا بکرێنەوە.
- **٣٧–٣٨:** دەقی زیادەی خاو بە جیاوازی لە ڕەشنووس و پشکنین پارێزراوە؛ پێویستە شیکاریی پێڕستە، سەرڕستە، بەرڕستە و ئامرازەکان یەکسان بکرێت.
- **٣٩–٤٥:** ترانسکریپتی تەواوی وانەکان هەیە، بەڵام هەندێک کلیلی وەڵام و فۆڕمی نموونەکان پێویستی بە بڕیاری زانستی هەیە.
- **٤٦:** دەقی خاو هەیە؛ وەشانی پێشنیارکراو بە پەسەندکراوی runtime ناژمێردرێت.

## ٥. یاسای دابەشکردن و پاراستن

1. هیچ دەقی خاو لە فایلەکانی سەرچاوەدا دەستکاری یان overwrite ناکرێت.
2. دابەشکردنی وانەکان دەبێت لە فایلە نوێکانی staging یان لە ماتریسی پەیوەندی تۆمار بکرێت؛ سەرچاوەی خاو وەک بەڵگەی بنەڕەت دەمێنێتەوە.
3. دەقی خاو، ڕەشنووسی یارمەتیدەر، پاشکۆی پشکنین و وەشانی پەسەندکراوی وانە چوار دۆخی جیاوازن.
4. هەر وانەیەک پێش چوونە ناو runtime پێویستی بە ناونیشان، دەقی تەواو، ئامانج، نموونە، ڕاهێنان، کلیلی وەڵام، پشکنینی زاراوە و پشکنینی schema هەیە.
5. ئەم نەخشەیە هیچ وانەیەک پەسەند ناکات و هیچ داتای runtime ناگۆڕێت.
