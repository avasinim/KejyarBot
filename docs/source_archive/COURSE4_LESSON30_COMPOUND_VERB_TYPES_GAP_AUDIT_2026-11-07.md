# کۆرسی ٤ — پشکنینی جۆرەکانی پێکهاتەی چاوگی لێکدراو لە وانەی ٣٠
**بەروار:** 2026-11-07  
**لق:** `feat/course4-clean-port-main-20261106`  
**بنەمای پشکنین:** runtime JSONی وانەی ٣٠، SHA `4789a3c969786acd144cea528db2c4c57d9353ac`، و ئەو زانیارییەی لە ماددەی خاوەن پڕۆژەدا لەبارەی جۆرەکانی پێکهاتەی چاوگی لێکدراو پارێزراوە.

## ١. ئەنجامی گشتی

وانەی ٣٠ پێکهاتەی کردارە لێکدراوەکان و کردارە سووکەکان دەگرێتەوە و لە runtimeدا ١٤ خاڵی سەرەکی، ٨ نموونە، ٣ چالاکی، ٥ ڕاهێنان، ١٠ دانەی تێگەیشتن/کورتە و ٨ پرسیاری کویزی هەیە.

لە وانەکەدا ئەم پێکهاتانە بە ڕوونی هەن:
- ناو + کردار/کرداری سووک (N+LV)
- هاوەڵناو + کردار/کرداری سووک (Adj+LV)
- هاوەڵکار + کردار (Adv+V)
- گروپی پێشبەندی + کردار (PP+V)
- پارتیکڵی پێش کردار + کردار (PREV+V)، بە تێبینیی جیاوازیی ڕێبازە زانستییەکان

بەڵام ماددەی خاوەن پڕۆژە باس لە «١٩ جۆری پێکهاتە» دەکات؛ لە زانیاریی بەردەستدا هەندێک جۆری دیکەش ناویان هاتووە، وەک:
- ئامراز/هاواری سەرسووڕمان + چاوگ/کردار
- پارتیکڵی ئارەزوو/داوا + چاوگ/کردار
- دووبارەکردنەوە/فۆڕمی دووبارەکراو + چاوگ/کردار

ئەم سێ جۆرە لە خاڵە سەرەکی و نموونەکانی runtimeی وانەی ٣٠دا بە شێوەیەکی دیار و سەربەخۆ نەهاتوون. لەبەر ئەوە، لە ئێستادا ناتوانرێت بانگەشە بکرێت کە هەموو ١٩ جۆرەکە لە وانەی ٣٠دا جێگیر کراون.

## ٢. خشتەی هاوتاییی پێکهاتەکان

| جۆری پێکهاتە | دۆخی لە وانەی ٣٠ | نموونە/بەڵگەی runtime | بڕیاری پشکنین |
|---|---|---|---|
| ناو + کردار (N+V/N+LV) | هەیە | شەڕکردن، بەڵێن دان، ئیستقالە دان | هاوتاییی ڕاستەوخۆ |
| هاوەڵناو + کردار (Adj+V/LV) | هەیە | ئامادەکردن، توندکردن | هاوتاییی ڕاستەوخۆ |
| هاوەڵکار + کردار (Adv+V) | هەیە | درەنگ کەوتن | هاوتاییی ڕاستەوخۆ |
| گروپی پێشبەندی + کردار (PP+V/LV) | هەیە | لە دەستدان، لە دایک بوون | هاوتاییی ڕاستەوخۆ |
| پارتیکڵی پێش کردار + کردار (PREV+V) | هەیە | ڕاکردن؛ هەڵکردن لە خاڵی سەرەکی | هەیە، بەڵام پۆلێنکردنەکە ڕێباز-پەیوەستە |

| دووبارەکردنەوە + کردار | لە runtimeدا دیار نییە | نموونەی پشکنراوی runtime نییە | پێویست بە دەقی خام و نموونە |

**گرنگ:** ئەم خشتەیە بانگەشە ناکات کە لیستی ١٩ جۆرەکە تەنها ئەو سێ جۆرەیەی سەرەوەی تێدایە؛ ئەوانە تەنها ئەو جۆرانەن کە لە زانیاریی پارێزراوی ماددەی سەرچاوەدا بە ناویان ئاماژەیان پێدراوە. بۆ پشکنینی تەواوی ١٩ جۆرەکە دەقی تەواوی ئەو بەشە پێویستە.

## ٣. جیاوازیی پێویست لە نێوان «چاوگی لێکدراو» و «کرداری لێکدراو»

لە ماددەی خاوەن پڕۆژەدا هەندێک جار ناوی «چاوگی لێکدراو» بەکارهاتووە؛ لە runtimeی وانەی ٣٠دا چوارچێوەی سەرەکی «کرداری لێکدراو/پێکهاتەی کرداری ئاڵۆز» و «NV+LV» ـە.

پێویستە ئەم جیاوازییە لە پاشکۆدا ڕوون بکرێتەوە:
1. چاوگ فۆڕمی فەرهەنگیی کردارە؛
2. پێکهاتەی کرداری ئاڵۆز لە بەشێکی ناوکرداری/ناکرداری و کردارێک پێکدێت؛
3. پێکهاتەکە دەتوانێت لە فۆڕمی چاوگدا پیشان بدرێت، بەڵام ئەمە بە مانای ئەوە نییە کە هەموو جۆرەکانی پێکهاتەکە «جۆری چاوگ» بن؛
4. پێویستە جۆری پێکهاتە لە ڕووی پۆلی وشە، ئەرکی LV، پەیوەندیی واتایی و ڕێنووس جیا دیاری بکرێت.

## ٤. نموونەکان و سنووری بەڵگە

لە runtimeدا نموونەکانی «شەڕکردن»، «ئامادەکردن»، «بەڵێن دان»، «ئیستقالە دان»، «لە دەستدان»، «لە دایک بوون»، «درەنگ کەوتن» و «ڕاکردن» هەن. هەروەها لە ماددەی سەرچاوەدا نموونەکانی «یارمەتیدان»، «دەستگرتن»، «لەناوبردن»، «دڵخۆشکردن»، «جوانکردن» و «کردن» بە شێوەی جیاواز ئاماژەیان پێدراوە.

بەڵام:
- هەموو ئەم نموونانە بە خۆکارانە لە یەک پۆلی NV+LVدا دانانرێن.
- «کردن» لە پێکهاتەی داڕێژراو و لە پێکهاتەی کرداری سووکدا دەکرێت ڕۆڵی جیاواز هەبێت.
- پێشگر/پارتیکڵی کردار نابێت بەبێ تێبینیی تیۆری لەگەڵ گروپی پێشبەندی یەک بگیرێت.
- جیاوازیی نووسینی پێکەوە، جیا، یان بە بۆشایی بە تەنها پۆلێنکردنی مۆرفۆلۆژی دیاری ناکات.

## ٥. کێشە و هەنگاوی پێویست

1. دەقی تەواوی ئەو بەشەی ماددەی خاوەن پڕۆژە کە ١٩ جۆرەکە دەژمێرێت، دەبێت بە وشەبەوشە بپارێزرێت و بۆ پشکنینی هەر خاڵێک بەکاربهێنرێت.
2. بۆ هەر جۆرێک: ناوی پێکهاتە، نموونەی خام، دابەشکردنی پێکهاتە، واتا، جۆری LV، و سەرچاوە/بەڵگە تۆمار بکرێت.
3. ئەو جۆرانەی بەڵگەی ئەکادیمییان نییە، لە پاشکۆدا بە «نموونەی سەرچاوەی خاوەن پڕۆژە/پێویست بە پشتڕاستکردنەوە» نیشان بدرێن؛ نەک وەک یاسای گشتی وانە بدرێن.
4. ئەگەر جۆرێک لە وانەی ٣٠دا نییە و بەڵگەی پێویستی هەیە، تەنها پاشکۆی وانەکە پڕ بکرێتەوە؛ بڕیاری گۆڕینی runtime یان زیادکردنی خاڵی سەرەکی بۆ دواتر و بە ڕێککەوتنی خاوەن پڕۆژە بهێڵدرێتەوە.
5. دەقی پچڕاوی سەرچاوە لە «تەواوکەری بەیاریدە...»دا بە خەمڵاندن تەواو نەکرێتەوە.

## ٦. بڕیاری ئێستا

- وانەی ٣٠ لە runtimeدا بە شێوەی ئێستا دەمێنێتەوە؛ هیچ گۆڕانکارییەکی runtime نەکراوە.
- جۆرەکانی بەڵگەدار لە خشتەکەدا وەک هاوتاییی ڕاستەوخۆ تۆمار کراون.
- جۆرەکانی ئامراز/هاوار، پارتیکڵی ئارەزوو و دووبارەکردنەوە وەک بۆشاییی پشکنین تۆمار کراون؛ ئەمە بە مانای هەڵەبوونیان نییە، بەڵکو بە مانای نەبوونی بەڵگەی تەواویان لە runtimeی ئێستادا.
- تا دەقی تەواوی لیستی ١٩ جۆرەکە بەردەست نەبێت، نابێت خشتەیەکی ١٩ دانەیی بە خەمڵاندن دروست بکرێت.
- هیچ دەقی وانە، نموونە، چالاکی، ڕاهێنان، پرسیار، کویز، داتابەیس یان deployment دەستکاری نەکراوە.

## ٧. هەنگاوی داهاتوو

کاتێک دەقی تەواوی لیستی ١٩ جۆرەکە لە ماددەی خامی خاوەن پڕۆژەدا لەبەردەست بێت، پشکنینی ١٩/١٩ بە خشتەی ورد تەواو دەکرێت. تا ئەو کاتە، ئەم بەڵگەنامەیە وەک پشکنینی سنوورداری هاوتایی دەمێنێتەوە، نەک وەک پشتڕاستکردنەوەی تەواوی ١٩ جۆرەکە.
