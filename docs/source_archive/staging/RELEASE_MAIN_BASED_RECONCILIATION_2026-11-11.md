## ٩.٥٢. پشکنینی collisionی زاراوە لە نێوان پەچەکان و runtime — 2026-11-11

### سنووری بەراورد
پەچەکانی Library بۆ وانەکانی ١١، ١٢، ١٣، ٢٦، ٢٩ و٣١-v2 بەراورد کران لەگەڵ Preservation Bundleی 2026-11-08 و runtimeی ٥٠ وانەیی. ئەم auditە پشکنینی consistencyی زاراوەییە؛ بڕیاری زانستی لەسەر یەکێک لە فۆڕمەکان نادات.

### Collisionە پشتڕاستکراوەکان
1. **Enclitic — وانەکانی ١١، ١٢، ١٣:** پەچەکانی ١١ و١٣ لە پاشکۆدا `Enclitic = پاشبەستە` بەکار دەهێنن؛ پەچی ١٢ و runtimeی سەرچاوەیییش `پاشبەستە`یان تۆمار کردووە. بەڵام runtimeی ئێستا لە پاشکۆی وانەکانی ١١ و١٢ و١٣دا `پاشنووس`ی داناوە. ئەگەر پەچەکان دواتر append بکرێن، هەردوو فۆڕمەکە لە یەک کۆرسدا دەردەکەون، مەگەر glossary/crosswalkێکی فەرمی هەبێت.
2. **Affix — وانەکانی ١٣ و٢٦:** پەچی ١٣ لە زاراوەنامەی خۆیدا `Affix = ئەفیکس` دەنووسێت؛ runtimeی ئێستا لە پاشکۆی وانەی ١٣ و٢٦دا `گیرەک` بەکار دەهێنێت. ئەم گۆڕانە پێویستی بە یەکسانکردنی زاراوەنامە و ڕوونکردنەوەی پەیوەندیی Affix/Prefix/Suffix هەیە؛ هیچ یەک لە دوو فۆڕمەکە لەم auditەدا پەسەند نەکرا.
3. **Inflection — وانەکانی ٢٩ و٣٠:** Preservation Bundle و patchی ٢٩ `لەچۆنایەتی (Inflection)`یان هەیە؛ runtimeی ئێستا لە وانەی ٢٩ و٣٠دا `گەردان (Inflection)`ی بەکار هێناوە. ئەمە لە هەردوو وانەدا consistencyی ناوخۆییی runtimeی نوێترە، بەڵام پەچەکانی ئەرشیف هێشتا فۆڕمی پێشوویان هەیە.
4. **Noun Phrase — وانەی ٣١:** patchی ٣١-v2 لە پاشکۆی هاوتاییی زاراوە بە ڕوونی `Noun Phrase = گروپی ناوی` پێشنیار دەکات؛ runtimeی ئێستا لە ناو خاڵەکان، نموونەکان، comprehension و appendixدا `گرێی ناوی` بەکار دەهێنێت. ئەمە ناکۆکییەکی ڕاستەوخۆی نێوان پەچی ئەرشیف و runtimeە.
5. **وانەی ٢٦:** گۆڕینی `ئەفیکس` بۆ `گیرەک` لە citationی Ahmadi (2021)دا لە runtime هەیە؛ پەچی وانەی ٢٦ هەمان سەرچاوە وەک preprint ناساندووە و سنووری بەڵگەکەی پاراستووە. پێویستە لە glossaryدا فۆڕمی کوردی و English term بە یەک شێوە تۆمار بکرێن، نەک تەنها بە گۆڕینی وشە لە citationدا.
