## 2. Six-class taxonomy: consistent labels and scope

The lesson's closing summary and sections 2–7 consistently enumerate six course classes:

1. `rengdêrên wesfîn` — descriptive
2. `rengdêrên îşarkî` — demonstrative
3. `rengdêrên jmarîn` — numeral (cardinal and ordinal subtypes are discussed within this area)
4. `rengdêrên pirsiyarkî` — interrogative
5. `rengdêrên nebinavkirî` — indefinite
6. `rengdêrên xwemalîn` — possessive

The master register should retain these exact plural class headings as the course's preferred labels. Keep singular explanatory wording separate: `rengdêrê jmarîn` appears in the lesson prose, while quiz Q3 option A has `rengdêra jmarîn`. The latter remains a specific morphology/editorial query, not a proven error.

## 3. Four distinct analytical levels

The lesson and register should explicitly keep these apart:

- **Word class:** `rengdêr`, `pronav`, or `jmarnav`.
- **Subclass:** e.g. `wesfîn`, `îşarkî`, `jmarîn`, `pirsiyarkî`, `nebinavkirî`, `xwemalîn`; and the cardinal/ordinal distinction within numeral adjectives.
- **Syntactic function/use:** attributive modifier, predicative use, substantivized/independent use, or another sentence role.
- **Surface form:** the actual inflected form (e.g. `ev`, `vî`, `van`, `yê`, `yên`); form alone does not determine class or function.

The six classes are the course's teaching taxonomy, not six fixed form-to-category mappings valid in every sentence.

## 4. Boundary checks against the lesson examples

### Adjective vs independent pronoun

- `ev keçik`: `ev` accompanies an expressed noun; demonstrative adjective/modifier use.
- `Ev hat.`: `Ev` stands in place of a noun; demonstrative-pronoun use.
- `hespê min`: possessive element accompanies an expressed noun; possessive-adjective use in the course taxonomy.
- `yê min / yên min`: replaces an understood noun/group; possessive-pronoun use.
- `kîjan mirov` and `tu mirov`: attributive uses because the noun is expressed; independent uses must be classified from sentence context.
- `gelek`, `hemî`, and `çend`: the lesson itself says these can also function pronominally depending on sentence position/use. Do not assign a permanent category from the isolated token.

### Predicative and substantivized adjectives

The lesson's opening definition says an adjective “comes with the noun.” This is an adequate first explanation of attributive examples but too absolute if treated as a full definition. The recorded source review §§124–127 includes descriptive adjectives used predicatively and without an expressed noun. Recommendation: qualify the opening explanation as the common attributive use, then briefly note predicative and substantivized uses. This is an audit recommendation only.

### Numeral adjective vs `jmarnav`

Use the function test, not the numeral's shape:
- `sê mal`, `çar xanî`, `deh bizin`: numeral modifies an expressed noun → numeral-adjective use.
- `jmarnav`: numeral used independently/substantively in the course's adopted framework.
- `stûna çaran`, `a pêncan`, `ê heftan`: ordinal adjective examples; retain them within the numeral-adjective discussion and identify the ordinal subtype, not as an additional seventh top-level adjective class.
- A numeral may have different roles in different constructions; the same written form alone does not decide.

### Specific exercise item: `nîv roj`

The previous exercise rubric left this item unresolved. Reconciliation with the full lesson narrows the issue: the lesson explicitly discusses `nîv` in the `jmarnav` section and states that before a numeral or noun it retains the form `nîv`. Thus, under the lesson's own lexical taxonomy, the intended label is `jmarnav`; in `nîv roj`, its phrase-level function is to quantify/modify the expressed noun `roj`. The teacher key should name both levels rather than confusing a noun-modifying function with membership in the six adjective subclasses. This is a course-internal reading; any broader grammatical claim should still be checked by a Kurmanji editor.

### Specific exercise item: `kurên van`

The complete lesson explicitly places `kurên van` and `keçên wan` in the possessive-adjective example list. The prior rubric's concern that `van` could be read as an independent demonstrative/genitive possessor was too cautious as a default answer-key position when the exercise is keyed to the lesson's own section. Provisional course key: classify `van` as the possessive element under `xwemalîn` in the lesson's intended construction, with the noun `kur` expressed. Still ask a Kurmanji editor to confirm the idiomaticity and precise syntactic analysis before using it as a high-stakes diagnostic example. Do not reclassify it as `îşarkî` merely because the form resembles a demonstrative.
