# Latin Courses 1–2 — 24-lesson dependency matrix
Date: 2026-11-10
Branch: `archive/preservation-audit-2026-11-10`

## Method and limits

This matrix maps prerequisites, first-introduced concepts, previews, deliberate repetition, quiz coverage, and source traceability for all 24 reviewed lessons. It is based on the reviewed drafts and the existing source/quiz audit notes. It is a planning and traceability artifact, not a claim that every supplementary example has been collated against the printed book.

Legend:
- **Prerequisite** = concept learners should already know.
- **New** = principal concept introduced in this lesson.
- **Preview / return** = concept mentioned before its formal treatment or deliberately revisited.
- **Quiz** = main skill visibly or previously structurally mapped to the lesson quiz; not a fresh independent semantic revalidation.
- **Source status** = source scope currently established. Where exact per-lesson pagination was not rechecked in this pass, no page number is invented.

### Course 1 dependency observations

1. The core dependency chain is coherent: inventory → ordering/categories → vowel groups → targeted contrasts → remaining consonants → sound/letter synthesis → review.
2. Lesson 11 is an enrichment detour and should not be made a prerequisite for core alphabet competence.
3. Lesson 10 is placed late as synthesis, but its basic distinction should be foreshadowed earlier because Lessons 4–9 already discuss sounds.
4. Lessons 6–8 and 12 repeat earlier concepts productively if they test discrimination and application rather than mere recitation.
5. No lesson should silently convert Celadet's short/long vowel grouping into a universal statement about all Kurdish varieties.

### Course 2 dependency observations

1. Core chain is coherent: grammar building blocks → noun → gender/number/case → noun phrase marking → pronouns → adjective/numeral categories.
2. Lesson 6 is the main forward-reference point: `ev/ew` are noun modifiers there and demonstrative pronouns in Lesson 11. Add a cross-reference, not duplicated full teaching.
3. Lessons 7 and 8 should be explicitly paired as definite versus indefinite marking, while keeping both distinct from case inflection.
4. Lessons 9 and 10 are a tightly dependent pair. Lesson 10 should explicitly remind learners that pronoun role depends on clause structure.
5. Lesson 11 is broad and contains several internal categories; keep each subsection functionally distinct.
6. Lesson 12's breadth is a potential cognitive-load issue, but splitting it would affect lesson numbering and quiz mappings. No split is authorized or recommended until full dependency and assessment mapping is complete.
