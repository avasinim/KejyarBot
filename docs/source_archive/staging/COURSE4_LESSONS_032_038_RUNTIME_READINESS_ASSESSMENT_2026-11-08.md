## ٢. دەرئەنجامی سەرەکی
- وانەکانی ٣٢–٣٦ لە سەرچاوەیەکی هاوبەشەوە جیاکراونەتەوە؛ ئەمە بە مانای ئەوە نییە کە لە سەرەتاوە وەک پێنج فایل/وانەی سەربەخۆ نێردراون.
- وانەکانی ٣٧–٣٨ segmentی سەرچاوەی خاو هەیە و نابێت لەگەڵ ڕەشنووسە پەرەپێدراوەکان تێکەڵ بکرێن.
- قەبارەی دەقی خاو بە تەنیا پێوەری ئامادەبوونی وانە نییە؛ وانەی runtime دەبێت ئامانج، خاڵی فێرکاری، نموونە، ڕاهێنان و پشکنینی تاقیکردنەوەیی هەبێت.
- وانەی ٣٥ بە ڕوونی لە ڕووی مەبەستی دەربڕینەوە جیاوازە لە وانەی ٣٧ لە ڕووی پێکهاتەوە؛ ئەم جیاوازییە دەبێت لە ناوەڕۆک و پرسیارەکاندا بپارێزرێت.
- وانەی ٣٨ پێویستی بە هەماهەنگی لەگەڵ وانەی ٣٧ و ٤٦ هەیە؛ بڕیاری Compound/Complex و Clause/Subordinate Clause پێش پەسەندکردنی کۆتایی دیاری بکرێت.

## ٣. ڕیزبەندیی پەرەپێدانی پێشنیارکراو
1. **٣٢–٣٤:** یەکەم جار بنەمای پێکهاتەی ڕستە، Subject/Agent، Verb/Predicate و Copula ڕوون بکرێنەوە؛ چونکە وانەکانی ٣٩–٤٤ پشتیان پێ دەبەستن.
2. **٣٦:** دوای جێگیرکردنی Object/Complement/Adjunct چاک بکرێتەوە؛ چونکە وانەکانی ٣٩–٤٥ ئەم زاراوەیان بەکار دەهێنن.
3. **٣٥:** بە جیاوازیی ڕوون لە پۆلێنکردنی پێکهاتەی ڕستە پەرەی پێ بدرێت.
4. **٣٧–٣٨:** پێوەری clause و پۆلێنی compound/complex یەکسان بکرێت؛ نموونە شیعرییەکان وەک بەڵگەی دەقی خاو بپارێزرێن.
5. پاشان پشکنینی بەردەوامیی زاراوەکان لە ٣٩–٤٦ و دووبارەکردنەوەی کویز و وەڵامەکان.

## ٤. ڕێنماییی runtime
هیچ JSONی runtime بۆ ئەم وانانە دروست نەکراوە؛ چونکە شەش بڕیاری زاراوەیی هێشتا پەسەند نەکراون و دەقی وانەکان پێویستیان بە پەرەپێدان و پشکنینی خاوەن کۆرس هەیە. هەر draftێکی داهاتوو دەبێت بە فایلێکی جیاواز لە owner source هەڵبگیرێت.

## ٥. پاراستن
- هەموو حەوت segmentی خاو بە هەمان دەق و ڕیزبەندی ماونەتەوە.
- ئەم پاشکۆیە تەنها هەڵسەنگاندن و ڕیزبەندیی کارە؛ هیچ ناوەڕۆکێکی وانەکان ناگۆڕێت.
- هیچ manifest، runtime JSON، bot.py، database، Botkeep، environment، deployment یان restart نەگۆڕدراوە.
