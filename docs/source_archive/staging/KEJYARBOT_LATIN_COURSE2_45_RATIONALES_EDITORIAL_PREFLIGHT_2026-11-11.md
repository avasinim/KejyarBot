## Findings

### E1 — L2 Q2: tautological description (recommended wording refinement)

Current proposal: `hesp navê giştî yê heywanê hesp e`. The phrase repeats the lexical head `hesp` in a way that is circular and less useful to a learner. The source defines `hesp` as a common noun used for members of the horse category; the keyed answer C (hevenav) remains unchanged.

**Editorial alternative for native-editor review:**

> `Hesp` navê giştî ye ku ji bo heywanên vê cureyê tê bikaranîn; ji ber vê yekê hevenav e, ne serenavê kesek an tiştekî taybet.

This is a clarity refinement only; no answer/key or taxonomy change is implied.

### E2 — L11 Q2: the defining feature of “yên qerse” is not restated

Current proposal correctly preserves the source's label `pronavên îşarkî yên qerse` and distinguishes them from personal pronouns. However, it does not state the key contrast that the lesson itself gives: these forms identify a person/thing/animal without specifying proximity or distance. Adding that feature makes the rationale explanatory rather than merely repeating the technical label.

**Editorial alternative for native-editor review:**

> `Yê/ya/yên` di vê dersê de pronavên îşarkî yên qerse ne: kes, tişt an heywan nîşan didin bêyî ku nêzîkî an dûrbûna wan diyar bikin. Ew ji pronavên kesîn ên wek `min/te/me` cuda ne û di nimûneyên dersê de bi pronavê girêkî `ko` re tên bikaranîn.

The source label “qerse” is retained; this audit does not rename or reinterpret the category. Key C remains unchanged.

### E3 — L10 Q2: improve the form-vs-role sentence

The source adjudication and key mapping remain consistent: `wê` is the feminine form in the course's pronoun paradigm, but in `Wê ew dît` it functions as the inflected agent while `ew` is the direct object. The current consolidated wording is accurate in intent but “forma mê ya `ew`” can be read awkwardly.

**Editorial alternative for native-editor review:**

> Di tabloya §86 de, di rêza formên pronavê bireser de, `wê` forma mê ya pronavê `ew` e. Lê di hevoka rabirdûya gerguhêz de, wek `Wê ew dît`, `wê` kirarê tewandî ye û `ew` bireser e. Ji ber vê yekê forma pronavê û erkê wê di hevokê de divê ji hev cuda bên girtin.

This preserves key C and the source distinction; it does not settle the broader quiz-stem wording question by itself.
