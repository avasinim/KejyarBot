## Findings

### 1. The opening definition is too narrow if read literally

The reviewed draft defines `rengdêr` as a word that “comes with the noun” and explains a test based on whether it is related to and specifies a noun. This is a useful first diagnostic for attributive use, but it is not a complete definition of the source category.

The recorded source-page review of §§124–127 states that descriptive adjectives may:
- modify an expressed noun;
- function predicatively; and
- occur without an expressed noun, including substantivized/noun-like use.

**Recommendation:** retain the learner-friendly noun-modification test as the first diagnostic, but add a short qualification that adjectives may also be predicative or substantivized. Do not rewrite the definition as though every adjective must stand directly beside an expressed noun.

### 2. Word class, subclass, and sentence function must remain separate

The six-class Lesson 12 taxonomy is a word-class inventory. It should not be confused with the syntactic role a form takes in an individual sentence.

- `ev mirov` / `ev keçik`: demonstrative adjective use with an expressed noun.
- `Ev hat.`: independent demonstrative pronoun use; the same surface form is not enough to decide the category.
- `hespê min`: possessive adjective element accompanying an expressed noun.
- `yê min` / `yên min`: possessive-pronoun use replacing an understood noun/group, as recorded in the pronoun page-image review.
- `gelek`, `hemî`, and `çend`: can have adjective or pronoun use according to whether a noun is expressed and what role the form takes.
- Numeral adjective: modifies an expressed noun (`sê mal`, `çar xanî`, `stûna çaran)); `jmarnav`: independent/substantive numeral use in the course's adopted framework.

**Recommendation:** use an “expressed noun vs replaces an understood noun” test for adjective/pronoun pairs, and a “modifies a stated noun vs functions independently” test for numeral adjective/`jmarnav`. Avoid permanent form-to-category assignments.

### 3. Possessive-adjective subsection is internally coherent, but its label needs a source crosswalk

The examples `hespê min`, `mehînên te`, `kitêba vî`, `qelemên wê`, `xaniyê me`, `çiyayê we`, `kurên van`, and `keçên wan` all present possessive elements with an expressed noun. The section's post-nominal placement and linking determiner description is consistent with the recorded source/course review.

However, the source uses `rengdêrên destdaniyê` and also records `rengdêrên xwedîtiyê`; the course uses `rengdêrên xwemalîn`. At first mention, explicitly identify `xwemalîn` as the course teaching label and map it to the source wording. Do not present it as a verbatim source quotation.
