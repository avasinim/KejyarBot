## 1. Method and limits

For each lesson, this pass compared the stated learning outcome(s), teaching content, practice tasks and five-item quiz. A topic is counted as assessed only when a quiz item directly checks it; merely appearing in the lesson or an unscored exercise is not treated as quiz coverage. This is a content-alignment audit, not a psychometric study.

The master answer-key file available in this pass was the Course 1 key. The Course 2 reviewed draft includes its quiz items, but a distinct Course 2 master-key file was not located through the repository file search in this pass. Therefore Course 2 answer-letter correctness is not re-certified here. The prior structural check that the 60 embedded questions match 60 key rows is retained as a prior audit result, not repeated as a fresh semantic key validation.

## 4. Priority and safe remediation

3. In Course 1 Lesson 10, label the existing quiz as a basic recognition check; it does not fully measure application of the sound/letter distinction.

### Priority B — assessment proposals only
1. Course 2 Lesson 10: add separate assessment coverage for `jê/lê/pê/tê`, `xwe`, and neuter `ê`.
2. Course 2 Lesson 11: add coverage for indefinite and possessive pronouns.
3. Course 2 Lesson 12: use a small rotating question bank covering all six adjective classes, comparison, and the `jmarnav` subgroups.
4. Course 1 Lesson 12: add cumulative application coverage for focused contrasts that are currently not sampled in its five questions.

Do not change current question text, order, key letters, quiz IDs or lesson count in this pass. A proposed item must be source-checked and independently checked for one unambiguous correct answer before adoption.
