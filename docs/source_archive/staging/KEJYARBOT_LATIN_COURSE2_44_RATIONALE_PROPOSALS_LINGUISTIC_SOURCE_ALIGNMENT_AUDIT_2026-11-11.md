### Wording refinements recommended before any approval
1. **L1 Q2:** The extra sentence that qiset is not a fifth element is consistent with the lesson, but the quiz asks only for the count of four listed elements. Keep the explanation concise so it does not suggest that the question tests qiset's full theoretical status.
2. **L2 Q2:** Saying hesp can refer to many horses is illustrative; the core reason is that it is a general/common noun. Frame it as a general category, not as a claim about the actual number of referents in a particular utterance.
3. **L3 Q5:** Prefer “have grammatical gender in the course's classification” over wording that suggests every inanimate noun is freely assigned either gender.
4. **L4 Q2/Q5:** Say -in marks plural in the specific indefinite paradigm taught here, not that -in is a universal plural suffix in Kurmanji.
5. **L5 Q1:** Keep the definition anchored in syntactic role and inflection. Avoid making sentence position sound like the only trigger; the lesson discusses transitive past tense, gender/number and sound-conditioned forms.
6. **L6 Q5:** The description of min as possession/postnominal element is compressed. Prefer “the possessive pronoun that specifies the noun in this noun phrase” if it matches the editor's terminology.
7. **L8 Q2:** Prefer the lesson's term hêmaneke raveker when referring to a postnominal modifier, rather than pêvekeke raveker, which can be mistaken for an affix.
8. **L10 Q1:** Retain the caveat that min can function as an agent in some clauses; do not simplify this to “min is always an object pronoun in the clause.”
9. **L11 Q2:** Name yê/ya/yên as pronavên îşarkî yên qerse rather than merely “other forms,” to preserve the course's subtype distinction.
10. **L12 Q5:** Add a short reminder that in nîv roj, nîv is classified lexically as jmarnav in this lesson while the phrase has a quantifying/modifying function with roj.

These are precision recommendations, not findings that the proposed keyed answers are wrong.
