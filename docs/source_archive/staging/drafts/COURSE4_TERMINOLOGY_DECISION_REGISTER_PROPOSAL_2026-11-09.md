# پێشنیاری تۆماری بڕیاری زاراوەیی — کۆرسی ٤
**دۆخ:** پێشنیاری بۆ پەسەندکردنی خاوەن کۆرس؛ هیچ بڕیارێک هێشتا کۆتایی نییە.  
**مەودا:** وانەکانی ١–٥٠؛ پێش هەر چاکسازییەکی گشتی، ئەم تۆمارە دەبێت پەسەند بکرێت.

| زاراوەی ئینگلیزی | فۆڕمی کوردیی پێشنیارکراو | سنووری بەکارهێنان |
|---|---|---|
| Subject | بکەر | ئەرکی ڕێزمانیی پێکهاتەیەک لە ڕستەدا؛ «نیهاد» تەنها لە یەکەم ناساندندا وەک هاوتای ڕێبازێکی تر باس بکرێت، ئەگەر خاوەن کۆرس ئەم یەکخستنە پەسەند بکات. |
| Predicate | گوزارە | ئەو بەشەی لەبارەی بکەرەوە زانیاری دەدات؛ نابێت بە کردار تەنها یەکسان بکرێت. |
| Verb | کردار | پۆلی وشە/سەرەکیی کرداری؛ لە گوزارە جیاوازە. |
| Object | بەرکار | ئەرکی ڕێزمانیی پەیوەست بە کردار؛ لە ڕۆڵی واتایی وەک ئەنجامدەر و تووشبوو جیاوازە. |
| Complement | تەواوکەر | پێکهاتەی هەڵبژێردراو یان پێویست لە چوارچێوەی ناو/کردار/پێشگر؛ هەمیشە بەرکار نییە. |
| Argument | بەشداربووی هەڵبژێردراو | بەشداربووی چوارچێوەی واتایی/فەرهەنگیی کردار؛ دەتوانێت لە ڕستەدا ئاشکرا نەبێت. |
| Adjunct | هاوەڵکاری | پێکهاتەی زیادەی ڕستەیی کە لە چوارچێوەی هەڵبژاردنی کرداردا جێگایەکی سەرەکی نییە. |
| Adverb | هاوەڵکار | پۆلی وشە. |
| Adverbial | هاوەڵکاری | ئەرک یان پێکهاتەی ڕستەیی؛ بە شێوەیەکی ڕاستەوخۆ هاوتای Adverb نییە. |
| Main Clause | سەرڕستە | پێڕستەی سەرەکی لە ڕستەی ئاڵۆزدا. |
| Subordinate Clause | بەرڕستە | پێڕستەی پشتبەستوو؛ «ژێرەڕستە» وەک هاوتای پێشوو لە تێبینیی یەکەمدا تۆمار بکرێت، ئەگەر پەسەند کرا. |
| Relative Clause | پێڕستەی ڕێژەیی | پێڕستەیەک کە سەرەناو دیاری/وەسف دەکات؛ لە پێڕستەی تەواوکەر جیا بکرێتەوە. |
| Possessor / Possessive | خاوەندار / خاوەنداری | پەیوەندیی ناوخۆی گرێی ناوی؛ نابێت هەر لکاوێک بە خاوەنداری شیکار بکرێت. |
| Ezafe | ئیزافە | پەیوەندیی ڕێزمانیی نێوان سەرەکی و بەشی پاشخراو؛ لە پاشبەستی خاوەنداری و نیشانەی کەسی جیا بکرێتەوە. |
| Clitic | لکاو / پاشبەست | فۆڕمێکی پەیوەست بە وشەیەکی میوان؛ سنووری مۆرفۆلۆژی/فۆنۆلۆژی بە پێی بەڵگە دیاری بکرێت. |
| Agent | ئەنجامدەر | ڕۆڵی واتایی؛ هەمیشە Subject نییە. |
| Patient | تووشبوو | ڕۆڵی واتایی؛ هەمیشە Objectی ڕێزمانی نییە. |
| Valency | توانای کردار | ژمارە و جۆری بەشداربووانی هەڵبژێردراوی کردار. |
| Alignment | ڕێکخستنی هاوتایی | شێوازی دابەشبوونی نیشانەکانی کەس/ڕۆڵ؛ لە ڕێککەوتن و Voice جیا بکرێتەوە. |

## یاساکانی بەکارهێنان
1. لە یەکەم بەکارهێناندا: فۆڕمی کوردی + English term؛ دواتر فۆڕمی کوردی بە تەنها.
2. فۆڕمی لاتینیی مۆرفیمەکان بە شێوەی یەکگرتوو بنووسرێت؛ فۆڕمی نووسین لە دەنگ و شیکاریی مۆرفۆلۆژی جیا بکرێتەوە.
3. هەمان فۆڕمی مۆرفیمی لە دوو پێکهاتەدا دەتوانێت ئەرکی جیاواز هەبێت؛ پۆلێنکردن لەسەر بنەمای سیاق و پێکهاتە بکرێت.
4. زاراوەی شێوەزارێک بەبێ بەڵگە بۆ هەموو سۆرانی گشت نەکرێت.
5. لە هەر وانەیەکدا glossary/terms و quiz answer key دەبێت لەگەڵ ئەم تۆمارە یەکبگرێتەوە.

## دۆخی پەسەندکردن
ئەم تۆمارە تەنها پێشنیارە. تا پەسەندی خاوەن کۆرس و پشکنینی نموونەکان، هیچ یەک لە فۆڕمەکان بە بڕیاری کۆتایی ناژمێردرێت.
