## وانەی 31 — چاوگ لە ئەرکی ناویدا
**باش:** هەشت پرسیارەکە جیاوازیی فۆڕمی کەسی‌دار و ناوکردنی کردار، ئەرکی سینتاکسیی گروپی ناوکردراو، بەشداربووی Theme، و سنووری پێناسەی چاوگ دەپارێزن.
**تێبینی:** پرسیاری 3 لە «کوشتنی ئاژەڵەکە»دا ئیزافەی «ـی» بە پەیوەندیی ناوکردن و بەشداربووی کردار دەناسێنێت. ئەمە دەبێت لەگەڵ شیکردنەوەی ئیزافە و clitic لە وانەکانی 12، 18 و 25 جیا بکرێتەوە؛ هەمان نیشانەی نووسراو لە هەموو شوێنێکدا هەمان مۆرفیم/ئەرک نییە.
**پێویستی بە پشتڕاستکردنەوە:** پرسیاری 5 «ـمان» لە «دەنگدانمان» بە خاوەندارێتی/کەسی یەکەمی کۆ دەناسێنێت؛ پێویستە لە پێکهاتەی گروپی ناویدا سیاق و دامەزراندنی ئەو لکاوە دیاری بکرێت. پێناسەی «دەنگدان» وەک non-finite verb لە Salavati & Ahmadi (2018) بە بەڵگەی پەڕەی سەرچاوە پشتڕاست بکرێتەوە.
**باش:** پرسیاری 7 لیستی پێنج تایبەتمەندی/حەوت ئەرک بە یاسای داخراو ناپەسێنێت؛ ئەمە هەڵوێستێکی بەڵگە-هەستیارە.

## وانەی 32 — بنەماکانی ڕستە
**ناوەڕۆکی کویز:** 5 پرسیار لە Markdownدا؛ 0 پرسیاری structured.
**باش:** پرسیارەکان بکەری شاراوە لە فەرماندا، جیاوازیی بکەر و Agent، گروپی ناوی و بەرکاری دەربڕاو دەگرنەوە.
**تێبینی:** پرسیاری 3 «پەنجەرەکە شکێنرا» بە نموونەی جیاوازیی بکەر و ئەنجامدەری کردار بەکاردەهێنێت. بۆ وانەی سەرەتایی گونجاوە؛ بەڵام دەبێت Subject-like argument لە ڕستەی passive لە Agentی نەهاتوو جیا بکرێتەوە، وەک خودی key_points ڕوونی دەکاتەوە.
**پێویستی بە وردکردنەوە:** پێناسەی ڕستە وەک دەربڕینی «تەواو» تەنها پێناسەی سەرەتایییە؛ key_points بە دروستی ڕێگری لە پێویستیی دوو وشەی ئاشکرا دەکات. لە کویزدا فەرمان بە نموونەی بکەری شاراوە گونجاوە.
**خاڵی runtime:** Markdown quiz لە JSON structured fieldدا نییە؛ adapter بە شێوەی ئاسایی لە `quiz` دەیخوێنێتەوە، نە لە دەقی Markdown. بۆیە ئەم 5 پرسیارە بە شێوەی runtime quiz بار ناکرێن.

## وانەی 33 — بکەر و کردار
**ناوەڕۆکی کویز:** 5 پرسیار لە Markdownدا؛ 0 structured.
**باش:** پرسیارەکان بکەر و کردار لە یەکتر جیا دەکەنەوە؛ بکەر بە Agent یەکسان ناکەن؛ ڕستەی passive و ڕستەی inchoative «خانووەکە سووتا» بە نموونە دەهێنن.
**تێبینی:** پرسیاری 3 «پەنجەرەکە شکێنرا» بۆ جیاوازیی بکەر و Agent گونجاوە. لە پرسیاری 4دا «فەرزانە شووتی دەخوات» بکەر بە «فەرزانە» دیاری کراوە؛ لە چوارچێوەی ڕستەی ئاسایی سۆرانی هاوتایە.
**پێویستی بە یەکسانکردنەوە:** زاراوەی «بکەر» لە L32–33 بە Subject بەکارهاتووە؛ L34 «نیهاد» بۆ Subject بەکاردەهێنێت. ئەم دوو ناوە نابێت بێ بڕیاری کۆرس بە شێوەی هاوتای یەکسان یان جیاواز جێگیر بکرێن.

## وانەی 34 — بکەر، گوزارە و کاری بەستەر
**ناوەڕۆکی کویز:** 5 پرسیار لە Markdownدا؛ 0 structured.
**باش:** جیاوازیی گوزارە لە کاری بەستەر، و پێویستیی شیکردنەوەی «دەبێت» بە سیاق بە باشی پشکنراوە.
**ناهاوتاییی ناوخۆیی:** key_points نموونەی «منداڵەکە خۆشەویستە» دەهێنێت و «ـە» بەشی بەستەر دەناسێنێت؛ ئەمە پێویستی بە پشکنینی مۆرفۆلۆژیی فۆڕمی بەستەری سۆرانی و کەس/ژمارە هەیە. نابێت پاشگر بەبێ پارادایم و ڕوونکردنەوەی سنوور وەک یاسای گشتی دابنرێت.
**تێبینی:** لە نموونەی «فەرزانە گەنجێکی ڕۆشنبیرە»دا ڕەشنووس بە دروستی نیهاد «فەرزانە» دەزانێت و هەڵەی ناوی «ئاڕگەش» لە دەقی خاو چاک کردووە؛ ئەمە لە پشکنینی ناوەڕۆکدا پێویستە بە چاوی لێکۆڵینەوە بپارێزرێت، نە بە گۆڕینی دەقی خاو.
**پێویستی بە بڕیاری زاراوەیی:** L34 «نیهاد» و L33 «بکەر» بۆ Subject بەکار دەهێنن. لەگەڵ owner decision queue یەکسان بکرێتەوە. گوزارە = Predicate و کاری بەستەر = Copula/Linking Verb لە ڕووی ئاستی پێکهاتەوە جیاوازن؛ کویز ئەم جیاوازییە بە باشی دەگرێتەوە.
**خاڵی runtime:** 5 پرسیاری Markdown لە structured quizدا نییە.

**ناوەڕۆکی کویز:** 5 پرسیار لە Markdownدا؛ 0 structured.
**باش:** چوار جۆری ڕاگەیاندن، داخوازی، پرسیاری و سەرسوڕمان لە ڕووی مەبەستەوە جیا کراونەتەوە؛ پرسیاری 5 نموونەی ڕاگەیاندن لە فەرمان و پرسیار جیا دەکاتەوە.
**تێبینی:** «سەرسوڕمان» وەک جۆری مەبەستی دەربڕین لەگەڵ ڕستەی ڕاگەیاندن دەتوانێت لە ئاستی syntax/mood و prosodyدا هاوپۆشانی هەبێت. بۆیە چوار پۆلەکە باشترە وەک پۆلێنکردنی فێرکاری/مەبەستی دەربڕین بناسێنرێن، نە taxonomyیەکی تاک و بێ‌تێکەڵبوون لە هەموو تیۆرییەکاندا.
**باش:** جیاکردنەوەی مەبەستی ڕستە لە خاڵبەندی بە گرنگییەکی زانستییەوە ڕاستە؛ نیشانەی نووسین بە تەنها جۆری ڕستە دیاری ناکات.
**خاڵی runtime:** 5 پرسیاری Markdown لە structured quizدا نییە.

## کێشەی هاوبەشی runtime و پێشنیار
1. L32–35 هەر یەک 5 پرسیاری Markdownیان هەیە، بەڵام `quiz=[]` ـە؛ ئەم پرسیارانە لە adapterی structured quizدا بار ناکرێن.
2. پێش هەر گواستنەوەیەک بۆ JSON structured quiz، دەبێت answer key و هەڵبژاردەکان بە شێوەیەکی بێ‌گومان map بکرێن؛ هیچ وەڵامێک بە خەمڵاندن دروست نەکرێت.
3. دەقی Markdown و ناوەڕۆکی structured دەبێت هەردووکیان بپارێزرێن؛ گواستنەوە append-only و بە پەسەندی خاوەن کۆرس بێت.
4. یەکسانیی «بکەر/نیهاد/Subject» و «Agent» لە ماستەر زاراوەدا بڕیار بدرێت.
5. پێش activation پێویستە regression tests بۆ quiz count، answer mapping، و review guard جێبەجێ بکرێن.
