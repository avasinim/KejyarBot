## 2. The conceptual spine: seven distinct analytical layers
1. Argument structure / valency (L39–40): a predicate licenses or selects arguments; lexical valency differs from which arguments are overtly expressed in a clause.
2. Grammatical functions (L39, L42, L44–45): Subject and Object are syntactic functions, not semantic roles and not merely linear positions.
3. Semantic roles (L39, L41–44): Agent, Patient/Theme, Recipient and other roles describe participants' semantic relations to an event; one semantic role may be realized by different grammatical functions.
4. Predicate construction and lexical structure (L41): simplex verb, derived verb, compound predicate and light-verb construction require lexical/morphosyntactic diagnostics; spelling or spacing alone does not decide classification.
5. Clitic morphology and hosting (L42–43): clitic status, host, person/number features, grammatical function and semantic role are separate questions.
6. Voice (L44): passive is a grammatical construction/voice relation, not simply absence of an overt Agent or an intransitive clause.
7. Information structure and constituent order (L45): Object Fronting, left dislocation, Topicalization, Topic, Focus, Given/New and canonical word order are related but distinct.

## 3. Integrated lesson-by-lesson dependency map

### L39 — Object and grammatical function
Define Object by syntactic diagnostics and predicate relation, not by "the thing affected" alone. Distinguish direct Object, Recipient/Goal, complement, and adjunct; framework-specific labels must be explicit. The example «من کتێبێکم بە هاوڕێکەم دا» requires analysis of Theme vs Recipient and the syntactic status of the prepositional phrase; a preposition does not automatically prove "indirect object". L39 provides function labels required by L40 and L42–45.

### L40 — Transitive and intransitive predicates
Transitivity relates to valency/argument structure, not whether an object noun happens to appear in one sentence. Distinguish lexical valency from realized/omitted arguments, generic uses, and object omission. Passive voice is not the same as intransitivity; omitted Object does not itself make a predicate intransitive. Causative/inchoative alternation and passive must be kept separate. L40 is prerequisite for L41 and L44.

### L41 — Simplex/compound verbs and complex predicates
Keep lexical compound verbs distinct from Light Verb Constructions and broader Complex Predicates; they may overlap in some frameworks but are not synonyms. Classify lexical structure independently of transitivity. Examples «شەڕی کرد»، «قسەی کرد»، «سوێندم خوارد» need argument-structure and syntactic diagnostics, not spacing-based classification. L41 affects how predicates in L39–40 and passive examples in L44 are analyzed.

### L42 — Clitic pronouns and Object function
Clitic is a morphological/prosodic status, not a grammatical function. Possessive clitic inside an NP is not automatically an Object marker; the whole NP may itself function as Object. Distinguish Subject, Agent, Object, possessor and agreement. «من تۆم بینی» requires an account of Sorani past-transitive Agent-related/ergative clitic placement; it must not be mislabeled as possessive or simply object clitic without analysis. L42 supplies concepts needed to parse L43 and L45.

### L43 — Clitics in transitive verbs
The title promises object clitics in transitive clauses, but several examples actually demonstrate independent pronoun Objects, NP-internal possessives, overt imperative objects, or intransitive agreement. The confirmed paradigm of object clitics is not sufficiently established in the draft. Unverified strings must remain quarantined until supplied with full clauses, dialect, intended meaning, segmentation and native-speaker judgments. «من دەچم ... ئەوان دەچن» illustrates intransitive agreement, not Object clitic marking. L43 must be reconciled with L42 before quiz or paradigm is authoritative.

### L44 — Passive and grammatical Subject
Canonical passive may promote the former Object (often Patient/Theme) to Subject-like grammatical function and demote, optionally omit, or obliquely express the Agent. Subject is a grammatical function; Agent is a semantic role. Define passive morphosyntactically, not as a necessary shift of discourse focus. Distinguish passive from middle, anticausative, resultative, reflexive and lexical intransitive constructions. Sorani passive morphology, agreement, aspect/tense, Agent phrase «لەلایەن ... ـەوە», and example naturalness need dialect-specific verification. L44 requires stable Object (L39), valency/transitivity (L40), predicate structure (L41), and clitic analysis (L42–43).

### L45 — Word order, Object Fronting and information structure
Grammatical function is not linear position; initial constituent is not automatically Subject. Object Fronting is a linear/syntactic description; Topicalization is a discourse operation; left dislocation is a separate construction; Focus is an information-structural relation. Topic is not identical to Subject or Given Information; Focus is not identical to Object or New Information. SOV is a broad Sorani tendency, not a rigid universal template. Past transitive clitics and morphology must be analyzed before using word-order contrasts to diagnose Subject/Object. Passive promotion in L44 is distinct from Object Fronting or Topicalization in L45.

## 5. High-priority cross-lesson contradictions and risks
1. Subject label: L33 uses «بکەر»; L34 uses «نیهاد»; this is an explicit owner decision, not an editorial normalization to guess.
2. Agent vs Subject: L33–34 and L42–44 must consistently separate semantic Agent from grammatical Subject.
3. Clitic function: L42–43 cannot label every suffix or attached pronoun as Object clitic; distinguish possessor, Agent-indexing, agreement and argument clitics.
4. Object vs Recipient/Complement/Adjunct: L36 and L39–40 need shared diagnostics and examples; avoid treating every prepositional phrase as an indirect object or complement.
5. Transitivity vs voice: L40 and L44 must not define passive by absence of Object/Agent or call passive clauses intransitive by default.
6. Passive vs fronting: L44 promotion of former Object to Subject is not the same as L45 fronting a constituent while retaining its grammatical function.
7. Topic/Focus vs grammatical function: L45 must not teach topic as Subject or focus as Object.
8. Compound predicate terminology: L41's compound verb, light verb and complex predicate labels need a framework-specific hierarchy.
9. Dialect and morphology: multiple L42–45 examples lack sufficient dialect, segmentation, prosody, or native-speaker verification; they should not be scored until validated.
10. Course identity metadata: Lessons39–45 expanded draft metadata says «کۆرسی: ١ — بەشی ٤», while files are stored in Course4. Owner confirmation is required; do not alter metadata by inference.
