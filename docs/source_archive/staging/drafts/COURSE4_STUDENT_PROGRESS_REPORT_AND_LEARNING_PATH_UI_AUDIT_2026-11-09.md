## 1. چی لە پەڕەی «پێشکەوتنم» پیشان دەدرێت؟
بەکارهێنەر ئەمانە دەبینێت:
- Score، XP، ئاستی قوتابی
- Coin و ژمارەی سەنوق
- نیشانەکانی پێشکەوتن

ئەم ڕووکارییە ژمارەی تەواوکردنی هەر کۆرسێک، ڕێژەی سەدی، ژمارەی کویزە تەواوکراوەکان، نمرەی کویز، کاتی خوێندن و مێژووی هەوڵەکان پیشان نادات.

## 2. نیشانەکان
`current_progress_badges()` تەنها کۆرسە چالاکەکان دەبینێت و لە ڕیزی وانەکاندا تا یەکەم وانەی تەواونەکراو دەژمێرێت. ئەمە ڕێگایەکی پارێزراوە بۆ نیشاندانی پێشکەوتنی بەردەوام؛ بەڵام ئەگەر قوتابی وانەیەکی دواتری لە داتای کۆندا تۆمارکردبێت و پێشووترەکەی ون/ناتەواو بێت، نیشانەکانی دواتر پیشان نادرێن. ئەمە نابێت بە مانای سڕینەوەی تۆمارەکە لێکبدرێتەوە.

## 3. ڕێگای فێربوون — کێشەی ڕوون
هەڵبژاردەی `🧭 ڕێگای فێربوون` تەنها `load_arami_course1_manifest()` دەخوێنێتەوە و ڕێڕەوی ٢١ وانەی کۆرسی ڕێنووسی سەرەتایی پیشان دەدات. ئەم ڕاپۆرتە گشتییە بۆ هەموو کۆرسەکان نییە؛ کۆرسی ڕێزمان (`grammar`) و کۆرسەکانی تر لەو پەڕەیەدا پێشکەوتنی تایبەتی خۆیان نابینن.

لە بەرامبەردا منووی `📘 کۆرسەکان` کۆرسەکان بە پێی manifest نیشان دەدات و بۆ هەر کۆرسێک callbackی تایبەتی هەیە. کەواتە داتای ڕێڕەوی کۆرسەکان هەیە، بەڵام ڕووکاری «ڕێگای فێربوون» هێشتا تایبەتە بە کۆرسی یەک.

## 4. پێشکەوتنی کویز
DB تەنها IDی کویزی تەواوکراو لە `completed_quizzes` و ژمارەی گشتیی `tests` هەڵدەگرێت؛ scoreی هەر هەوڵێک، وەڵامە هەڵەکان و مێژووی هەوڵەکان نییە. بۆیە ڕاپۆرتی ئێستا ناتوانێت پێشکەوتنی کویز بە وردی پیشان بدات. ئەمە جیاوازە لە تۆمارکردنی تەواوبوون و خەڵاتی XP.

## 5. پێشنیاری بێ مەترسی بۆ قۆناغی داهاتوو
1. ڕووکاری «ڕێگای فێربوون» لە manifestی گشتیی کۆرسەکان دروست بکرێت، نەک تەنها لە manifestی Arami.
2. بۆ هەر کۆرسێک: completed/total، ڕێژەی پێشکەوتن، وانەی ئێستا و وانەی داهاتوو پیشان بدرێت.
3. وانەی pending review لە ژمارەی وانە تەواوکراوەکان جیا بکرێتەوە؛ خوێندنەوەی دەق بە تەواوکردن تێکەڵ نەکرێت.
4. ژمارەی کویزی تەواوکراو لە `completed_quizzes` بە شێوەی کۆیی پیشان بدرێت؛ نمرەی هەر هەوڵێک تەنها دوای دیزاینی attempt history زیاد بکرێت.
5. هیچ IDی پێشکەوتن مەگۆڕدرێت و هیچ تۆمارێک مەسڕدرێتەوە؛ UI تەنها لە داتای ئێستا خوێندنەوە بکات.

## 6. سنوور و حوکم
- ئەمە static source audit ـە؛ هیچ قوتابی/DBی بەرهەمهێنان نەخوێندرایەوە.
- هیچ test suiteێک نەجێبەجێکرا.
- هیچ کۆد، manifest، DB، Telegram، Botkeep یان `main` دەستکاری نەکرا.
- **حوکم:** پێشکەوتنی بنەڕەتی و خەڵات لە DBدا هەڵدەگیرێت، بەڵام ڕاپۆرتی قوتابی و ڕێگای فێربوون ناتەواون بۆ چەند کۆرس. گرنگترین کێشەی دۆزراوە ئەوەیە ڕێگای فێربوون تەنها کۆرسی ٢١ وانەیی Arami پیشان دەدات، نەک هەموو کۆرسە چالاکەکان.
