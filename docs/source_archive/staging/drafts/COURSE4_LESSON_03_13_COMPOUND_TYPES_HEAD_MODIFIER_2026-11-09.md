# کەژیار — کۆرسی ٤ی ڕێزمان
## پاشکۆی پەرەپێدانی وانەی ٣-١٣: جۆرەکانی ناوی لێکدراو، سەرە و دیارخەر

- بەروار: 2026-11-09
- دۆخ: پاشکۆی پێشنیارکراو؛ فۆڕمەکانی سەرچاوە کرمانجیی ناوەڕاستن و پێویستیان بە بەراوردی سۆرانی هەیە.
- سەرچاوە: سەعید کەرەمی، *وشەناسیی زمانی کوردی (کرمانجیی ناوەڕاست)*، بەشی حەوتەم، ٧-١ «لێکدراوی ناکرداری»، لاپەڕە چاپییەکانی ١٧٩–١٨٣ (PDF ١٩٥–١٩٩).
- پاراستن: ئەم فایلە زیادەیە؛ دەقی سەرەکیی وانەی خاوەنکار ناسڕێتەوە و ناگۆڕێت.

---

## ١. سەرە و دیارخەر

- **سەرە (Head):** ئەو ئەندامەیە کە پۆلی وشەی لێکدراوەکە و بەشێکی گرنگی واتاکەی دیاری دەکات.
- **دیارخەر (Modifier):** ئەو ئەندامەیە کە سەرەکە ڕوونتر دەکاتەوە یان واتاکەی سنووردار دەکات.

نموونە: `کتێب + خانە → کتێبخانە`
- سەرە: `خانە`
- دیارخەر: `کتێب`

چونکە کتێبخانە جۆرێک خانەیە، نەک جۆرێک کتێب.

## ٢. جۆربەندی بە پێی پۆلی ئەندامەکان

| پێکهاتە | نموونەی کتێب | پۆلی وشەی دەرئەنجام |
|---|---|---|
| ناو + ناو | بەفر + ئاو → بەفراو | ناو |
| ناو + هاوەڵناو | چاو + پیس → چاوپیس | هاوەڵناو |
| ئاوەڵکردار + ناو | ژێر + پیاڵە → ژێرپیاڵە | ناو |

ئەم نموونانە لە لاپەڕە ١٨٠ی چاپی کتێبەکەن. پۆلی وشەی دەرئەنجام لە هەر پێکهاتەیەکدا بە پۆلی سەرەکەوە پەیوەستە.

## ٣. جۆرەکانی لێکدراوی ناکرداری بە پێی پێکهاتە

کتێب لە لاپەڕەکانی ١٨١–١٨٢دا چەند شێوازێکی لێکدراوی ناکرداری دەخاتەڕوو:

| پێکهاتە | نموونەی سەرچاوە |
|---|---|
| ناو + ناو | ماستاو، گاسن، چێشتخانە، براژن |
| ناو + هاوەڵناو | دەنگخۆش، ئێسکسووک، دڵڕەق |
| ئاوەڵکردار + ناو | ژێرپیاڵە، پێشنوێژ، پێشباس |
| هاوەڵناو + ناو | ڕەشمار، زەردئاو، سپیپێست |
| هاوەڵناو + ـەـ + ناو | ڕەشەماڵ، تەڕەپیاز، پیرەمێرد |
| ناو + ـەـ + ناو | بەردەنوێژ، ماڵەمەال، گوڵەگەنم |
| هاوەڵناو + هاوەڵناو | جوانشیرین، جوانخاس |

**تێبینیی زانستی:** ئەمانە نموونەی شێوەزاری سەرچاوەن. فۆڕمی وشەکان بەبێ پشکنینی هاوتای سۆرانی ناگۆڕدرێت. هەروەها کتێب لە هەندێک پێکهاتەدا پەیوەندیی مێژوویی یان ڕێزمانیی پێشینەی ئیزافە باس دەکات؛ بۆیە نابێت هەموو دوو بەشێک بە سادەیی بە دوو وشەی هاوتای ئێستایی لێک بدرێنەوە.

## ٤. نێڤبەند (Interfix)

هەندێک ناوی لێکدراو بە مۆرفیمێکی بەند لە نێوان دوو ئەندامەکەدا پێک دێت. کتێب لەم بەشەدا بە تایبەتی نێڤبەندی `ـەـ` دەناسێنێت.

نموونە:
- `ڕەش + ـەـ + ماڵ → ڕەشەماڵ`
- `بەرد + ـەـ + نوێژ → بەردەنوێژ`
- `گوڵ + ـەـ + گەنم → گوڵەگەنم`

نێڤبەند بە تەنها واتای سەربەخۆی نییە؛ ئەرکی پەیوەستکردنی ئەندامەکانی پێکهاتەکەیە. نابێت بە پاشگری وشەداڕێژ تێکەڵ بکرێت.

## ٥. لێکدراوی بێ‌نێڤبەند و نێڤبەنددار

- **بێ‌نێڤبەند:** دوو ئەندامی لێکدان بەبێ مۆرفیمی ناوەندگیر پێکەوە دەبەسترێن.
- **نێڤبەنددار:** مۆرفیمێکی بەند لە نێوانیاندا دەردەکەوێت؛ لەم بەشەدا نموونەی `ـەـ` باس کراوە.

ئەم جیاوازییە پەیوەندی بە شێوازی پێکهاتنەوە هەیە، نەک بەوەی وشەکە ناوە یان هاوەڵناو.

## ٦. پەیوەندیی ئیزافە و لێکدان

کتێب ڕوون دەکاتەوە کە زۆرێک لە وشە لێکدراوەکان لە پێکهاتەی ئیزافەی پێشووترەوە دروست بوون. دوو جۆری گرنگی ئیزافە لێرەدا جیا دەکرێنەوە:

- **ئیزافەی وەسفی:** وەک «دەنگی خۆش»، «ئێسکی سووک».
- **ئیزافەی غەیرەوەسفی:** وەک «خانووی چێشت»، «ژنی برا»، «نوێژی شەو».

لە نموونەی وەسفییەوە:
- `دەنگی خۆش → دەنگخۆش`
- `ئێسکی سووک → ئێسکسووک`
- `قژی لوول → قژلوول`

لە نموونەی غەیرەوەسفییەوە:
- `خانووی چێشت → چێشتخانە`
- `ژنی برا → براژن`
- `نوێژی شەو → شەونوێژ`

ئەم نموونانە نیشان دەدەن کە پێکهاتەی وشەی لێکدراو هەمیشە بە لکاندنی ڕاستەوخۆی دوو وشەی ئێستا دروست نابێت؛ هەندێک جار پێکهاتەی ئیزافەی پێشوو دەگۆڕێت و دەبێتە وشەیەکی یەکگرتوو.

## ٧. ڕاهێنان و هەڵسەنگاندن

### ڕاهێنانی یەکەم: سەرە و دیارخەر

لە نموونەکاندا سەرە و دیارخەر دیاری بکە:
1. کتێبخانە
2. چاوپیس
3. ژێرپیاڵە
4. ڕەشمار
5. دەنگخۆش

### ڕاهێنانی دووەم: نێڤبەند

جیاوازیی نێوان نێڤبەند و پاشگری وشەداڕێژ ڕوون بکەرەوە.

### ڕاهێنانی سێیەم: ئیزافە

ئەم گۆڕانکارییانە شیکەرەوە:
- دەنگی خۆش → دەنگخۆش
- خانووی چێشت → چێشتخانە

بڵێ هەر یەکەیان لە چ جۆرە پێکهاتەی ئیزافەیەوە هاتووە.

### ڕاهێنانی چوارەم: هەڵسەنگاندنی گشتی‌کردن

بۆچی نابێت بڵێین هەموو وشە لێکدراوەکانی کوردی سەرەپاشوون؟

**وەڵامی ڕێنمایی:** چونکە کتێب ئەوە وەک گشتی‌کردنێکی سەرەتایی دەخاتەڕوو و بە ڕوونی دەڵێت پشکنینی زیاتر پێویستە؛ هەروەها لە هەندێک پێکهاتەدا ڕیزبەندیی سەرە و دیارخەر جیاوازە.

## ٨. کورتەی وانە

- ناوی لێکدراو لە دوو یان زیاتر ئەندامی وشەیی پێک دێت.
- سەرە پۆلی وشە و بەشێک لە واتای کۆتایی دیاری دەکات.
- پێکهاتەکان دەتوانن ناو، هاوەڵناو، ئاوەڵکردار یان ڕەگ لەخۆ بگرن.
- هەندێک لێکدراو نێڤبەندی `ـەـ`یان هەیە.
- پێکهاتەی ئیزافەی پێشوو دەتوانێت ببێتە بنەمای وشەی لێکدراو.
- فۆڕمی کرمانجیی ناوەڕاست دەبێت لە فۆڕمی سۆرانیی کۆرس جیا بپارێزرێت.

## ٩. سنووری بەڵگە و پشکنین

- نموونەکان لە لاپەڕەکانی ١٧٩–١٨٣ وەرگیراون؛ شێوەی نووسینی OCR لە هەندێک شوێن پێویستی بە پشکنینی وێنەی لاپەڕەی چاپکراو هەیە.
- کتێب دەڵێت سەرەپاشووبوونی زۆربەی لێکدراوەکان لە کرمانجیی ناوەڕاست گشتی‌کردنێکی خێرا و سەرەتاییە و پشکنینی زیاتر دەوێت.
- جۆرەکانی لێکدراوی کرداری لە وانەی داهاتوودا بە جیا دەخوێندرێنەوە.
- نموونەکان نابێت بەبێ بەراوردی شێوەزار و فۆڕمی سۆرانی بگوازرێنەوە بۆ وانەی کۆرسی کەژیار.
