# وانەی ٥٠ — پاشکۆی وەشانی دووەم (V2 Amendment)
**بنەما:** ڕەشنووسی سەرەتایی پارێزراوە؛ ئەم پاشکۆیە دەقی چاککراو بۆ زیادکردن دیاری دەکات.  
**دۆخ:** ڕەشنووسی چاککراو؛ پەسەند نەکراوە.

## نموونەی object relative
نموونەی «کتێبەکەی کە خوێندمەوە» لە نموونەی ستاندارد و کویز لاببرێت تا شیکارییەکەی پشتڕاست بکرێتەوە. لە شوێنی ئەودا نموونەی سەرچاوەی Bahar (2023) بە فۆڕمی لاتینی و glossی سەرچاوەیی خۆی بهێڵرێتەوە:
`kteb-aka-ī [(ka) aw da-y=kr-e]`
ئەمە نموونەی سەرچاوەییە؛ فۆڕمی لاتینی بە گومانەوە نەگۆڕدرێت. نموونەی نوێی کوردیی عەرەبی تەنها دوای پشتڕاستکردنەوەی قسەکەری شێوەزاری ئامانج زیاد بکرێت.

## مەرجەکانی لابردنی ka
بەپێی بەشی Sorani relativization لە Bahar (2023):
- لە restrictive RCدا، ئەگەر سەرەناو ئیزافەی `-ī` وەربگرێت، لە داتای باسکراودا `ka` دەتوانێت لە subject و object relativesدا لاببرێت.
- بەبێ ئەو ئیزافەیە، `ka` پێویستە.
- لە non-restrictive RCدا ئیزافەی بەستەری ئەم جۆرە بەکارناهێنرێت و `ka` بەردەوامە.
ئەم مەرجانە بە داتای توێژینەوەکەوە سنووردارن و نابێت بێ‌مەرج بۆ هەموو شێوەزارەکان گشتاندن بکرێن.

## Resumptive pronoun
لە داتای باسکراوی Baharدا، جێناوی دووبارەکەرەوە لە object relativeدا بەکاردێت؛ لە subject relativeدا ئەو بەکارهێنانە ڕێگەپێدراو نییە. ئەمە وەسفی داتای توێژینەوەکەیە، نە یاسایەکی بێ‌استثنا بۆ هەموو سۆرانی.

## کویز و ڕاهێنان
- پرسیاری ٣ بە «بەپێی Bahar (2023)» سنووردار بکرێت.
- پرسیاری ٤ object relative بە نموونەی سەرچاوەیی و glossی ڕوون بپرسێت، نە بە نموونەی کوردیی پشتڕاست‌نەکراو.
- پرسیاری extraposed/centre-embedded لە کویز لاببرێت تا پێناسە و نموونەی پشتڕاستکراوی بۆ ئامادە بێت.
- نموونەکانی restrictive/non-restrictive لە ڕەشنووسدا بمێننەوە، بەڵام پێش بەکارهێنانی وەک فۆڕمی ستاندارد پشتڕاست بکرێنەوە.

## سنووری سەرچاوە
Bahar (2023) سەرەتا توێژینەوەیەکی acquisitionی ئینگلیزییە؛ تەنها بەشی “Relativization in Kurdish Sorani” وەک بەڵگەی تایبەت بە سۆرانی بەکاربهێنرێت. هیچ یاسایەکی گشتی لە دەرەوەی ئەو بەشەوە بۆ وانەکە نەهێنرێت.

## دۆخی پەسەندکردن
هیچ نموونەیەکی نوێی پشتڕاست‌نەکراو بۆ کویز زیاد نەکراوە. structured quiz و runtime هێشتا دروست نەکراون.
