## ٢. بەراوردی ناوەڕۆک

ناوەڕۆکی ئێستای JSON بە شێوەیەکی زۆر نزیک لە ڕەشنووسی پەرەپێدراوی ١٤٥ هێڵییەوە وەرگیراوە؛ ئامانج، پێناسەی Subject و Verb، بەراوردی بکەر و Agent، خشتەی نموونەکان، هەڵە باوەکان و کویزەکە لە هەردووکیاندا هاوشێوەن. بۆیە پەیوەندیی JSON بە ڕەشنووسی پەرەپێدراو ڕوونە، بەڵام پەیوەندیی بە دەقی خاوەوە پشتڕاست نەکراوە.

### سنووری وانە

پلانی هێڵی ١١٩٤–١٢٠٦ وانەی ٣٣ بەم بابەتانە دیاری دەکات: بکەر، کار، جیاوازیی بکەر و ئەنجامدەری کردار، پەیوەندیی بکەر و کار، شیکاریی ڕستەی کرداریدار و جیاکردنەوەی بکەر لە تەواوکەر. ڕەشنووسی فراوانتری پێشوو ئەم سنوورەی ڕوونتر دەکاتەوە و دەڵێت نیهاد/گوزارە و تەواوکەر نابێت لەگەڵ بابەتی وانەی ٣٣ تێکەڵ بکرێن.

## ٣. خاڵە زانستییەکان بۆ پشکنینی خاوەن کۆرس

### ٣.١ Subject و Agent

- جیاکردنەوەی Subject و Agent لە بنەڕەتدا پێویستە: Subject ئەرکی ڕێزمانییە؛ Agent ڕۆڵێکی واتایییە.
- لە ڕەشنووسی فراوانتر، Agent بە «ئەو بەشداربووەیە کە کردارەکە ئەنجام دەدات» پێناسە کراوە؛ لە ڕەشنووسی پەرەپێدراوی نوێدا پێناسەکە دەڵێت کردارەکە بە ئەنقەست یان بە شێوەیەکی چالاک ئەنجام دەدات.
- ئەم دوو پێناسەیە هاوتای تەواو نین. «چالاک» بە تەنها سنووری Agent دیاری ناکات؛ ڕۆڵی Agent دەبێت لە ڕۆڵە واتاییەکانی تر وەک Cause/Force و Experiencer جیا بکرێتەوە. ئەنقەستیش پێویستە وەک تایبەتمەندیی نموونەیی/پڕۆتۆتایپی ڕۆڵەکە ڕوون بکرێتەوە، نەک بە شێوەیەکی سادە وەک مەرجێکی هەمیشەیی.
- لە «خانووەکە سووتا»دا خانوو Subject ـە، بەڵام لە شیکارییە واتاییەکەدا بەشداربووی کاریگەری‌لێکەوتووە، نە Agent. لە «پەنجەرەکە شکێنرا»دا بکەری ڕێزمانی و ئەنجامدەری کردار لە یەک جیاوازن و ئەنجامدەر لە ڕستەدا دیاری نەکراوە.
- پێویستە خاوەن کۆرس پێناسەی کۆتایی Agent و هاوتای کوردیی `ئەنجامدەری کردار` پەسەند بکات.

### ٣.٢ «کار» یان «کردار»؟

- پلانی دابەشکردن و ڕەشنووسی فراوانتر «کار» بەکار دەهێنن.
- ناونیشانی JSON و ڕەشنووسی پەرەپێدراوی ئێستا «کردار» بەکار دەهێنن و ئینگلیزییەکەیان `Verb` ـە.
- ئەم گۆڕانە پێویستی بە بڕیاری یەکگرتووی زاراوەیی هەیە؛ نابێت لە یەک وانەدا بەبێ ڕوونکردنەوە دوو فۆڕم بە یەک چەمک بەکاربهێنرێن.
- هەروەها پێویستە لە فەرهەنگی کۆرسدا `Verb` لە `Action` و `Predicate` جیا بکرێتەوە.

### ٣.٣ کردار و ڕۆڵی واتایی

کردار لە هەموو نموونەکاندا بە مانای «کردەوەی ئەنقەستی» نییە؛ «خەوت»، «هات» و «سووتا» ڕووداو یان دۆخن. ئەم خاڵە لە ڕەشنووسەکاندا بە دروستی دەستی پێکراوە، بەڵام پێویستە لە پێناسەی Verb و Agentدا یەکسان بپارێزرێت.

### ٣.٤ کارا و نەکارا

ئامانجی JSON باس لە دیاریکردنی Subject لە ڕستەی کارا و نەکارادا دەکات؛ بەڵام ڕەشنووسەکە زیاتر لەسەر دوو نموونەی «کەژیار پەنجەرەکەی شکاند» و «پەنجەرەکە شکێنرا» دەوەستێت. پێویستە نموونەی زیاتر و ڕوونکردنەوەی پەیوەندیی Voice بە Subject و Agent زیاد بکرێت؛ بەبێ ئەوە ئامانجەکە بە تەواوی پێک نایەت.

## ٤. هەڵە و ناسازییەکانی نموونە و پێکهاتە

- ترانسکریپتی خامی وانەی ٣٢ لە هێڵی ٨٦ «فەرزانە شووتی دەخوات» دەنووسێت، بەڵام «نەسرین» وەک بکەر دەستنیشان دەکات؛ هێڵی ٩٠یش «کەژیار هات» دەنووسێت، بەڵام «شیرین» بە بکەر دەزانێت. ئەم هەڵانە لە دەقی خامدا دەبێت وەک خۆیان پارێزراو بمێننەوە و لە ڕەشنووسدا بە چاکسازیی جیاواز نیشان بدرێن.
- ڕەشنووسی پەرەپێدراو نموونەی «فەرزانە شووتی دەخوات» لە کویزدا بەکاردەهێنێت؛ پێویستە دروستیی وشە و شێوەزاریی «شووتی» و گونجانی نموونەکە لەگەڵ فێرکاریی کۆرس بپشکنرێت.
- خشتەی نموونەکان و کویز لە `source_markdown`دا هەن، بەڵام `examples=[]` و `quiz=[]` لە JSONدا بەتاڵن.
- ڕاهێنانەکان لە `exercises` و لە `source_markdown`دا دووبارە دەبنەوە؛ ئەمە لە ڕووی ڕێکخستنی داتا پێویستی بە یەک ڕێگای دیاریکراو هەیە.
- `key_points[0]` هەموو دەقی وانەکەی تێدایە، نەک خاڵە سەرەکییە کورتەکان؛ پێویستە لە قۆناغی چاکسازیی داتا ئەم شێوازە هەڵبسەنگێندرێت.
- ناونیشان «بکەر و کردار»ە، بەڵام پلان «بکەر و کار»ە؛ بڕیاری زاراوەیی پێویستە.

## ٥. میتاداتا و پەیوەندیی کۆرس

لە سەرەتای ڕەشنووسی پەرەپێدراو و `source_markdown`ی JSONدا هێشتا «کۆرسی: ١ — بەشی ٤» نووسراوە، لە کاتێکدا فایل و runtimeی ئێستا لە کۆرسی ٤دان. ئەمە لەگەڵ ناسازییەکانی میتاداتای وانەکانی ٣٢–٤٦ هاوتایە و دەبێت بە یەک بڕیار چاک بکرێتەوە؛ بەڵام لە ئەرشیفدا وەک بەڵگەی ڕەشنووسی پێشوو بمێنێتەوە.

## ٦. پێشنیاری قۆناغی داهاتوو — هیچکام پەسەندکراو نین

1. دەقی خاو، ترانسکریپتی کۆکراوە، ڕەشنووسی ٢٥٩ هێڵی و ڕەشنووسی پەرەپێدراوی ١٤٥ هێڵی بە چوار جۆری بەڵگەی جیاواز لە فهرستی سەرچاوەدا تۆمار بکرێن.
2. خاوەن کۆرس بڕیار بدات `Verb` بە «کار» بنووسرێت یان «کردار» و لە هەموو وانەکاندا یەکسان بێت.
3. پێناسەی Subject و Agent و هاوتای کوردیی Agent بە پەسەندی زاراوەیی جێگیر بکرێت.
4. نموونەکانی کارا/نەکارا، کردارە ڕووداو/دۆخەکان و ڕۆڵە واتاییەکان بە نموونەی زیاتر پشتڕاست بکرێنەوە.
5. ئامانجی وانە، نموونە، ڕاهێنان و کویز لەگەڵ خانەکانی structured JSON یەکسان بکرێن؛ ناوەڕۆک نابێت بسڕدرێتەوە.
6. ئاماژەی سەرچاوەی نەدۆزراوە بە هیچ فایلێکی ساختە جێگۆڕکێ نەکرێت؛ تەنها بەڵگەی ڕاستەقینە بەکاربهێنرێت.
