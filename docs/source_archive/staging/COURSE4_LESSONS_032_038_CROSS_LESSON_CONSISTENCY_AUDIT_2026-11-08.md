# پشکنینی یەکگرتوویی وانەکانی ٣٢–٣٨
**کۆرسی:** ١ — بەشی ٤: ڕێزمانی کەژیار  
**دۆخ:** پشکنینی ناوەڕۆک و زاراوە؛ پەسەندکردنی خاوەن پڕۆژە پێویستە.  
**سنوور:** تەنها ڕەشنووسەکانی ٣٢–٣٨؛ دەقی خاو، runtime، manifest و هیچ بەشی دیکە دەستکاری نەکراون.

## ١. کورتەی ئەنجام
حەوت ڕەشنووسەکە لە ڕووی ڕیزبەندیی بابەتەوە زنجیرەیەکی گونجاو پێکدەهێنن: بنەمای ڕستە ← بکەر و کردار ← نیهاد و گوزارە ← مەبەستی دەربڕین ← پێکهاتەکانی ناو ڕستە ← جۆرەکانی ڕستە بەپێی پێکهاتە ← شیکاری پێڕستەکان. بەڵام پێش پەسەندکردن پێویستە چەند خاڵی هاوبەش یەکبخرێن.

## ٢. دۆزینەوە سەرەکییەکان

### ٢.١ بکەر / نیهاد
- وانەی ٣٢ و ٣٣ زاراوەی «بکەر (Subject)» بەکار دەهێنن.
- وانەی ٣٤ بە «نیهاد (Subject)» دەست پێدەکات.
- ئەگەر هەردووکیان هەمان چەمکن، دوو ناوی هاوتا بەبێ یاسای دیاریکراو نابێت لە وانەکاندا بەکاربهێنرێن.
- پێشنیاری کاری: «بکەر (Subject)» وەک شێوەی سەرەکی بپارێزرێت؛ «نیهاد» تەنها ئەگەر خاوەن پڕۆژە جیاوازییەکی چەمکیی بۆ دیاری بکات بمێنێتەوە.

### ٢.٢ کردار / گوزارە / کاری بەستەر
- وانەی ٣٢ کردار وەک پێکهاتەی سەرەکی دەناسێنێت؛ وانەی ٣٤ گوزارە و کاری بەستەر جیا دەکاتەوە.
- لە وانەکانی ٣٧–٣٨دا پێڕستە بە دەوری کردار یان گوزارە ڕێکدەخرێت.
- پێویستە یاسایەکی یەکگرتوو هەبێت: کردار (Verb) جۆرێک لە وشە/پێکهاتەی کردارە؛ گوزارە (Predicate) ئەرکی ڕێزمانیی تەواوی بەشی هەواڵدەرە؛ کاری بەستەر (Copula) ئامرازی بەستنەوەی نیهاد بە گوزارەی ناوی/هاوەڵناوی. ئەم پێناسەیە پێشنیاری پشکنینە، نە بڕیاری پەسەندکراو.

### ٢.٣ مەبەستی دەربڕین لە بەرامبەر پێکهاتەی ڕستە
- وانەی ٣٥ ڕستەکان بەپێی مەبەستی دەربڕین پۆلێن دەکات.
- وانەی ٣٧ ڕستەکان بەپێی ژمارە و پەیوەندیی پێڕستەکان پۆلێن دەکات.
- ئەم دوو پۆلێنکردنە دوو تەوەری جیاوازن و نابێت یەکدی لەناوببەن. ڕستەیەک دەتوانێت هەمان کات ڕاگەیاندن بێت و لە ڕووی پێکهاتەوە ئاڵۆز بێت.

### ٢.٤ تەواوکەر / بەرکار / هاوەڵکار
- وانەی ٣٦ بەرکار، تەواوکەر، هاوەڵکار و دیارخەری ناو لە یەکتر جیا دەکاتەوە.
- لە وانەکانی ٣٢–٣٤دا پێویستە هەر بەکارهێنانێکی «تەواوکەر» بەپێی ئەم جیاوازییە بپشکنرێت؛ تەواوکەر نابێت ناوی گشتیی هەموو پێکهاتەی زیادەی ڕستە بێت.
- جیاوازیی Complement و Adjunct هێشتا پێویستی بە بڕیاری چەمکی و نموونەی یەکسان هەیە.

### ٢.٥ پێڕستە / سەرڕستە / بەرڕستە
- وانەکانی ٣٧–٣٨ ئەم زاراوەیانە بەکار دەهێنن.
- «بەرڕستە» و «ژێرەڕستە» هێشتا بڕیاری کۆتاییان نییە؛ لە هەموو وانەکاندا تەنها یەک شێوە بەکاربهێنرێت دوای پەسەندکردنی خاوەن پڕۆژە.
- پێڕستەی سەربەخۆ دەبێت لە پێڕستەی وابەستە جیا بکرێتەوە؛ تەنها بوونی هاولکی بە تەنها بەڵگەی وابەستەبوون نییە.

### ٢.٦ جۆرەکانی ڕستەی لێکدراو و ئاڵۆز
- یاسای پێویست بۆ وانەی ٣٧: سادە = یەک پێڕستەی سەربەخۆ؛ لێکدراو = لانیکەم دوو پێڕستەی سەربەخۆ؛ ئاڵۆز = یەک پێڕستەی سەربەخۆ و لانیکەم یەک پێڕستەی وابەستە؛ لێکدراوی ئاڵۆز = لانیکەم دوو پێڕستەی سەربەخۆ و لانیکەم یەک وابەستە.
- ژمارەی کردار بە تەنها پێوەری جۆری ڕستە نییە؛ پێڕستە و پەیوەندییەکانیان پێوەرن.
- نموونەکان دەبێت بە شێوەی ئاشکرا ئەو پێڕستانە نیشان بدەن کە پۆلێنکردنەکەیان پشت پێ دەبەستێت.

## ٣. یاساکانی یەکگرتوویی پێش پەسەندکردن
1. لە یەکەم بەکارهێناندا زاراوەی کوردی و هاوتای ئینگلیزی بنووسرێت؛ لە دواتردا شێوەی کوردیی یەکسان بپارێزرێت.
2. Subject و Agent لە یەکتر جیا بمێننەوە.
3. Verb و Predicate و Copula وەک سێ ئاستی جیاواز بناسرێنەوە.
4. Object و Complement و Adjunct بە یەک ناو بانگ نەکرێن.
5. Sentence Type by Purpose لە Sentence Type by Structure جیا بکرێتەوە.
6. هەموو نموونەیەک لەگەڵ شیکاریی خۆی هاوتا بێت؛ ناوی کەس و ڕۆڵی ڕێزمانی لە نموونە و شیکارییەکەدا نەگۆڕدرێت.
7. کویزەکان تەنها ئەو زانیارییانە بپرسن کە لە هەمان وانەدا بە ڕوونی فێر کراون.

## ٤. خاڵەکانی پێویست بە بڕیاری خاوەن پڕۆژە
- Subject: «بکەر» یان «نیهاد»؟ ئایا جیاوازیی چەمکییان هەیە؟
- Predicate: «گوزارە» یان «بەروتار»؟ کامەیان شێوەی ستانداردە؟
- Subordinate Clause: «بەرڕستە» یان «ژێرەڕستە»؟
- Complement و Adjunct: پێناسە و نموونەی کۆتایی.
- Compound و Complex: پەسەندکردنی پۆلێنکردنی پێڕستە-بنەما.

## ٥. ڕێنمایی بۆ هەنگاوی داهاتوو
- یەکەم: بڕیاری زاراوەکان وەربگیرێت.
- دووەم: ڕەشنووسەکانی ٣٢–٣٨ بە پێی بڕیارەکان یەکسان بکرێنەوە.
- سێیەم: ناو، نموونە، شیکاری و کویز لە نێوان وانەکاندا پشکنین بکرێن.
- چوارەم: تەنها دوای پەسەندکردنی خاوەن پڕۆژە، گۆڕینی بۆ شێوازی runtime دەست پێبکرێت.

**تێبینی پاراستن:** ئەم پشکنینە تەنها بەڵگەنامەی کارییە؛ هیچ ڕەشنووسێک پەسەند نەکراوە و هیچ وانەیەک runtime نەکراوە.
