# پاشکۆی چاکسازیی تۆماری زاراوەی Round 26
## 2026-11-10 | Append-only correction notice

لە تۆماری یەکگرتووی Round 26دا خشتەی زاراوەیی بە شێوەی کورت «Root = ڕەگ» تۆمار کراوە. ئەو هاوتاییە بە پێی فەرهەنگۆکی کتێبی سەعید کەرەمی ورد نییە و دەبێت بە پاشکۆی ئەمڕۆ ڕوون بکرێتەوە:

- Root = ڕیشە.
- Bound Root = ڕەگ.
- Stem = بنکە لە فەرهەنگۆکی کتێبدا؛ «بنج» زاراوەی بەکارهاتووی کۆرسە و پێویستی بە بڕیاری یەکگرتووی زاراوەیی هەیە.
- Base = بناغە.
- Lexeme = بنەچەوشە.

ئەم تۆمارە تەنها ڕوونکردنەوەیەکی پاشکۆییە؛ دەقی Round 26 و هیچ دەقی خاو ناگۆڕێت. بۆ پێشکەشکردنی فەرمی، خشتەی زاراوەیی نوێی کۆرس دەبێت ئەم جیاوازییە بپارێزێت و بە داتای سۆرانی پشتڕاست بکرێتەوە.
