# کۆرسی ٤ — پشکنینی زانستیی وانەکانی ٣٦–٤٠
## Round 38 | 2026-11-10 | Append-only review

### سنووری پشکنین
پشکنینی ڕەشنووسی پەرەپێدراوی وانەکانی ٣٦–٤٠؛ هیچ دەقی خاو، ڕەشنووس، نموونە، ڕاهێنان یان کویزێک دەستکاری نەکراوە. هەموو ئەم وانانە هێشتا owner_review_pending_expanded_draft ـن و runtime/quizی چالاکیان نییە.

## وانەی ٣٦ — تەواوکەر و پێکهاتەکانی ناو ڕستە
### خاڵە بەهێزەکان
- ڕەتکردنەوەی پێناسەی «هەرچی جگە لە بکەر و کردارە تەواوکەرە» دروستە.
- جیاکردنەوەی Object، Noun Complement، Noun Modifier و Adjunct بە پێی ئەرکەکانیان پێویستە.
- هۆشداریی ئەوەی تاقیکردنەوەی لابردن بە تەنها بڕیاردەر نییە، دروستە.

### خاڵە پێویستەکان
1. **Object vs Complement:** Object لە چوارچێوەی Complementی کرداردا دەتوانێت جۆرێک بێت؛ پێناسەکان دەبێت hierarchical بکرێن، نەک وەک پۆلە هاوتاکان.
2. **Noun Complement vs Noun Modifier:** لە «گەڵای دارەکە» و «شووشەی پەنجەرەکە»دا پەیوەندیی نێوان دوو ناو بە تەنها بە خاوەنداری/بەش-کۆڵەکەوە دیاری ناکرێت؛ دەبێت لە سیاق و واتای ناوەکاندا پشکنین بکرێت.
3. **نموونەی «گەڵای دارەکە وەری»:** فۆڕم و سروشتیی ڕستەکە لە داتای سۆرانی/دەقی خاو پشتڕاست بکرێتەوە؛ بێ بەڵگە وەک نموونەی ستاندارد پەسەند نەکرێت.
4. **«لە ئاودا دەژی»:** پێکهاتەی شوێن دەتوانێت بە پێی ڕێباز Adjunct یان Complementی پێویست بێت؛ تاقیکردنەوەی لابردن بە تەنها بەس نییە.
5. **«هەورامان» لە «گوێزی هەورامان»:** پەیوەندیی ناوی/ناوچەیییەکە بە بەڵگەی بەکارهێنان پشتڕاست بکرێتەوە.
6. **زاراوە:** «گرێی ناوی/گرێی کرداری» لەگەڵ registerی کۆرس یەکسان بکرێت؛ «هاوەڵکار» بۆ adjunct بەکاربهێنرێت، بەڵام adverbial (ئەرکی ڕستەیی) لە adverb (جۆری وشە) جیا بێت.

## وانەی ٣٧ — جۆرەکانی ڕستە لە ڕووی پێکهاتەوە
### خاڵە بەهێزەکان
- یەکەی پۆلێنکردن Clause ـە، نە تەنها ژمارەی کردار.
- Simple = یەک independent clause؛ Compound = دوو یان زیاتر independent clauses؛ Complex = independent + dependent clause؛ Compound-complex = لانیکەم دوو independent + لانیکەم یەک dependent clause، وەک چوارچێوەی پێشنیارکراو.
- جیاکردنەوەی coordination لە subordination گرنگە.

### خاڵە پێویستەکان
1. **Clause terminology:** بەپێی registerی پێشنیارکراو: Clause = پێڕستە؛ Main Clause = سەرڕستە؛ Independent Clause = پێڕستەی سەربەخۆ؛ Dependent Clause = پێڕستەی پشتبەست. «بەرڕستە» نابێت بێ دیاریکردنی واتای دقیق بەکاربهێنرێت.
2. **«هاولکیی بەرخەر»:** فۆڕمەکە لە دەقی وانەدا ڕوون نییە و دەکرێت هەڵەی نووسین یان زاراوەیەکی تر بێت؛ بێ بەڵگە نابێت بگۆڕدرێت. دەبێت لە سەرچاوەی خاو و مەبەستی ڕێزمانییەکە بپشکنرێت.
3. **پێڕستەی سادە:** هەبوونی چەند هاوئاهەنگیی ناوی بە تەنها ڕستە ناکاتە compound؛ ئەمە بە دروستی ڕوون کراوەتەوە.
4. **نموونەی شیعری:** دەقی شیعریی خاو بپارێزرێت؛ شیکردنەوەی clause structureی شیعر لە شێوەی قسەی ئاسایی جیا بکرێتەوە.
5. **نمونەی ڕوونکراوەی زیادکراو:** هەر نموونەی زیادکراو دەبێت بە شێوەیەکی ڕوون لە دەقی خاو جیا بکرێتەوە و بۆ شێوەزاری دیاریکراو پشتڕاست بکرێتەوە.

## وانەی ٣٨ — پێڕستە، سەرڕستە و بەرڕستە
### خاڵە بەهێزەکان
- جیاکردنەوەی ڕستە لە پێڕستە و سەرڕستە لە پێڕستەی پشتبەست بنەڕەتییە.
- ڕێکخستنی سەرڕستە و پێڕستەی پشتبەست لە شوێنی پێش/دوای یەکتر بە بابەتی clause order گرنگە.

### خاڵە پێویستەکان
1. «هاولکیی بەرخەر» هەمان کێشەی زاراوەیی وانەی ٣٧ی هەیە؛ هیچ چاکسازییەک بە خەمڵاندن ناکرێت.
2. «بەرڕستە» و «پێڕستەی پشتبەست» لە دەقەکەدا پێویستیان بە یەکگرتن هەیە؛ یەک زاراوەی سەرەکی و crosswalkی ڕوون دیاری بکرێت.
3. سەرڕستە لە هەموو ڕستەی ئاڵۆزدا هەمیشە بە شێوەی ڕووکەشی یەکسان لە پێش پێڕستەی پشتبەست نایەت؛ شوێن بە جۆری subordinate clause و زمان/شێوەزار دەگۆڕێت.
4. پێناسەی پێڕستە بە «دەوری کردار یان گوزارە» نابێت clauseی ناوی/بێ کردار لە پێناسەی گشتی دەربکات؛ دەبێت بە شێوەیەکی فراوانتر و بەڵگەدارتر بنووسرێت.
5. شیعرەکانی مەولەوی و گۆران لە فایلە خاوەکاندا بەجێ بمێنن؛ هیچ نموونەی شیعری بە دەستکاری ناوەڕۆک پەسەند ناکرێت.

## وانەی ٣٩ — بەرکار و ئەرکی ڕێزمانیی ئەو
### خاڵە بەهێزەکان
- بەرکار لە بکەر و Agent جیا کراوەتەوە.
- ئاگاداریی ئەوەی هەر پێکهاتەی «بە/بۆ/لە»دار بەرکاری ناڕاستەوخۆ نییە، دروستە.
- «پێکهاتەی وەرگر/ئاراستە» وەک ناوی وەسفیی کاتی لە پەسەندکردنی زاراوەیی پێشترە.

### خاڵە پێویستەکان
1. **Recipient vs Indirect Object:** Recipient ڕۆڵێکی واتایییە؛ Indirect Object ئەرک/پێکهاتەی ڕێزمانییە. ئەم دووانە نابێت بە یەکدی بگۆڕدرێن.
2. **Prepositional phrase:** «بە هاوڕێکەم» لە «کتێبێکم بە هاوڕێکەم دا»دا پێکهاتەی پێشگر‌دارە؛ لە ڕێبازێکدا recipient/oblique complement ـە، بەڵام پێویستە پێش پەسەندکردنی indirect object لەگەڵ داتای سۆرانی بپشکنرێت.
3. **Object tests:** جێگۆڕکێ، پرسیارکردن و لابردن بە تەنها بڕیاردەر نین؛ پێویستە هاوکێشەی مۆرفۆلۆژی، ڕیزبەندی و کردارە هەڵبژێردراوەکان بپشکنرێن.
4. **بەرکار و Agent:** بەرکار زۆرجار Theme/Patient ـە، بەڵام هەمیشە ئەنجامدەری کردار نییە؛ ڕۆڵی واتایی و ئەرکی ڕێزمانی لە registerدا جیا بمێنن.
5. **تێکەڵی لەگەڵ Complement/Adjunct:** پێناسەی بەرکار و تەواوکەر لەگەڵ وانەی ٣٦ یەکسان بکرێتەوە؛ «بەرکاری ناڕاستەوخۆ» تەنها دوای پەسەندکردنی ڕێباز و بەڵگە بەکاربهێنرێت.

## وانەی ٤٠ — کاری تێپەڕ و کاری تێنەپەڕ
### خاڵە بەهێزەکان
- Transitivity لەسەر وەرگرتنی Direct Object لە بەکارهێنانی دیاریکراودا بنیات نراوە.
- جیاکردنەوەی lexical valency لە overt object realization گرنگە.
- نەبوونی بەرکاری ئاشکرا بە تەنها بەڵگەی intransitive نییە؛ omission/implicit object پێویستە لە contextual use جیا بکرێتەوە.
- لێکدراوبوونی کردار بە خۆی transitivity دیاری ناکات.
- تێنەپەڕ = Intransitive لەگەڵ registerی کۆرس یەکسانە.

### خاڵە پێویستەکان
1. **Transitivity vs Valency:** Transitivity تایبەتمەندیی وەرگرتنی direct object ـە؛ Valency ژمارە و جۆری arguments ـەکان دەگرێتەوە. ئەم دووانە یەکسان نین.
2. **Passive vs Intransitive:** Passive voice گۆڕانی ڕێکخستنی ڕۆڵ/ئەرکی ڕستەیە؛ Intransitive verb لە ڕێکخستنی بنەڕەتیدا direct objectی نییە. ڕستەی passive بە خۆکار ناگۆڕێتە کردارێکی intransitive لە ئاستی فەرهەنگی.
3. **Noun incorporation/compound:** «نان خوارد» لە بەرامبەر «نانەکەی خوارد»دا پێویستی بە شیکردنەوەی lexicalization/incorporation و دەوروبەری قسە هەیە؛ نابێت بە شێوەی یەکگرتوو بڕیار بدرێت.
4. **Passive paradigms:** فۆڕمەکانی «شکایەوە»، «کرایەوە» و هاوشێوەکان لە داتای سۆرانی و شێوەزاری دیاریکراودا پشتڕاست بکرێنەوە؛ نابێت فۆڕمی passive و inchoative بەبێ پشکنین یەکسان بکرێن.
5. **Verb alternation:** کردارێک دەتوانێت بە پێی واتا و پێکهاتەی ڕستە بەکارهێنانی جیاواز هەبێت؛ بۆ هەر نموونەیەک valency frameی دیاری کراو پێویستە.
6. **Clitics:** جێناوی لکاو پێوەری سەربەخۆی transitivity نییە؛ لەگەڵ پشکنینی وانەی ٤٢ و ٤٩ بپارێزرێت.

## بڕیاری گشتی بۆ وانەکانی ٣٦–٤٠
- زاراوەکانی Complement/Object/Adjunct و Recipient/Indirect Object بە جیاوازیی ئەرکی و واتایی پێناسە بکرێن.
- Clause = پێڕستە؛ Main Clause = سەرڕستە؛ Independent Clause = پێڕستەی سەربەخۆ؛ Dependent Clause = پێڕستەی پشتبەست.
- «هاولکیی بەرخەر» تا پشتڕاستکردنەوەی دەقی خاو بە هەمان شێوە وەک فۆڕمی unresolved بمێنێتەوە.
- Transitivity و Valency و Passive و Intransitivity چەمکی جیاوازن.
- هیچ کویزێک بۆ وانەکانی ٣٦–٤٠ بە خەمڵاندن دروست نەکراوە.
