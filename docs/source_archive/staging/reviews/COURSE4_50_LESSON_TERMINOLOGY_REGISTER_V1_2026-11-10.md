# کۆرسی ٤ — تۆماری یەکگرتووی زاراوەکان بۆ ٥٠ وانە
## وەشانی ١ | 2026-11-10 | Append-only terminology decision record

### ١. بنەمای بڕیار
1. کتێبی سەعید کەرەمی «وشەناسیی زمانی کوردی (کرمانجیی ناوەڕاست)» بۆ زاراوە و چەمکەکانی خۆی سەرچاوەی پێشەنگە؛ بەڵام داتای کرمانجیی ناوەڕاست نابێت بە یاسای سۆرانی بگشتێندرێت.
2. بۆ نموونە و فۆڕمی سۆرانی، دەقی سۆرانیی پەسەندکراوی خاوەن کۆرس و پارادایمی کردار/گرێی سۆرانی بنەمای بڕیارە.
3. کتێبی دیاکۆ هاشمی بۆ کۆرسی ٤ سەرچاوەی ڕێنووس/خاڵبەندیی ڕێزمانی نییە؛ ئەو سەرچاوەیە بۆ کاری ڕێنووسی کۆرسی ٣ بەکاردێت.
4. زاراوەیەک لە چەند زاراوەی نزیک جیا دەکرێتەوە ئەگەر چەمکەکان جیاوازن؛ یەکسانکردنی وشە بەبێ یەکسانیی چەمک قەدەغەیە.

### ٢. زاراوە سەرچاوەیییەکانی کتێبی کەرەمی
ئەم هاوتاکردنانە لە وشەنامەی کتێبەکەدا تۆمارکراون (لاپەڕەکانی ٢١٧–٢١٨):
| English | زاراوەی کتێب | بڕیاری بەکارهێنان |
|---|---|---|
| Root | ڕیشە | بۆ Root بەکاربهێنرێت؛ لە Bound Root جیا بێت |
| Bound Root | ڕەگ | تەنها بۆ ڕەگی بەستراو/Bound Root |
| Stem | بنکە | زاراوەی سەرچاوەییی Stem؛ بەبێ crosswalk لەگەڵ «بنج» یەکسان نەکرێت |
| Base | بناغە | لە Stem و Root جیا بێت |
| Lexeme | بنەچەوشە | لە وشەی فۆڕمی و Stem جیا بێت |
| Affix | گیرەک | چەمکی گشتیی پێشگر/پاشگر |
| Enclitic | پاشنووس | لە پاشگر/Suffix جیا بێت |
| Proclitic | پێشنووس | لە پێشگر/Prefix جیا بێت |
| Incorporation | پێکنووسان | لە Compound Verb و Verbal Compound جیا بێت |
| Inflection | گەردان | زاراوەی سەرچاوەیی؛ «چەمانەوەی ڕێزمانی» تەنها وەک ڕوونکردنەوەی واتایی لە یەکەم بەکارهێناندا دێت |
| Preposition | پێشبەند | لە پارتیکڵ و پێشگری وشەڕۆنان جیا بێت |

### ٣. زاراوەی یەکگرتووی ڕێزمان و سینتاکس
| English | زاراوەی ستانداردی کۆرس | تێبینی |
|---|---|---|
| Noun Phrase (NP) | گرێی ناوی | «گروپی ناوی» فۆڕمی پێشوویە؛ لە دەقی نوێدا بەکارنەهێنرێت |
| Verb Phrase (VP) | گرێی کرداری | «گروپی کرداری» فۆڕمی پێشوویە؛ پێویستە پێکهاتە و سەرەکەی بپشکنرێت |
| Subject | بکەری ڕێزمانی | ئەرکی سینتاکسییە؛ لە Agent جیا بێت |
| Agent | ئەنجامدەری کردار | ڕۆڵی واتاییە؛ نابێت بە Subject یەکسان بکرێت |
| Object | بەرکار | ئەرکی ڕێزمانییە؛ بە «تووشبووی کردار» وەک ڕۆڵی واتایی تێکەڵ نەکرێت |
| Direct Object | بەرکاری ڕاستەوخۆ | تەنها کاتێک بەڵگەی سینتاکسی هەیە |
| Indirect Object | بەرکاری ناڕاستەوخۆ | هەموو گرێی پێشبەندی بەو ناوە ناونەبرێت |
| Recipient | وەرگر | ڕۆڵی واتاییە؛ لە ئەرکی سینتاکسی جیا بێت |
| Predicate | گوزارە | لە Copula جیا بێت |
| Copula | کاری بەستەر | لە گوزارەی تەواو جیا بێت |
| Clause | پێڕستە | یەکەی سینتاکسی |
| Main Clause | سەرڕستە | لە ژێرەڕستە جیا بێت |
| Subordinate Clause | ژێرەڕستە | لە بەرڕستەی فۆڕمی پێشووی جیا بێت |
| Independent Clause | پێڕستەی سەربەخۆ | لە Dependent Clause جیا بێت |
| Dependent Clause | پێڕستەی پشتبەست | پەیوەندیی پشتبەستن دیاری بکرێت |
| Adverb (word class) | هاوەڵکار | پۆلی وشەییە |
| Adverbial (function) | هاوەڵکاری | ئەرکی سینتاکسییە؛ لە هاوەڵکار جیا بێت |
| Transitive | تێپەڕ | تایبەتمەندیی کردار |
| Intransitive | تێنەپەڕ | تایبەتمەندیی کردار؛ لە Passive جیا بێت |
| Active Voice | کاری کارا | لە ڕۆڵی Agent جیا بێت |
| Passive Voice | کاری ناکارا | لە کردارە تێنەپەڕەکان جیا بێت |
| Derivation | داڕشتن | لێکسیەم/وشەی نوێ دروست دەکات |
| Inflection | گەردان | فۆڕمی ڕێزمانیی هەمان لێکسیەم دەگۆڕێت |

### ٤. لکاو، پاشگر و پێشگر — جیاوازیی پێویست
| English | زاراوەی کۆرس | بڕیاری شیکردنەوە |
|---|---|---|
| Clitic | لکاو | ناوی گشتی بۆ توخمی بەستراو بە وشە/گرێیەکی تر |
| Enclitic | پاشنووس | لکاوی دوای توخمە سەرەکییەکە |
| Proclitic | پێشنووس | لکاوی پێش توخمە سەرەکییەکە |
| Affix | گیرەک | پێشگر و پاشگر لەخۆدەگرێت |
| Prefix | پێشگر | بەشێک لە وشە، لە پێش بنەما |
| Suffix | پاشگر | بەشێک لە وشە، لە دوای بنەما |
| Possessive clitic | لکاوی خاوەنداری | ئەرکی خاوەنداری لە گرێی ناویدا |
| Past transitive subject clitic | لکاوی بکەری ڕابردووی تێپەڕ | بە پێی پارادایم و سیاق شیکار بکرێت |

«پاشبەستە» لە runtimeدا ١٨ جار هاتووە، بەڵام بێ پێناسەی یەکسان دەتوانێت لە Clitic، Enclitic و Suffix تێکەڵ بکرێت؛ لە دەقی نوێدا بەکارنەهێنرێت تا چەمکەکە دیاری نەکرێت.

| Verbal Compound | لێکدراوی کرداری | پێکهاتەی وشەیی/کرداری؛ لە Compound Verb جیا بێت |

### ٧. بڕیاری جێبەجێکردن
1. لە دەقی نوێدا ئەم تۆمارە بنەمای یەکگرتووییە؛ NP=گرێی ناوی، VP=گرێی کرداری، Subject=بکەری ڕێزمانی، Agent=ئەنجامدەری کردار.
2. Root/Bound Root/Stem/Base/Lexeme بە پێی وشەنامەی کەرەمی جیا دەکرێنەوە. «بنج»ی وانەکانی سۆرانی بەبێ crosswalk بە «بنکە» ناگۆڕدرێت؛ تۆمارەکە لە یەکەم بەکارهێناندا پەیوەندییان ڕوون دەکاتەوە.
3. Inflection بە «گەردان» دەنووسرێت؛ لە یەکەم بەکارهێناندا دەتوانرێت «گەردان (چەمانەوەی ڕێزمانی)» بێت. «لەچۆنایەتی» لە دەقی نوێدا بەکارنەهێنرێت.
4. Clitic/Enclitic/Affix/Suffix بە پێی خشتەی سەرەوە جیا دەکرێنەوە؛ «پاشبەستە» بێ پێناسە بەکارنەهێنرێت.
5. Compound Verb، Verbal Compound و Incorporation سێ چەمکی جیاوازن؛ نموونەکانی کتێبی کەرەمی بۆ شیکردنەوەی خۆی بەکاربهێنرێن، نە بۆ گشتاندن بۆ سۆرانی.
6. هیچ mass find-and-replace ـێک ناکرێت. هەر چاکسازییەک لە وانە بە وانە، بە پاشکۆی زیادکراو، پاراستنی دەقی خاو و تاقیکردنەوەی regression ئەنجام دەدرێت.

### ٨. دۆخی جێبەجێکردن
ئەم تۆمارە بڕیاری editorialی یەکگرتووی وەشانی ١ بۆ دەقی نوێ و پاشکۆکانی داهاتووە. هیچ runtime، JSON، DB، Botkeep، Telegram یان deployment لەم قۆناغەدا دەستکاری نەکراوە. گۆڕینی دەقی کۆن تەنها بە پاشکۆی جیا و تاقیکردنەوەی پشتڕاستکراو دەکرێت.
