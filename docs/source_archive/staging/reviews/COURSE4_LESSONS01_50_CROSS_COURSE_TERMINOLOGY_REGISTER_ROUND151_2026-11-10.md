# تۆماری یەکگرتوویی زاراوەییی کۆرسی ٤ — وانەکانی ١–٥٠، Round 151

## بنەمای کار
ئەم تۆمارە تەنها بۆ candidate و پشکنینی زاراوەییە؛ JSONی بنەڕەتی، دەقی خام، runtime و داتای فێرخوازان ناگۆڕێت. هەموو candidate ـەکان inactive_candidate_not_approved دەمێننەوە.

| چەمک | زاراوەی پێشنیارکراو | دۆخ |
|---|---|---|
| Subject | بکەر | یەکگرتوو |
| Agent | ئەنجامدەری کردار | یەکگرتوو؛ لە بکەر جیاوازە |

| Intransitive | تێنەپەڕ | یەکگرتوو لە candidate ـە نوێکاندا |
| Active Voice | ڕستەی کارا | یەکگرتوو لە وانەکانی ١٣، ١٨ و candidate ـەکانی دواتر |
| Passive Voice | ڕستەی نەکارا | یەکگرتوو |
| Clause | پێڕستە | بەردەوام |

## چاکسازییە بەڵگەدارەکان
1. **بەستێن:** Round 143، ١٤٤ دەرکەوتنی «سیاق» لە ١٣٦ خانەی دەقی structuredی وانەکانی ١–٣١ بۆ «بەستێن» گۆڕدرا؛ candidate ـەکان لە Round 146 و Round 147 تۆمار کران. لە وانەکانی ٣٢–٥٠دا structured fields ـی candidate ـەکان لە پشکنینی Round 142دا «سیاق»یان نەما.
2. **Voice:** Round 145، ٤٨ خانە لە وانەکانی ١٣ و ١٨ بە «ڕستەی کارا/ڕستەی نەکارا» یەکخرا؛ «چالاکی» بە مانای activity پارێزرا. Round 144 هەڵەی substring replacementی هەبوو و نابێت جێبەجێ بکرێت.
3. **Transitivity:** Round 149، ٢١ خانە لە وانەکانی ١٢، ١٣، ١٤، ١٥ و ١٨ بە «تێنەپەڕ» یەکخرا؛ «تێپەڕ» وەک خۆی پارێزرا.
4. **Subject/Agent:** Round 148 وانەی ١٨ی ورد کردەوە؛ Round 150 لە وانەی ٤٤دا slash-formی بکەر/ئەنجامدەری کردار لابرا. لە وانەی ٤٢دا ئەو slash ـە تەنها لە source_markdown ـی پارێزراودا دەرکەوتووە، نە لە structured fields.

## خاڵە هێشتا پێویستەکان
- هاوتاییی «هاوەڵکاریی ئازاد» و «هاوەڵکاریی زیادە» پێویستی بە بڕیاری تیۆریی ورد هەیە؛ بۆیە لە ئێستادا وەک دوو لیبڵی جیاواز تۆمار دەکرێن.
- هەموو نموونەکانی بکەر/ئەنجامدەر و Voice دەبێت لەگەڵ زاری ئامانج و بەڵگەی سروشتیبوون بپشکنرێن.
- پێویستە کویز و وەڵامەکان لە ڕووی یەکسانیی واتایی و لۆژیکی بپشکنرێن؛ پشکنینی ژمارەی هەڵبژاردە و answer-index بە تەنها بەڵگەی دروستیی زانستی نییە.

## پاراستن و سنووری کردار
- هەموو candidate ـە نوێکان ناچالاک و پەسەندنەکراون.
- هیچ فایلێکی بنەڕەتی overwrite نەکراوە؛ candidate ـی پێشوو هەمووی پارێزراون.
- source_markdown و source_path لە هەر candidate ـێکدا بە مەبەستی پاراستنی بەڵگە دەستکاری نەکراون.
- هیچ merge، deploy، activation، runtime change، Botkeep/Telegram sync یان restart نەکراوە.

## داهاتوو
پشکنینی regression ـی کویز/وەڵام و نموونەکان لە ٥٠ وانەدا، بە پێی ئەم تۆمارە؛ پاشان پشکنینی فێرکاریی شێوەزار و پشتڕاستکردنەوەی سەرچاوەیی. پەسەندکردنی runtime قۆناغێکی جیاوازە.
