### ٢. دۆزینەوەی یەکەم — Root / Bound Root / Stem
تۆماری Terminology Register V1 لە وشەنامەی کتێبی کەرەمی ئەم جیاوازییە تۆمار دەکات:
- Root = ڕیشە
- Bound Root = ڕەگ
- Stem = بنکە
- Base = بناغە
- Lexeme = بنەچەوشە

بەڵام دەقی runtime لە وانەی ١٣دا:
- لە objectiveدا «جیاکردنەوەی چاوگ و ڕەگی کردار» دەڵێت.
- لە پێناسەدا «ڕەگ بنەمای لێکسیەمییە» بەکاردێنێت؛ ئەمە لەگەڵ پێناسەی تۆمارکراوی Root=ڕیشە و Bound Root=ڕەگ بە تەواوی هاوتا نییە.
- لە هەمان وانەدا Root، Bound Root و Stem بە ئینگلیزی دەهێنێت و ڕەگ/ڕیشە/بنج لە چەند شوێنێکدا دەردەکەون.
- وانەی ٢٩ دەڵێت «ڕەگ بنەمای لێکسیەمییە و بنج فۆڕمی کردارە»؛ ئەمە هێشتا پێویستی بە دیاریکردنی ئەوە هەیە کە «ڕەگ» لێرە Root ـە یان Bound Root، چونکە هەموو Rootێک بە پێی پێناسەی مۆرفۆلۆژی لەوانەیە بەستراو نەبێت.

**بڕیاری پشکنین:** ئەم ناهاوتاییە بە تەنها mass replacement چارەسەر ناکرێت. پێویستە پێش گۆڕینی وانەی ١٣ و ٢٩، بۆ نموونەکانی کردار دیاری بکرێت کە کامەیان Root ـی سەربەخۆیە، کامەیان Bound Root ـە، و کامەیان Stem ـی فۆڕم‌دروستکەرە. تا ئەوە پشتڕاست نەکرێتەوە، «بنج» و «ڕەگ»ی دەقی خاو دەمێننەوە و پێناسەی نوێ بە پاشکۆ زیاد دەکرێت.

### ٣. دۆزینەوەی دووەم — Enclitic / Clitic / Suffix
- وانەی ١١ بە ڕوونی دەڵێت Clitic pronoun = «جێناوی لکاو» و Enclitic = «پاشبەستە».
- وانەی ١٣ دەڵێت «پاشبەستە لە پاشگر جیاوازە» و پاشبەستە/پاشگر بە چەمکەکانی Clitic و Suffix پەیوەست دەکات.
- Terminology Register V1 بۆ Enclitic «پاشنووس» دیاری کردووە و «پاشبەستە»ی بێ‌پێناسەی یەکگرتوو بۆ دەقی نوێ ڕەت دەکاتەوە.
- بۆیە runtimeی کۆن لە وانەکانی ١١ و ١٣دا فۆڕمی «پاشبەستە»ی بەکارهێناوە، بەڵام بڕیاری نوێ «پاشنووس»ە.

**بڕیاری پشکنین:** لە دەقی نوێدا «لکاو» بۆ Clitic و «پاشنووس» بۆ Enclitic بەکاربهێنرێت؛ «پاشگر» تەنها بۆ Suffix. لە چاکسازیی داهاتوودا هەر occurrenceێک لە وانەکانی ١١ و ١٣ بە سیاق پشکنرێت؛ نابێت هەموو «پاشبەستە»کان بەبێ تێڕوانین بگۆڕدرێن.

### ٤. دۆزینەوەی سێیەم — Root و Stem لە وانەی ١٦ و ٢٨
- وانەی ١٦ بنجی ئێستا بە نموونەی «خۆ»، «کڕ» و «کە» دیاری دەکات و لە چاوگ و بنجی ڕابردوو جیا دەکاتەوە؛ ئەم جیاکردنەوەیە لە ئاستی paradigm ـی کردارەوە دروستە، بەڵام نابێت Stem لە هەموو سیاقێکدا بە Root یەکسان بکرێت.
- وانەی ٢٨ «Infinitive» بە چاوگ دەناسێنێت و دوو بنجی ڕابردوو/ئێستا لە یەکتر جیا دەکاتەوە؛ لە چەند شوێنێکدا Stem بەکار دەهێنێت، بەڵام «بنکە»ی تۆماری نوێ لە دەقی runtimeدا هێشتا occurrenceی نییە.
- بڕیاری نوێ: Root، Bound Root، Stem، Base و Lexeme بە پێی پێناسەی سەرچاوەیی جیا بمێننەوە؛ بنجی ئێستا و بنجی ڕابردووی کۆرسی سۆرانی وەک پارادایمی کردار لە تۆماری جیاوازدا پێناسە بکرێن، نە بە خۆکار Stem/Rootی یەکسان.

### ٥. دۆزینەوەی چوارەم — لکاوی کەسی لە وانەکانی ١١ و ١٢
- وانەی ١١ بە دروستی جیاوازیی فۆڕمی لکاو لە خاوەنداری و نیشانەکردنی بکەری ڕابردووی تێپەڕ دەناسێنێت.
- وانەی ١٢ هەمان پێوەر بە سیاق، تێپەڕی کردار و شوێنی لکاو پشتڕاست دەکاتەوە.
- هەمان فۆڕمی ـم/ـت/ـی/ـمان/ـتان/ـیان نابێت بە تەنها بە Possessive، Subject clitic یان Object clitic ناونرێت.
- ئەم بەشە لە ڕووی بنەمای فێرکارییەوە یەکگرتوویی باشی هەیە؛ لە چاکسازیی داهاتوودا تەنها ناهاوتاییی زاراوەی Enclitic/پاشبەستە چارەسەر بکرێت و نموونەکان بە پاراستنی سیاق بمێننەوە.
