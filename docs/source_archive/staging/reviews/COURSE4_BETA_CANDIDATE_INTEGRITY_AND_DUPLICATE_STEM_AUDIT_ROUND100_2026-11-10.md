## ٢. ئەنجامی پشکنینی داتایی
- ٥٠ وانە لە فایلە سەرەکییەکەدا هەن.
- ٢٤٨ کویزی سەرچاوەی وانەکانی ١–٣١ لە کاندیدی یەکخراودا بە تەواوی پارێزراون؛ بەراوردی array بە array هیچ جیاوازییەکی نەدۆزییەوە.
- ٩٥ کویزی ڕەشنووس بۆ وانەکانی ٣٢–٥٠ هەن؛ ٥ پرسیار بۆ هەر وانەیەک.
- کۆی کویزی کاندیدی یەکخراو: ٣٤٣ = ٢٤٨ی سەرچاوە + ٩٥ی ڕەشنووس.
- هەموو ٩٥ answer index لە سنووری هەڵبژاردەکانن.
- هەموو ٩٥ `source_answer_label` لەگەڵ answer index هاوتان؛ هیچ ناکۆکییەک نەدۆزرایەوە.
- ژمارەی هەڵبژاردەکان: ٣٣ پرسیار دوو هەڵبژاردە، ٢٧ پرسیار سێ هەڵبژاردە، ٣٥ پرسیار چوار هەڵبژاردە. ئەمە هەڵەی schema نییە، بەڵام پێویستی بە پێداچوونەوەی پەروەردەیی هەیە تا ئاستی پرسیارەکان یەکسان و گونجاو بێت.
- هیچ دووبارەبوونەوەی تەواوی تۆماری پرسیار (پرسیار + هەڵبژاردە + کلیلی وەڵام) نەدۆزرایەوە.
- ٥ سەرپەڕەی پرسیار لە وانە جیاوازەکاندا دووبارە بوونەتەوە؛ هەندێکیان بابەتیان جیاوازە، بەڵام پرسیاری وانەکانی ٣٢/٣٣ لەسەر جیاوازیی بکەر و ئەنجامدەری کردار هەمان دەق و هەمان هەڵبژاردە/کلیلە، و پێویستی بە بڕیاری فێرکاری هەیە. دووبارەبوونەوەی سەرپەڕە بە تەنها بەڵگەی دووبارەبوونی هەڵە نییە.
- ٩٥ explanation بەتاڵن؛ بە ئاگاداری پارێزراون، چونکە پێشتر بڕیار دراوە هیچ ڕوونکردنەوەیەکی ساختە زیاد نەکرێت.
