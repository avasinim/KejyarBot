## ٢. وانە بە وانە

### وانەی ٣٩ — Object، Recipient و Complement
- خاڵی بەهێز: جیاوازیی ئەرکی ڕێزمانیی Subject لە ڕۆڵی واتایی Agent و جیاوازیی Object لە Recipient/Goal ڕوون کراوەتەوە.
- پێویستی بە یەکخستن: «پێکهاتەی وەرگر/ئاراستە» لەگەڵ تۆماری V2 ی زاراوەکان بپارێزرێت تا بڕیاری کۆتایی لەسەر Indirect Object نەدرێت.
- پێویستی بە چاکسازی: پێناسەی Complement و Adjunct لەگەڵ وانەی ٣٦ یەکسان بکرێتەوە؛ تاقیکردنەوەی لابردنی Adjunct بە تەنها وەک پێوەری کۆتایی بەکارنەهێنرێت.
- نموونەی «کەژیار کتێبەکەی خوێندەوە» لە ئاستی گروپی ناوی، «کتێبەکە» Object ـە؛ ئەمە بڕیار لەسەر مۆرفیمی «ـی» نادات. ئەو مۆرفیمە دەبێت بە سیاق و مۆرفیم‌بەندیی جیاواز شیکار بکرێت.

### وانەی ٤٠ — Transitivity و Voice
- بنەمای وانەکە Transitivity لە توانای کردار و بەکارهێنانی ڕستەی دیاریکراو جیا دەکاتەوە؛ ئەم جیاوازییە بپارێزرێت.
- Transitivity و Voice دوو پێوەری جیاوازن؛ لە ڕاهێنان و خشتەی وەڵامدا دوو خانەی سەربەخۆیان بۆ دابنرێت.
- «دەرگاکە کرایەوە» بەبێ پشکنینی زاری و شیکاریی کردار نابێت بە یەکلا Passive دابنرێت؛ Middle/Anticausative هەڵبژاردەی شیکارییە و نابێت بە خۆکار لاببرێت.
- نموونەکانی «دزەکە گیرا» و «نامەکە نووسرا»ش پێویستیان بە پشتڕاستکردنەوەی زاری و فۆڕمی کردار هەیە.

### وانەی ٤١ — کردارە لێکدراوەکان
- «کرداری لێکدراو» لە دەقی وانەکەدا چەند پێکهاتەی جیاواز لەخۆدەگرێت: یەکەی فەرهەنگی، ناو + کردار، کردارە سووک/یارمەتیدەر و دەستەواژەی کرداری.
- پێشنیار: ئەم ئاستە جیاوازانە لە پێناسە و نموونەدا لێک جیا بکرێنەوە؛ «شەڕکردن»، «قسەکردن» و «سوێندخواردن» بە زاری ئامانج پشتڕاست بکرێنەوە.
- نابێت توخمی ناوی لە پێکهاتەی کرداردا بە خۆکار Object دابنرێت؛ پەیوەندیی فەرهەنگی/ڕێزمانییەکە دەبێت دیاری بکرێت.

### وانەی ٤٢ — Clitic و خاوەندارێتی
- جیاوازیی نێوان ئەرکی گروپی ناوی و ئەرکی مۆرفیمی لکاو بەردەوام بپارێزرێت.
- لە «کتێبەکەم»دا گروپی ناوی دەتوانێت Object بێت، بەڵام «ـم» لە ناو ئەو گروپەدا نیشانەی خاوەندارێتییە؛ ئەرکی گروپی ناوی نابێت بە مۆرفیمەکە بدرێت.
- فۆڕمەکانی «گرتمن»، «ناردمیت»، «گرتتن»، «گرتتانن»، «گرتمی» و «گرتنی» لە دەقی وانەکەدا پشکنین‌نەکراون؛ نابێت بۆ یاسای گشتی یان کویزی یەک وەڵامی بگۆڕدرێن.

### وانەی ٤٣ — Person markers لە کردارە تێپەڕەکاندا
- شیکاریی «ـی» لە «کتێبەکەی خوێندەوە» وەک Possessive لە وانەکەدا هاتووە؛ ئەم شیکارییە تەنها بۆ ئەو سیاقەی دیاریکراوە و نابێت بۆ هەموو فۆڕمی نووسراوی «ـی» گشتی بکرێتەوە.
- پێویستە زاری ئامانج، کۆنتێکست و مۆرفیم‌بەندیی ڕستەکە پشتڕاست بکرێنەوە؛ لکاوی هاوشێوە دەتوانێت ئەرکی کەسی/ڕێککەوتن یان خاوەندارێتی هەبێت.
- کویزی یەک وەڵامی لەسەر ئەم شیکارییە تا پشتڕاستکردنەوەی زاری هەڵبگیرێت.

### وانەی ٤٤ — Passive و Transitivity
- هەمان کێشەی بنەڕەتیی وانەی ٤٠ دووبارە دەبێتەوە: Voice لە Transitivity جیا بکرێتەوە.
- ڕاهێنانێک کە داوا دەکات ڕستەکان «نەکارا یان تێنەپەڕ» پۆلێن بکرێن، دوو پێوەری جیاواز تێکەڵ دەکات. پێشنیار: خشتەی دوو ستوونی Voice و Transitivity زیاد بکرێت، بە هەڵبژاردەی «پێویستی بە شیکاریی زیاتر».
- نموونەی «دەرگاکە کرایەوە» بەبێ بەڵگەی زاری و مۆرفۆسینتاکسی نابێت بە یەک شێوە Passive/Middle/Anticausative دیاری بکرێت.

### وانەی ٤٥ — Topic، Focus و ڕیزبەندیی وشە
- دەقی وانەکە بە دروستی ئاگاداری دەدات کە شوێنی سەرەتایی بە تەنها ئەرکی ڕێزمانی دیاری ناکات و بابەتکردن لە جەختکردن جیاوازە.
- پێویستی بە زیادکردنی سیاقی گوتار بۆ نموونەکان هەیە؛ Topic و Focus تەنها بە ڕیزبەندیی وشە یان جەختی دەنگی بەبێ سیاق دیاری نەکرێن.
- هەر نموونەیەک کە سروشتیبوونی لە زاری ستانداردی کۆرس پشتڕاست نەکراوەتەوە، بە نیشانی «پشکنینی زاری پێویستە» بمێنێتەوە.

### وانەی ٤٦ — Clause taxonomy و conjunction
- پێڕستە، سەرڕستە و بەرڕستە لە وانەکەدا بەکار هاتوون؛ بەپێی تۆماری V2، بڕیاری نێوان «بەرڕستە» و «ژێرەڕستە» هێشتا پەسەند نەکراوە.
- پێویستە Main/Subordinate لە Independent/Dependent جیا بکرێنەوە؛ ئەمانە هاوواتای یەکتر نین.
- «هاولکی» و «ئامرازی پەیوەندی» و هەروەها Coordinating/Subordinating Conjunction لە Discourse connective جیا بکرێنەوە. «هێشتا»، «بۆیە»، «کەوایە» و «بەڵکو» بە یەک پۆل مەخە.
- لە نموونەی «کاتێک باران بارێت، ئێمە لە ماڵەوە دەمێنینەوە و کەژیار کتێب دەخوێنێتەوە» سروشتیبوونی ڕستە و سنووری پێڕستەکان پێویستی بە پشکنینی زاری هەیە.

## ٣. ناکۆکییە هاوبەشەکان کە دەبێت لە هەموو وانەکاندا یەکسان بکرێن
1. **Subject / Agent / Patient:** ئەرکی ڕێزمانی لە ڕۆڵی واتایی جیا بکرێتەوە.
2. **Object / Recipient / Complement / Adjunct:** گروپی ناوی و ئەرکی مۆرفیمی یان پێکهاتەی پێشگر‌دار تێکەڵ نەکرێن.
3. **Clitic / Possessive / Person marker:** شێوەی نووسراوی هاوشێوە بە تەنها بۆ دیاریکردنی ئەرک بەس نییە.
4. **Transitivity / Voice:** دوو پێوەری سەربەخۆن.
5. **Lexical compound / light verb construction / verb phrase:** پێناسە و نموونەکان لێک جیا بکرێنەوە.
6. **Topic / Focus:** سیاقی گوتار پێویستە.
7. **Clause relations:** Main/Subordinate و Independent/Dependent جیا بپارێزرێن؛ هاولکی لە discourse connective جیا بکرێتەوە.
