### ١. سنووری کۆرس
- کۆرسی ٤ بە ٥٠ وانە کۆتایی دێت.
- Runtime JSON لە commit ـی پشکنراودا ٤٦ وانەی چالاکی تێدایە.
- وانەکانی ٤٧–٥٠ لە ڕەشنووسە archived V2 و پەکەیجی پشکنین پارێزراون؛ نەبوونیان لە runtime بەڵگەی کۆتایی کۆرس لە وانەی ٤٦ نییە.
- وانەی ٥٠ پاشکۆی Capstone ـی تێدایە؛ وانەی ٥١ نییە.

### ٢. هەرمی سەرچاوە
1. کتێبی سەعید کەرەمی «وشەناسیی زمانی کوردی (کرمانجیی ناوەڕاست)» و دەق و ماددە ڕاستەوخۆ نێردراوەکانی خاوەنی کۆرس، بنەمای کۆرسی ٤ن.
2. داتای کرمانجیی ناوەڕاست بەبێ بەراوردی زار و پارادایمی سۆرانی نابێت وەک یاسای سۆرانی بگوازرێتەوە.
3. کتێبی دیاکۆ هاشمی «پوختەی ڕێنووس و خاڵبەندی» تەنها بۆ کۆرسی ٣ی ڕێنووسی یەکگرتووە؛ لە کۆرسی ٤دا بە سەرچاوەی زانستیی ڕێزمان، مۆرفۆلۆژی یان سینتاکس بەکارنایەت.
4. ئاماژە ئەکادیمییەکانی ناو پاشکۆکان بە خۆکارانە نابنە سەرچاوەی پەسەندکراوی کۆرس؛ دەبێت لەگەڵ ماددەی خاوەنی کۆرس پشتڕاست بکرێنەوە.

### ٤. زاراوە یەکگرتووەکان
- Root = ڕەگ؛ Stem = بنج.
- Present Stem = بنجی ئێستا؛ Past Stem = بنجی ڕابردوو.
- Infinitive = چاوگ؛ Finite Form = فۆڕمی کەسی‌دار.
- Derivation = داڕشتن؛ Inflection = چەمانەوەی ڕێزمانی.
- Active Voice = کاری کارا؛ Passive Voice = کاری ناکارا.
- Transitive = تێپەڕ؛ Intransitive = تێنەپەڕ.
- Noun Phrase = گرێی ناوی؛ Verb Phrase = گرێی کرداری.
- Clause = پێڕستە؛ Main Clause = سەرڕستە؛ Subordinate Clause = ژێرەڕستە.
- بکەر/Subject ئەرکی ڕێزمانییە؛ Agent/ئەنجامدەری کردار ڕۆڵی واتایییە.
- Recipient/وەرگر ڕۆڵی واتایییە؛ نابێت بە خۆکارانە بە بەرکار یان تەواوکەری پێشبەندی یەکسان بکرێت.
- Clitic = پاشبەست؛ Suffix = پاشگر.
- Inflection = چەمانەوەی ڕێزمانی، لە جیاتی «لەچۆنایەتی».

### ٥. خاڵە هەستیارەکان بۆ چارەسەری کۆتایی
1. هەموو نموونەکانی ـی/ـیان/ـم بە سیاق بپشکنە؛ خاوەنداری، بکەری تێپەڕ و بەرکار یەک نین.
2. لکاوی کردار بە تەنها بەرکار نییە؛ لەوانەیە نیشانەی بکەر/ڕێککەوتن بێت.
3. نموونەی نەپشتڕاستکراوی سۆرانی لە کویزی یەک‌وەڵامیدا وەڵامی قطعی نەبێت.
4. کارا/ناکارا لە تێپەڕ/تێنەپەڕ جیا بکرێتەوە.
5. Valency لە تێپەڕی جیاوازە؛ تێپەڕی تەنها یەک ڕەهەندی Valency ـە.
6. پێڕستە بە ژمارەی کردار بە تەنها دیاری ناکرێت؛ پەیوەندیی هاوئاست/ژێرئاست شیکار بکرێت.
7. بابەتکردن لە جەختکردن جیاوازە؛ شوێنی وشە بە تەنها ئەرکی ڕێزمانی دیاری ناکات.
8. توخمی ناوی لە کردارێکی لێکدراو بە خۆکار بەرکار نییە.
9. ناونیشانی وانەی ٤٣ و نموونەکانی ناگونجێن؛ نموونەی لکاوی بەرکاری پشتڕاستکراوی سۆرانی پێویستە.
10. وانەکانی ٣٧–٣٨ و ٤٦ دەبێت یەک زاراوەی Subordinate Clause بەکاربهێنن؛ پێشنیاری پەکەیجی نوێ «ژێرەڕستە»یە و پێویستی بە تۆماری بڕیاری یەکگرتووی کۆرس هەیە.
11. لە وانەی ٣٤دا «نیهاد» و «بکەر» ناگونجێن؛ زاراوەی نوێ «بکەر» بێت.
12. Metadataی هەندێک ڕەشنووسی ٣٢–٤٦ بە هەڵە «کۆرسی ١ — بەشی ٤»ی نووسیوە؛ ئەمە هەڵەی metadata ـە، نە هەڵەی ژمارەی کۆرس.
