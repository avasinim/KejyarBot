# هاوسەنگکردنی شوێنی وەڵامی کویزەکانی وانەکانی ٣٢–٥٠ — Round 153

## هۆکاری چاکسازی
پشکنینی Round 152 نیشانی دا کە لە زۆرێک لە ٩٥ پرسیاری وانەکانی ٣٢–٥٠دا وەڵامی ڕاست بە زۆری لە indexی ١دا بوو. ئەمە پاتڕۆنی پێشبینیکراو دروست دەکرد.

## شێوازی چاکسازی
- بۆ هەر پرسیارێک تەنها شوێنی هەڵبژاردەی ڕاست گۆڕدرا؛ دەقی هەڵبژاردەکان نەگۆڕدرا.
- answer index بە پێی `(lesson_number + question_index_zero_based) mod 4` ڕێکخرا.
- هەر وانەیەک ٥ پرسیاری هەیە؛ لەبەر ئەوە هەر چوار index بەکار دەهێنرێن و یەک index دووبارە دەبێتەوە.
- پرسیار، explanation، کۆمەڵی هەڵبژاردەکان و دەقی وەڵامی ڕاست وەک خۆیان پارێزراون.

## ئەنجام
- ١٩ وانە × ٥ پرسیار = ٩٥ پرسیار.
- ٧٠ لە ٩٥ پرسیاردا شوێنی وەڵامی ڕاست گۆڕدرا.
- ٢٥ پرسیار شوێنی پێشوویان لەگەڵ target index یەکسان بوو و پێویستیان بە گۆڕین نەبوو.
- ٩٥/٩٥ پرسیار: دەقی پرسیار پارێزراو، explanation پارێزراو، کۆمەڵی هەڵبژاردەکان وەک خۆی، و دەقی وەڵامی ڕاست لە شوێنی نوێدا هەمانە.
- هەموو ١٩ candidate ـی نوێ status ـیان `inactive_candidate_not_approved` ـە.
