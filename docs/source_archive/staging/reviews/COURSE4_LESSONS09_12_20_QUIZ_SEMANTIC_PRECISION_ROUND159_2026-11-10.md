# وردکردنەوەی semantic ـی کویز لە وانەکانی ٩، ١٢ و ٢٠ — Round 159

## وانەی ٩
- پرسیاری ٥ لە «کام ڕستە زانستیترە؟» بۆ «کام بڕیار لەبارەی پێکهاتەی ژمارەکان دروستترە؟» گۆڕدرا، چونکە هەڵبژاردەکان بڕیار/بانگەشە بوون، نە ڕستە.
- لە پرسیاری ٧دا «چاوگ/کردار» بە «چاوگ (فۆڕمی ناوی کردار)» ورد کرا؛ explanation ڕوون دەکاتەوە کە «یەکگرتن» چاوگی کردارە.

## وانەی ١٢
- پرسیاری ٤ بە مەرجی خوێندنەوەی مەبەست ڕوون کرا: «ئەوان کتێبەکەیان خوێند» لە بەستێنی خاوەنداریدا خوێندنەوەیەکی تر دەتوانێت هەبێت؛ بۆیە stem ئەو خوێندنەوەیەی کە لە وەڵامدا مەبەستە دیاری دەکات.
- answer index و option set نەگۆڕاون.

## وانەی ٢٠
- وەڵامی hardly لە «بە دەگمەن/نزیکەی هیچ» بۆ «نزیکەی هیچ/بە ئەندازەیەکی زۆر کەم» ڕاستکرایەوە؛ چونکە rarely واتای «بە دەگمەن» دەدات، بەڵام hardly واتای scarcely/almost not هەیە.
- explanation جیاوازیی hardly و hard ڕوون دەکاتەوە.

## پاراستن
- هەموو candidate ـە نوێکان inactive_candidate_not_approved ـن.
- answer index ـەکان پارێزراون؛ لە وانەی ٩ و ٢٠ تەنها دەقی هەڵبژاردەی ڕاست ورد کرا، لە وانەی ١٢ تەنها stem و explanation.
- هیچ source JSON، runtime، Botkeep یان Telegram دەستکاری نەکراوە.
