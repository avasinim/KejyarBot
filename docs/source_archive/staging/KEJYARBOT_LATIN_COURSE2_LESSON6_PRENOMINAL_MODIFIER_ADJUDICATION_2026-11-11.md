## 1. Issue

Lesson 6 uses the paired label `pêşnavdêr/bireser` for `ev` in `ev keçik`. The same lesson names `bireserê navdêrê` as the noun-attached modifier in examples such as `hespê beza`. The terminology register also distinguishes bare `bireser` as a clause-level object role.

The slash construction is ambiguous because it appears to present two terms as synonyms without defining their relationship.

## 2. Evidence in the source-aligned Course 2 text

File: `course_data/latin_course_2_source_aligned_lessons_01_12.md`  
Blob SHA: `19090077a11dc9d7211987e958e560b328fcd3d6`

Lesson 6 says:
- `Bireserê navdêrê` is a word or group of words that describes, specifies, or adds information to a noun; it can occur before or after the noun.
- Pre-nominal examples include `ev keçik`, `kîjan mirov`, `çar xanî`, `hin çiya`, `çend kitêb`, `deh bizin`, and `van zarokan`.
- Post-nominal examples include `hespê beza`, `mehinên spehî`, and `xencera min`.
- The lesson explicitly warns that the noun-attached modifier is not the same as demonstrative pronouns `ev/ew).
- It then labels `ev` in `ev keçik` as `pêşnavdêr/bireser`, while saying that `Ev hat.` is a demonstrative pronoun because it stands independently.

This supports a distinction between (a) position before the noun and (b) the broader noun-modifying function. It does not establish that `pêşnavdêr` and `bireser` are synonyms.

## 3. Terminological distinctions to preserve

| Dimension | What the text supports | What must not be conflated |
|---|---|---|
| Position | `ev` occurs before `keçik` in `ev keçik` | Pre-nominal position alone does not define the full grammatical category |
| Noun-modifying function | `ev` specifies which noun is intended | This is not the same as a clause-level object |
| Clause-level role | `bireser` is used elsewhere for the object role in a clause | Do not shorten `bireserê navdêrê` to bare `bireser` where ambiguity results |
| Independent use | `Ev hat.` uses `ev` as a demonstrative pronoun | Do not classify by word form alone; syntactic use matters |

## 4. Provisional editorial recommendation

1. Do not retain `pêşnavdêr/bireser` as an unexplained slash-pair.
2. Keep `bireserê navdêrê` as the course's full label for the broader noun-attached modifier/complement function, including both pre- and post-nominal examples, pending source terminology verification.
3. Treat `pêşnavdêr` as a position-oriented label only if the primary grammar source confirms that usage; do not present it as an automatic synonym for `bireser`.
4. For `ev keçik`, a clearer teaching description could be: `ev` is a demonstrative form used attributively before the noun, specifying `keçik`. The category label should follow the source's actual terminology (for example, demonstrative adjective/modifier) after checking the original source.
5. Keep `Ev hat.` distinct as an independent demonstrative-pronoun use.
6. Keep the existing L6 Q3 repair proposal that uses the full term `bireserê navdêrê` for `beza` in `hespê beza`; do not use this adjudication to change its answer key.
