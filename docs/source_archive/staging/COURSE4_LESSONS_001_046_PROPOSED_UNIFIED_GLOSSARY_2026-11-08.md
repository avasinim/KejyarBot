# پێشنیاری زاراوەی یەکگرتوو — کۆرسی ٤، وانەکانی ١–٤٦
**بەروار:** 2026-11-08  
**برانچ:** `feat/course4-clean-port-main-20261106`  
**دۆخ:** پێشنیاری دەستکاری؛ هیچ زاراوەیەک بە فەرمی پەسەند نەکراوە.  
**پەیوەندی:** پشکنینی یەکگرتوویی وانەکانی ١–٤٦ و پشکنینە تایبەتییەکانی وانەکانی ٣٢–٤٦.

## ١. چۆنیەتی بەکارهێنان
ئەم بەڵگەنامەیە پێشنیاری یەکخستنی زاراوەکانە، نە فەرمانی گۆڕینی دەقی وانەکان. «پێشنیاری سەرەکی» تەنها ئەو شێوەیەیە کە بۆ بڕیاری خاوەن کۆرس پێشکەش دەکرێت. تا پەسەندکردن:
- دەقی خاو، ترانسکریپتی ئەرشیفی و نموونە سەرچاوەییەکان وەک خۆیان دەمێننەوە.
- هیچ وشەیەک بە خۆکار لە وانەکاندا ناگۆڕدرێت.
- لە ڕەشنووسە نوێکاندا دەتوانرێت پێشنیارەکان بە نیشانەی «پێشنیاری زاراوە» بەکاربهێنرێن، بەڵام نابێت وەک بڕیاری کۆتایی بناسرێن.
- زاراوەیەکی هاوتا لە تەنیشت زاراوەی سەرەکی تەنها ئەگەر پێناسە و جیاوازیی چەمکییەکەی ڕوون بێت بەکاربهێنرێت.

## ٢. خشتەی زاراوە سەرەکییەکان

| چەمکی ئینگلیزی | پێشنیاری سەرەکیی کوردی | دۆخ و ڕێنمایی |
|---|---|---|
| Subject | بکەر | پێشنیاری سەرەکی؛ ئەرکی ڕێزمانییە، نە پێویستە هەمیشە ئەنجامدەری کردار بێت. |
| Agent | ئەنجامدەری کردار | لە «بکەر» جیا بپارێزرێت؛ ڕۆڵی واتاییی ئەنجامدەرە. |
| Predicate | گوزارە | پێشنیاری سەرەکی؛ نابێت بە کاری ناتەواو یان تەنها کردار سنووردار بکرێت. |
| Verb | کردار | پێشنیاری سەرەکی بۆ پێکهاتەی کردار؛ «کار» تا بڕیاری کۆتایی وەک هاوتای ئۆتۆماتیکی بەکار نەهێنرێت. |
| Copula | کاری بەستەر | لە گوزارە جیاوازە؛ شێوەکانی «ـە»، «بوو»، «دەبێت» بە پێی ڕستە و ئەرک شیکار بکرێن. |
| Clause | پێڕستە | پێشنیاری سەرەکی؛ بنەمای پۆلێنکردنی ڕستە بە ژمارە و پەیوەندیی پێڕستەکان. |
| Main Clause | سەرڕستە | پێشنیاری سەرەکی. |
| Subordinate Clause | بەرڕستە / ژێرەڕستە | بڕیاری کۆتایی پێویستە؛ یەک شێوە هەڵبژێردرێت. |
| Object | بەرکار | پێشنیاری سەرەکی؛ لە تەواوکەر و ڕۆڵی واتاییی وەرگر/کاریگەربوو جیا بکرێتەوە. |
| Direct Object | بەرکاری ڕاستەوخۆ | پێشنیاری سەرەکی. |
| Indirect Object | بەرکاری ناڕاستەوخۆ | پێشنیاری کاتی؛ هەر گرووپی پێشگرەدارێک بە خۆکار بەرکاری ناڕاستەوخۆ نییە. |
| Complement | تەواوکەر | پێشنیاری سەرەکی، بەڵام پێویستە جۆری تەواوکەر دیاری بکرێت. |
| Adjunct | هاوەڵکار | پێشنیاری کاتی؛ لە تەواوکەر جیا بکرێتەوە. |
| Transitive Verb | کرداری تێپەڕ | پێشنیاری سەرەکی؛ بە پێی پێکهاتەی بەرکار/Valency دیاری بکرێت. |
| Intransitive Verb | کرداری تێنەپەڕ | پێشنیاری سەرەکی؛ «ناتێپەڕ» وەک شێوەی پێشووتر تۆمار بکرێت تا بڕیار. |
| Active Voice | ڕستەی کارا | پێشنیاری سەرەکی؛ لە Agent و Active Alignment جیاوازە. |
| Passive Voice | ڕستەی نەکارا | پێشنیاری سەرەکی؛ لە تێنەپەڕ جیاوازە. |
| Clitic | جێناوی لکاو | بۆ جێناوە لکاوەکان؛ ئەرکی هەر فۆڕمێک لە سیاقی ڕستەدا دیاری بکرێت. |
| Possessive | خاوەندارێتی | نیشانەی خاوەندارێتی لە گروپی ناویدا نابێت بە بەرکاری ڕستە تێکەڵ بکرێت. |
| Object Clitic | جێناوی لکاوی بەرکار | تەنها کاتێک فۆڕمەکە لەو پێکهاتەیەدا ئەرکی بەرکار هەبێت. |
| Simple Sentence | ڕستەی سادە | یەک پێڕستە؛ ژمارەی کردار بە تەنها پێوەر نییە. |
| Compound Sentence | ڕستەی لێکدراو | لانیکەم دوو سەرڕستەی هاوئاست/سەربەخۆ. |
| Complex Sentence | ڕستەی ئاڵۆز | سەرڕستە + لانیکەم یەک بەرڕستەی ژێرئاست. |
| Compound-Complex Sentence | ڕستەی لێکدراوی ئاڵۆز | لانیکەم دوو سەرڕستە و لانیکەم یەک بەرڕستە. |
| Coordinating Conjunction | هاولکی هاوئاست | پێشنیاری کاتی؛ پەیوەندیی دوو پێڕستەی هاوئاست. |
| Subordinating Conjunction | هاولکی بەرخەر | پێشنیاری کاتی؛ پێڕستەی ژێرئاست دەبەستێتەوە. |
| Topicalization | بابەتکردن | لە پێشخستنی بەرکار و جەخت جیا بێت. |
| Focus | جەخت | زانیاریی جەختکراو؛ هاوتای بابەتکردن نییە. |
| Object Fronting | پێشخستنی بەرکار | گۆڕینی شوێنی بەرکار؛ بە تەنها ئەرکی ڕێزمانی ناگۆڕێت. |

## ٣. زاراوە نادیارەکان و بڕیارە پێویستەکان

### ٣.١. بکەر یان نیهاد؟
- **پێشنیاری سەرەکی:** «بکەر» بۆ Subject.
- **پرسیاری بڕیار:** «نیهاد» هاوتای تەواوی Subject ـە، یان لە شیکاریی نیهاد/گوزارەدا چەمکێکی فراوانترە؟
- تا وەڵامدانەوە، «نیهاد» لە دەقی خاو و لە شوێنی خۆیدا دەمێنێتەوە؛ بە خۆکار ناگۆڕدرێت.

### ٣.٢. کردار یان کار؟
- **پێشنیاری سەرەکی:** «کردار» بۆ Verb.
- **پرسیاری بڕیار:** ئایا «کار» لە وانەکانی پێشوودا بە واتای Predicate بەکارهاتووە، یان تەنها هاوتای کۆنی Verb ـە؟
- «گوزارە» بۆ Predicate بە جیاوازی بپارێزرێت.

### ٣.٣. کارا/نەکارا یان چالاک/نەچالاک؟
- **پێشنیاری سەرەکی:** «ڕستەی کارا/ڕستەی نەکارا» بۆ Active/Passive Voice.
- **پرسیاری بڕیار:** ئایا لە وانەی ١٨ «چالاک/نەچالاک» بۆ چەمکێکی دیکە بەکارهاتووە؟
- جیاوازیی Voice لە Alignment بە تەواوی بپارێزرێت.

### ٣.٤. تێنەپەڕ یان ناتێپەڕ؟
- **پێشنیاری سەرەکی:** «کرداری تێنەپەڕ».
- **پرسیاری بڕیار:** ئایا ئەم شێوەیە لەگەڵ ڕێنووسی فەرمیی کۆرس دەگونجێت، یان «ناتێپەڕ» هەڵبژێردرێت؟

### ٣.٥. بەرڕستە یان ژێرەڕستە؟
- **پێشنیاری کاتی:** «بەرڕستە» لەگەڵ «سەرڕستە»دا هاوتەریبە لە ڕووی ناونان.
- **پرسیاری بڕیار:** ئایا «ژێرەڕستە» لە ڕووی زانستی و ڕوونیی فێرکاری باشترە؟ یەکێک هەڵبژێردرێت و لە وانەکانی ٣٢، ٣٧، ٣٨، ٤٦ یەکسان بکرێت.

### ٣.٦. هاولکی هاوئاست/بەرخەر
- پێویستە دیاری بکرێت ئایا ئەمانە ناوی پۆلی وشەن یان ناوی ئەرکی پەیوەندیی پێڕستەکان؛ ئەم دوو ئاستە لە ڕوونکردنەوەدا تێکەڵ نەکرێن.

### ٣.٧. تەواوکەر/هاوەڵکار
- «تەواوکەر» بە پێی پێویستیی پێکهاتەی کردار/ناو/گوزارە پۆلێن بکرێت.
- «هاوەڵکار» بۆ زانیاریی زیادەی نەهەڵبژێردراو بەکاربهێنرێت، بەڵام پێویستی بە پشکنینی هەر نموونەیەک هەیە.
- هەر پێکهاتەی دوای کردار بە خۆکار تەواوکەر نییە.

## ٤. یاساکانی بەکارهێنانی یەکگرتوو
1. لە یەکەم بەکارهێناندا: زاراوەی کوردی + هاوتای ئینگلیزی؛ دوای ئەوە تەنها زاراوەی کوردی.
2. زاراوەی یەک چەمک لە سەرتاسەری کۆرسدا بە هەمان شێوە بنووسرێت.
3. هاوتا و شێوەی پێشووتر لە پاشکۆی زاراوەکاندا تۆمار بکرێن، نەک بە شێوەی هەڕەمەکی لە ناو دەق.
4. ناوی کەس لە نموونەکاندا بە پێی داواکاریی پڕۆژە یەکسان بکرێت؛ دەقی خامی ئەرشیف نەگۆڕدرێت.
5. نموونەی زاریی نادڵنیا بە زار/کۆنتێکستی دیاریکراو نیشان بدرێت؛ شێوەیەکی زارێک بە یاسای گشتیی هەموو کوردی دانەنرێت.
6. پێشنیاری زاراوە بە مانای پەسەندکردن نییە؛ گۆڕینی وانەکان تەنها دوای بڕیاری خاوەن کۆرس.

## ٥. پلانی جێبەجێکردن دوای بڕیار
1. بڕیارەکان لە بەشی ٣دا تۆمار بکرێن.
2. تەنها ڕەشنووسە پەرەپێدراوەکان چاک بکرێنەوە؛ دەقی خام و ترانسکریپتی ئەرشیفی وەک خۆی بمێنێتەوە.
3. هەر گۆڕانکارییەک لەگەڵ پێش/دوای، ژمارەی وانە و هۆکاری زانستی تۆمار بکرێت.
4. دووبارە پشکنینی ١–٤٦ بۆ زاراوە، پێناسە، نموونە، ڕاهێنان و وەڵام ئەنجام بدرێت.
5. پەسەندکردنی خاوەن کۆرس بەڵگەدار بکرێت.
6. تەنها بە ڕێگەی قۆناغی جیاواز و دوای مۆڵەتی ڕوون، گواستنەوە بۆ runtime هەڵبسەنگێندرێت.

## ٦. پاراستن و دۆخی runtime
- ئەم فایلە تەنها پێشنیاری زاراوەییە.
- هیچ وانەیەک لە JSONی runtime زیاد یان چالاک نەکراوە.
- هیچ دەقی خاو یان ئەرشیفی نەگۆڕدراوە.
- `main`، deploy branch، manifest، `courses.json`، کۆد، داتابەیس، `.env` و Botkeep دەستکاری نەکراون.
- هیچ merge، deploy، sync یان restart ئەنجام نەدراوە.
