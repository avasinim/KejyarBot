# Course 2 — Lesson 4 source collation: number examples
Date: 2026-11-10
Branch: `archive/preservation-audit-2026-11-10`
Primary source: Celadet Alî Bedir-Xan, *Elfabêya kurdî & Bingehên gramera kurdmancî*, Nefel, Stockholm, 2002.

## Source pages checked

- Printed p.55, §47–50: definition of number; singular/plural distinction; examples with `Mîr`, `mehîn`, `hesp`, and `çiya`.
- Printed p.56, continuation and §51: examples `Ev kurê kê ye? / Ev kurên kê ne?`, `Mehîne xwar. / Mehînan xwar.`, `Tu vî hespî dibînî? / Tu van hespan dibînî?`; proper names are not normally pluralized, except in figurative/metaphorical usage.
- Printed p.64, §66: the indefinite suffixes `-ek`, `-ek`, `-in`, with exact pairs including `hespek hat / hespin hatin`, `Mehînek hat / Mehînin hatin`, `Min hespek dît / Min hespin dîtin`, `Min mehînek dît / Min mehînin dîtin`, `Ev hespek e / Ev hespinin in`, `Ev mehînek e / Ev mehînin in`. This confirms the lesson's `hespek/hespin` and `mehînek/mehînin` suffix examples are source-supported and should not be removed.

## Verified corrections in the reviewed draft

In `course_data/latin_course_2_reviewed_draft_2026-11-10.md`, Lesson 4:
- `Ev mehin e` → `Ev mehîn e`
- `Ev mehin in` → `Ev mehîn in`
- `Min mehin dît` → `Min mehîn dît`
- `Min mehin dîtin` → `Min mehîn dîtin`
- `Ez mehinê dibînim` → `Ez mehînekê dibînim`
- Exercise comparison updated from `Ev mehin e/Ev mehin in` to `Ev mehîn e/Ev mehîn in`.

The source p.55 table has `Ez mehînekê dibînim / Ez mehînan dibînim`; the course now follows those exact forms. The other `-ek/-in` pairs in the explanatory note and quiz remain because §66 on p.64 confirms them.

## Interpretive note

The course's explanation that `Mîr` in `Mîr hat / Mîr hatin` is a common noun/title rather than a proper personal name is a pedagogical interpretation of the source's number example, consistent with §51's note that proper names are not ordinarily pluralized. It is not presented as a verbatim source statement.
