### Lesson 9 — X, Y, Z
- **Confirmed orthographic errors:** `yêk` should be checked/corrected to `yek`; `çîya` should be checked/corrected to `çiya`. They recur in tables, exercises and quiz text.
- **Confirmed question wording error:** Q5 asks “Di peyva çîya de Y çi erkê heye?” and the answer key says “Dengdar e”. This tests the role of Y in the word, but the lesson's stated scope is letter-classification; better wording is “Di peyva çiya de Y di kîjan komê de tê hesibandin?” so the question tests the stated alphabetic classification, not an ambiguous phonetic function.
- Quiz answer letters 1–5 match the answer key (A, A, C, B, A), but Q5 needs the wording correction above. Correct spelling must be propagated to Q3/Q4 options and all lesson occurrences.
- Scientific caution: the source's inventory classifies Y among 23 consonant letters. Explain that this is the source's alphabetic classification and does not erase the phonetic complexity of [j] / glide behavior in actual speech.

### Lesson 10 — sound and letter
- Core distinction (sound is heard; letter is written) is pedagogically sound.
- Examples C/Ç, E/Ê, I/Î, S/Ş, U/Û correctly illustrate distinct graphemes; do not state that orthography records every fine phonetic variation.
- Quiz answer letters checked: Q1 B, Q2 B, Q3 B, Q4 B, Q5 A. No key mismatch identified.
- Minor phrasing: “Mînak, dema em av, mal an jin dibêjin, dengên wan dibihîzin.” is awkward because speakers pronounce words; learners hear the sounds. Rephrase in future edit as “Dema em peyvên av, mal an jin dibêjin, dengên wan bi guh têne bihîstin.”

### Lesson 11 — letter frequency tables

- Text correctly distinguishes the overall table from the word-initial table and correctly warns that counts are source-table data, not universal frequencies.
- Quiz answer letters checked: Q1 A, Q2 B, Q3 C, Q4 A, Q5 D. No key mismatch identified.
- Source-level caution: verify the exact table headings, sample/corpus basis and all copied values against printed pp. 33–34 before claiming frequency rankings outside the book. Current lesson cites only selected values.
