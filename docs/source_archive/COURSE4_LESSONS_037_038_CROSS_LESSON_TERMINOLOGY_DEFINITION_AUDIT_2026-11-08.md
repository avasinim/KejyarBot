## ٢. پێڕستە لە بەرامبەر ڕستە
### بەڵگەی دەقی خاو
- لە وانەی ٣٧دا ڕستەی سادە بە تاکە پێڕستە پەیوەست کراوە؛ بەڵام هەمان بەش لە شوێنێکی تر «تەنها یەک کردار» و «یەک بکەر و بەروتار» وەک پێوەر دەهێنێت.
- لە وانەی ٣٨دا `پێڕستە` بەرامبەر Clause بەکارهاتووە، بەڵام هەندێک جار `شێوەڕستە` و فۆڕمەکانی `پیڕستە`/ `پێڕستە`یش هەن.
- لە وانەی ٣٢دا پێناسەی پێڕستە هێشتا لە هەندێک ڕەشنووسدا بە کردار یان پێکهاتەی هەواڵدەرەوە گرێدراوە؛ پاشکۆی وانەی ٣٢ پێشتر داوای جیاکردنەوەی ڕستە و پێڕستەی کردووە.

### کێشە و پێشنیار
1. `ڕستە` بۆ Sentence و `پێڕستە` بۆ Clause بپارێزرێت؛ ئەم دووە بە یەک ناونەبرێن.
2. `شێوەڕستە` لە دەقی وانەی ٣٨دا بەکارهاتووە، بەڵام پێناسەیەکی جیاوازی بۆی نییە. تا خاوەن دەق مەبەستی ئەم فۆڕمە ڕوون نەکاتەوە، نابێت وەک زاراوەیەکی سێیەم هاوتای پێڕستە دابنرێت.
3. `پێڕستە` وەک فۆڕمی ستانداردی نووسین هەڵبژێردرێت؛ `پیڕستە` و `بپێڕستە` لە شوێنەکاندا وەک جیاوازیی نووسین/هەڵەی تایپی تۆمار بکرێن، نەک زاراوەی نوێ.
4. پێناسەی ڕستەی سادە بە «یەک کردار» مەبەستەکە ناگرێتەوە؛ پێوەری سەرەکی دەبێت یەک پێڕستەی سەربەخۆ بێت. ژمارەی کردار بە تەنیا پێوەر نییە، بە تایبەتی لە ڕستەی بەستەری و کردارە هاوبەستەکاندا.
5. پێناسەی ڕستەی لێکدراو بە «زیاتر لە یەک بکەر یان بەروتار» بەس نییە؛ پێویستی بە لانیکەم دوو پێڕستەی سەربەخۆی هاوئاست هەیە.

## ٣. دوو ئاستی شیکاری: سەربەخۆ/پشتبەستە و سەرڕستە/بەرڕستە
### بەڵگەی دەقی خاو
وانەی ٣٨ لە شوێنێکدا دەڵێت «پێڕستەی سەرەکی سەربەست یان سەرڕستە» و «پێڕستەی پشتبەست dependent ... بەرڕستە subordinate clause». لە کورتەی کۆتاییدا سەربەخۆ/پشتبەستە بە independent/dependent و سەرڕستە/بەرڕستە بە main/subordinate دەناسێنێت.

### کێشە و پێشنیار
- `سەربەخۆ / پشتبەستە` تایبەتمەندیی سەربەخۆییی پێڕستە دەستنیشان دەکات.
- `سەرڕستە / بەرڕستە` ئەرک و پلەی پێڕستە لە پێکهاتەی گەورەتر دەستنیشان دەکات.
- لە نموونەی ئاساییدا سەرڕستە زۆرجار سەربەخۆ و بەرڕستە زۆرجار پشتبەستەیە؛ بەڵام ئەمانە دوو جفتی زاراوەیی بە دوو پرسیاری شیکاریی جیاوازن، نابێت وەک هاوواتای تەواو وانەبێن.
- `سەربەست` و `پشبەست` لە کورتەی زاراوەکانی دەقی خاوەدا لەگەڵ `سەربەخۆ` و `پشتبەستە` یەکسان نین لە ڕووی نووسین؛ پێشنیار دەکرێت فۆڕمی یەکگرتووی `سەربەخۆ / پشتبەستە` بەکاربهێنرێت و فۆڕمە کورت/هەڵەنووسراوەکان بەبێ بڕیاری خاوەن دەق لە دەقی خامدا نەگۆڕدرێن.

## ٤. هاولک، هاولکی بەرخەر و ئامرازی پەیوەندیی بریناویی
### ٤.١ تێکەڵبوونی لیستی وانەی ٣٧
لە ترانسکریپتی وانەی ٣٧دا ئەم لیستە بە ناوی «هاولک» هاتووە: `و، بەڵام، یان، نە…نە، بۆیە، هێشتا`؛ دواتر لیستی فراوانتر `کەوایە، بەڵکو، بەشکم`یشی تێدا زیاد دەکات. ئەم لیستە لە ڕووی ئەرکی ڕێزمانی و واتاییەوە یەکجۆر نییە.

| فۆڕم | ئەوەی لە نموونەدا دەردەکەوێت | بڕیاری پشکنین |
|---|---|---|
| و | دوو پێکهاتە/پێڕستەی هاوئاست دەبەستێتەوە | نموونەی ڕوونی هاوبەندی/لێکدان |
| بەڵام | پەیوەندیی دژبەیەک | هاوبەندیی دژبەیەک؛ سنووری ئەو دوو پێکهاتەیە دیاری بکرێت |
| یان…یان | هەڵبژاردنی دوولایەنە | هاوبەندیی هەڵبژاردن |
| نە…نە | هاوبەندیی نەرێیی | پێکهاتەی دوولایەنەی نەرێیی |
| بەڵکو | ڕاستکردنەوە/گۆڕینی ئاراستەی دەربڕین | بە خۆکار هاوبەندیی دوو پێڕستەی سەربەخۆ نییە |
| هێشتا | لە نموونەی «دوو سێوی خوارد، هێشتا حەزی لە هی ترە»دا واتای بەردەوامی/تا ئێستا دەدات | زۆرجار هاوەڵکارە؛ پۆلێنی پەیوەندیی نێوان دوو بەش لە پۆلی وشە جیا بکرێتەوە |
| بۆیە | پەیوەندیی هۆکار/ئەنجام | پەیوەندیی دەرئەنجامە؛ نابێت بە خۆکار لەگەڵ «و» یەک پۆل بکرێت |
| کەوایە | پەیوەندیی دەرئەنجام؛ لە نموونەکەدا بەشی دووەم داخوازییە | پەیوەندیی واتایی لە پۆلێنی ڕێزمانی و جۆری پێڕستە جیا بکرێتەوە |
| بەشکم | پارتیکڵی گومان/ئەگەری | ئامرازی لێکدان نییە |
| چونکە | پێڕستەی هۆکاریی پشتبەستە دەناسێنێت | هاولکی بەرخەر/ئامرازی بەرخەر لە نموونەی خاوەدا |
| بەرلەوەی، لەدوای ئەوەی، لەکاتێکدا | پێکهاتەی فرەوشەیی کە پێڕستەی پشتبەستە دەناسێنێت | پێکهاتەی بەرخەری فرەوشەیی؛ نابێت بە تاک‌وشە شیکاری بکرێت |

### ٤.٢ جیاوازیی ناونان لە وانەی ٣٨
وانەی ٣٨ «هاولکی بەرخەر» بۆ `چونکە` و `لەکاتێکدا` بەکار دەهێنێت؛ هەروەها `ئامرازی پێوەندیی بریناویی` بۆ `کە، کو، ئەوەی` دەهێنێت. ئەمانە لە دەقی خاوەدا بە پێناسەی ورد و نموونەی هەموو بەکارهێنانەکان پشتڕاست نەکراونەتەوە.

### ٤.٣ پێشنیاری یەکسانکردن
1. `هاولک` و `ئامرازی لێکدان` لە نموونەکانی پێڕستە هاوئاستەکاندا بە پێناسەیەکی ڕوون جێگیر بکرێن؛ لە ناونانی ورددا دەتوانرێت `هاولکی لێکدان` بۆ coordinator بەکاربهێنرێت، ئەگەر خاوەن دەق پەسەندی بکات.
2. `هاولکی بەرخەر` یان `ئامرازی بەرخەر` بۆ subordinator بەکاربهێنرێت؛ یەک فۆڕم هەڵبژێردرێت و لە هەموو وانەکاندا بپارێزرێت.
3. `ئامرازی پەیوەندیی بریناویی` بە جیا بمێنێتەوە؛ نابێت بە خۆکار هاوتای هاولکی لێکدان یان بەرخەر دابنرێت. ئەرکی `کە، کو، ئەوەی` لە هەر نموونەیەکدا بە سیاق و جۆری پێڕستە دیاری بکرێت.
4. `بۆیە` و `کەوایە` لە پەیوەندیی واتاییی دەرئەنجامدا شیکاری بکرێن؛ پێویستە پۆلێنی ڕێزمانییان لە نموونەی کوردیی دیاریکراودا پشتڕاست بکرێتەوە.
5. `هێشتا` و `بەشکم` لە لیستی هاولکدا بە تەنیا بەهۆی ئەوەی دوو بەش لە دەربڕینەکەدا پێکەوە دێن، دانەنرێن.

## ٥. خاڵی تایبەت: پێناسەی ئاڵۆز و ژمارەی پێڕستە
لە وانەی ٣٨دا دەق دەڵێت «هەموو ڕستەیەکی ئاڵۆز پێک دێت لە دوو پێڕستە»؛ بەڵام لە هەمان بەشدا دەڵێت ڕستەیەک دەتوانێت زیاتر لە یەک سەرڕستە و زیاتر لە یەک بەرڕستەی تێدا بێت. ئەم دوو بانگەشەیە پێکەوە ناگونجێن.
**پێشنیار:** پێناسەکە بگۆڕدرێت بۆ «لانیکەم یەک پێڕستەی سەربەخۆ و لانیکەم یەک پێڕستەی پشتبەستە»؛ ژمارەی پێڕستەکان بە پێی نموونە دەستنیشان بکرێت، نە بە دوو دانە سنووردار بکرێت. ئەم گۆڕانە تەنها پێشنیارە و دەقی خاو نەگۆڕدراوە.

## ٦. بەراورد لەگەڵ وانەی ٤٦
وانەی ٤٦ فۆڕمەکانی `ڕستەی سەربەخۆ` و `ژێرەڕستە` بەکار دەهێنێت، و لە پێناسەی ڕستەی سادە/لێکدراودا `پێکهاتەی ڕستەیی` دەهێنێت. ئەمە لە ڕووی ناونانەوە لەگەڵ وانەی ٣٨دا جیاوازییەکی گرنگە:
- `ژێرەڕستە` لە وانەی ٤٦ هاوتایەکی پێشنیارکراوە بۆ subordinate clause، لە کاتێکدا وانەی ٣٨ `بەرڕستە` بەکاردەهێنێت.
- `پێکهاتەی ڕستەیی` لە وانەی ٤٦ هێندە ورد نییە کە هەموو جار جێگرەوەی Clause بێت.
- `سەرڕستە/بەرڕستە` لە وانەی ٣٨ و `ڕستەی سەربەخۆ/ژێرەڕستە` لە وانەی ٤٦ نابێت بەبێ بڕیاری خاوەن پڕۆژە تێکەڵ یان یەکگرتوو بکرێن.

**پێشنیاری بڕیاردان:** یەک جفتی زاراوە بۆ main/subordinate clause هەڵبژێردرێت. بەڵگەی زۆرتر لە دەقی خاو و بەکارهێنانی کۆرسی کەژیار پێویستە بۆ بڕیاری کۆتایی؛ ئەم audit ـە بە خۆی مافی گۆڕینی `بەرڕستە` بۆ `ژێرەڕستە` یان پێچەوانەکەی نادات.

## ٧. تۆماری پێشنیاری زاراوەیی بۆ پەسەندکردن
| چەمک | فۆڕمی پێشنیارکراو | تێبینی |
|---|---|---|
| Sentence | ڕستە | لە پێڕستە جیا بپارێزرێت |
| Clause | پێڕستە | فۆڕمی نووسینی یەکگرتوو |
| Independent / Dependent clause | پێڕستەی سەربەخۆ / پشتبەستە | ئاستی سەربەخۆیی |
| Main / Subordinate clause | سەرڕستە / بەرڕستە یان ژێرەڕستە | تەنها دوای بڕیاری خاوەن پڕۆژە یەک جفت هەڵبژێردرێت |
| Coordinating conjunction | هاولک / ئامرازی لێکدان | پێناسە و ناونانی ورد پێویستی بە پەسەندکردن هەیە |
| Subordinator | هاولکی بەرخەر / ئامرازی بەرخەر | یەک فۆڕم هەڵبژێردرێت |
| Complementizer | ئامرازی پێوەندیی بریناویی | لە دوو جۆری سەرەوە جیا بپارێزرێت |

## ٨. بڕیاری پشکنین و سنووری کار
- ناکۆکیی سەرەکیی وانەی ٣٧ لە پۆلێنکردنی فراوانی «هاولک»ە؛ لیستی خاو هەموو وشەکان لە یەک پۆلی ڕێزمانیدا کۆ دەکاتەوە.
- وانەی ٣٨ جیاوازیی coordinator/subordinator هەیە، بەڵام «ئامرازی پەیوەندیی بریناویی» پێویستی بە پێناسەی تایبەت و نموونەی سیاقی هەیە.
- پێڕستە/ڕستە، سەربەخۆ/پشتبەستە، سەرڕستە/بەرڕستە دەبێت وەک جفتە زاراوەی جیاوازەکان بپارێزرێن.
- جیاوازیی وانەی ٣٨ `بەرڕستە` و وانەی ٤٦ `ژێرەڕستە` هێشتا بڕیاری یەکلاکەرەوەی نییە.
- بانگەشەی فەرهەنگەکانی Oxford/Cambridge لە دەقی خاو هاتووە، بەڵام لەم audit ـەدا بە سەرچاوەی ڕاستەوخۆ پشتڕاست نەکراوەتەوە.
- هیچ دەقی خاو، ترانسکریپت، JSON، runtime، DB، `.env`، Botkeep، PR یان branchی چالاک نەگۆڕدراوە. هیچ merge/deploy/sync/restart/migration نەکراوە.
- ئەم بەڵگەنامەیە پشکنین و پێشنیارە؛ هیچ زاراوەیەک بە شێوەی فەرمی پەسەند نەکراوە.
