## ٣. ستانداردی زاراوەیی بۆ پشکنینی دواتر
ئەمە پێشنیاری پشکنینە، نەک بڕیاری پەسەندکراو:
- **بکەر** بۆ ئەرکی ڕێزمانیی Subject؛ **ئەنجامدەری کردار** بۆ ڕۆڵی واتایی Agent.
- **بەرکار** ئەرکێکی دیاریکراوی کردارە؛ **تەواوکەر** چەمکێکی فراوانترە و دەبێت جۆرەکەی دیاری بکرێت.
- **کاری تێپەڕ/تێنەپەڕ** لە **کارا/نەکارا** جیا بکرێتەوە.
- **پێڕستەی سەربەخۆ/پشتبەستە** لە **سەرڕستە/بەرڕستە** جیا بکرێتەوە.
- **بابەتکردن** و **جەختکردن** بە دوو چەمکی جیاواز بمێننەوە.
- **سادە/لێکدراو** هەمیشە لەگەڵ ئاستی شیکارییەکە بنووسرێن: ڕستە یان کردار.

## ٤. ڕیزبەندیی چاکسازی
١. یەکلاکەرەوەکردنی بنەمای زاراوەیی لەگەڵ خاوەن پڕۆژە؛ بەتایبەتی بکەر/ئەنجامدەری کردار، کار/کردار و پێڕستە/ڕستە.  
٢. چاککردنی کلیلی وەڵامی وانەی ٤٠ و هاوتاکردنەوەی نموونەکانی ٤٢–٤٣.  
٣. ڕوونکردنەوەی پێناسەی بەرکاری ناڕاستەوخۆ و تەواوکەری پێشگر لە وانەی ٣٩.  
٤. پشکنینی فۆڕمی کردار و سیاقی بابەتکردن لە وانەی ٤٥.  
٥. یەکخستنی پۆلێنی وانەی ٤٦ لەگەڵ وانەی ٣٧ و ڕێکخستنی ڕاهێنان و کلیلی وەڵام.  
٦. دوای پەسەندی خاوەن پڕۆژە، دروستکردنی وەشانی نوێی وانەکان؛ پاشان پشکنینی runtime بە جیاوازی.
