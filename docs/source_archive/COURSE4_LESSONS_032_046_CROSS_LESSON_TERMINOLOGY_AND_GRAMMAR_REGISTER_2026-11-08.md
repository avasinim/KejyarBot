## ٢. تۆماری زاراوەی یەکگرتوو — پێشنیاری کار
| چەمکی ئینگلیزی | فۆڕمی کوردیی پێشنیارکراو | جیاوازیی پێویست |
|---|---|---|
| Sentence | ڕستە | یەکەی تەواوی دەربڕین؛ نابێت بە Clause یەکسان بکرێت. |
| Clause | پێڕستە | یەکەی ڕێزمانیی پێڕستەیی؛ هەر کردارێک بە تەنیا پێڕستە دروست ناکات. |
| Subject | بکەر | ئەرکی ڕێزمانی؛ لە ئەنجامدەری کردار جیاوازە. |
| Agent | ئەنجامدەری کردار | ڕۆڵی واتایی؛ لە ڕستەی نەکارادا دەکرێت بە پێکهاتەی پێشگر‌دار دەربکەوێت. |
| Predicate | گوزارە | پێکهاتەی هەواڵدەر؛ تەنها کردار نییە. |
| Verb | کردار | پۆلی وشە/ناوەندی کردار؛ لە گوزارە جیاوازە. |
| Object | بەرکار | ئەرکی ڕێزمانی؛ لە تەواوکەر جیاوازە. |
| Complement | تەواوکەر | پێکهاتەی پێویست/تەواوکەری سەرەوە؛ نابێت بە هەموو پێکهاتەی دەرەوەی بکەر و کردار بگوترێت. |
| Adjunct | هاوەڵکار/پێکهاتەی زیادە | هەڵبژاردنی فۆڕمی کۆتایی پێویستی بە بڕیاری خاوەن پڕۆژە هەیە. |
| Independent Clause | پێڕستەی سەربەخۆ | ئاستی سەربەخۆیی پێڕستە. |
| Dependent Clause | پێڕستەی پشتبەستە | ئاستی پشتبەستەیی پێڕستە. |
| Main Clause | سەرڕستە | ئەرکی پێڕستە لە پێکهاتەی فرە-پێڕستەدا. |
| Subordinate Clause | بەرڕستە | پێشنیاری پێشوو؛ لەگەڵ «ژێرەڕستە»ی وانەی ٤٦ دەبێت یەکلا بکرێتەوە. |
| Transitive / Intransitive | تێپەڕ / تێنەپەڕ | پێوەری توانای وەرگرتنی بەرکار؛ بە Active/Passive تێکەڵ ناکرێت. |
| Active / Passive | کارا / نەکارا | پێوەری ڕێکخستنی ڕستە و ڕۆڵەکان؛ بە تێپەڕ/تێنەپەڕ یەکسان نییە. |
| Topicalization | بابەتکردن | هێنانە پێشەوەی بابەتی گفتوگۆ؛ بە Focus جیاوازە. |
| Focus | جەختکردن | دیاریکردنی زانیاریی جەختکراو؛ نابێت بە هەر گۆڕینی ڕیزبەندی یەکسان بکرێت. |
| Coordinating conjunction | ئامرازی لێکدان | پەیوەندیی هاوتەراز. |
| Subordinating conjunction | ئامرازی بەرخەر | پێڕستەی پشتبەستە دەبەستێتەوە بە پێکهاتەی سەرەکی. |
| Clitic | لکاو | پێکهاتەی مۆرفۆلۆژی؛ لە جێناوی سەربەخۆ جیاوازە. |
| Preposition / Prepositional phrase | پێشبەند / دەستەواژەی پێشگر‌دار | پۆلی ئامراز لە پێکهاتەی تەواوی دەستەواژە جیاوازە. |

**تێبینی:** ئەم خشتەیە ڕێنماییی کارە، نە بڕیاری کۆتایی. بە تایبەتی «Adjunct»، «Subordinate Clause»، «نیهاد» و «کاری بەستەر» پێویستیان بە بڕیاری خاوەن پڕۆژە و ڕوونکردنەوەی چوارچێوەی زانستی هەیە.

## ٣. یاساکانی شیکاری کە دەبێت لە هەموو وانەکاندا بپارێزرێن
1. **ڕستە ≠ پێڕستە:** پۆلێنی ڕستە بە ژمارە و پەیوەندیی پێڕستەکان دیاری دەکرێت، نە بە ژمارەی کردارەکان بە تەنیا.
2. **بکەر ≠ ئەنجامدەری کردار:** یەکەم ئەرکی ڕێزمانییە، دووەم ڕۆڵی واتاییە.
3. **گوزارە ≠ کردار:** گوزارە لە ڕستەی ناوی/هاوەڵناویشدا هەیە و دەتوانێت لە کردار فراوانتر بێت.
4. **بەرکار ≠ تەواوکەر:** بەرکار ئەرکی دیاریکراوی ڕستەییە؛ تەواوکەر چەمکێکی فراوانترە و پێویستی بە پێناسەی دیاریکراو هەیە.
5. **تێپەڕ/تێنەپەڕ ≠ کارا/نەکارا:** دوو پێوەری جیاوازن؛ نابێت لە وانەی ٤٠ و ٤٤دا یەک پێناسەیان بۆ دابنرێت.
6. **سەربەخۆ/پشتبەستە ≠ سەرڕستە/بەرڕستە:** جوتەی یەکەم سەربەخۆیی پێڕستە دەسەلمێنێت؛ جوتەی دووەم ئەرکی پێڕستە لە پێکهاتەی فرە-پێڕستەدا.
7. **پێشگر ≠ دەستەواژەی پێشگر‌دار:** پێشبەند ئامرازە؛ دەستەواژەی پێشگر‌دار پێکهاتەیەکی تەواوە.
8. **بابەتکردن ≠ جەختکردن:** پێویستیان بە سیاقی گفتوگۆ و شیکاریی زانیاریی نوێ/کۆن هەیە.
9. **کرداری لێکدراو ≠ کردار + بەرکار بە خۆکار:** توخمی ناوی کردارە لێکدراوەکان بە پێی فەرهەنگ و واتا دەستنیشان دەکرێن.
10. **جێناوی لکاو ≠ نیشانەی خاوەندارێتی لە هەموو شوێنێک:** فۆڕمی هاوشێوە دەکرێت لە پێکهاتەی کرداردا نیشانەی کەسی/ڕێکەوتن بێت؛ پێویستی بە شیکاریی مۆرفیمی و زاری هەیە.

## ٤. ناڕێکییە دیاریکراوەکان بە پەیوەندیی وانە
### وانەکانی ٣٢–٣٨
- ٣٢: پێناسەی ڕستە و پێڕستە دەبێت بە شێوەیەک بێت کە ڕستەی فەرمانی، بکەری نەهاتوو/سڕاوە و ڕیزبەندیی جیاواز لەخۆبگرێت.
- ٣٣: بکەر بە پێی ئەرکی ڕێزمانی دیاری بکرێت، نە بە شوێنی سەرەتای ڕستە؛ لە ئەنجامدەری کردار جیا بکرێتەوە.
- ٣٤: «نیهاد» و «گوزارە» پێویستیان بە یەکسانکردنی واتا و سنوور هەیە؛ گوزارە بە کردار سنووردار نەکرێت.
- ٣٥: مەبەستی دەربڕین (هەواڵی، پرسیاری، فەرمانی، سەرسوڕمان) لە پێکهاتەی ڕستە جیا بکرێتەوە.
- ٣٦: تەواوکەر بە «هەموو ئەوەی لە دەرەوەی بکەر و کردارە» پێناسە نەکرێت؛ بەرکار، هاوەڵکار و پێکهاتەی ناوخۆی دەستەواژە جیا بکرێنەوە.
- ٣٧–٣٨: پۆلێنی چوارگانەی سادە، هاوبەست، ئاڵۆز و لێکدراوی ئاڵۆز لەگەڵ پێناسەی پێڕستە یەکبخرێت؛ ئامرازەکان بە پۆلی وشەی جیاواز هەڵبسەنگێندرێن.
### وانەکانی ٣٩–٤٦
- ٣٩: وەرگر/بەرکاری ناڕاستەوخۆ/تەواوکەری پێشگر دەبێت لە چوارچێوەیەکی دیاریکراودا یەکلا بکرێتەوە؛ کلیلی ڕاهێنانی ٤ تەواو بکرێت.
- ٤٠: نەبوونی بەرکاری ئاشکرا بەڵگەی تێنەپەڕبوون نییە؛ «نان خوارد» بە سیاق و واتای کردارە لێکدراوەکان شیکاری بکرێت.
- ٤١: «لەگەڵ هاوڕێکەی» گرووپی هاوەڵناو نییە؛ پۆلی پێکهاتە و ئەرکی ڕستەیی لێک جیا بکرێنەوە.
- ٤٢: «من دەمناسێت» لە شێوەی ئاساییدا ناکۆکیی کەس/کرداری هەیە؛ سیاق یان چاکسازی پێویستە.
- ٤٣: نیشانەکانی کەسیی بکەر/ڕێکەوتن لە خاوەندارێتیی ناو جیا بکرێنەوە؛ شیکاریی «ـی» بەبێ بەڵگەی زاری کۆتایی نەکرێت.
- ٤٤: کارا/نەکارا لە تێپەڕ/تێنەپەڕ جیا بکرێتەوە؛ «بە دەستی پۆلیس» بە خۆکار بە ئەنجامدەری کردار دانەنرێت.
- ٤٥: SOV وەک ڕیزبەندیی باو پێشکەش بکرێت، نە یاسای بێ‌استثنا؛ گواستنەوەی بەرکار لەگەڵ مۆرفۆلۆژی کردار و سیاق بپشکنرێت.
- ٤٦: پۆلێنی سادە/لێکدراو بە پۆلێنی چوارگانەی وانەی ٣٧ یەکبخرێت؛ «ئەگەر کاتم هەبێت، سەردانت دەکەم» لەو پۆلێنەدا ئاڵۆزە؛ «هاوبەست/خۆبەست» پێش بەکارهێنان پێناسە بکرێن.

## ٥. پشکنینی ڕێنووس و فۆڕمی نووسین
ئەم بەشە تەنها یاسای کار و خاڵە پێویستەکان دیاری دەکات؛ بەڵگەی تەواوی ڕێنووسی هەموو دەقەکان بە شێوەی وشە بە وشە لەم قۆناغەدا پشکنین نەکراوە.
- یەک فۆڕمی هێمای نێوانەیی بۆ دووگولە، خاڵ، خاڵبەندی و نیشانەی پرسیار لە هەموو وانەکاندا بەکاربهێنرێت؛ بەڵام هێمای ڕستەسازی نابێت جێگەی شیکاریی پێڕستە بگرێتەوە.
- فۆڕمی پێشگر و دەستەواژەی پێشگر‌دار لە نووسین و نموونەکاندا جیا بکرێتەوە.
- وشە و دەستەواژەی شێوەزاری/ئەدەبی لە دەقی شیعریدا بەبێ تۆمارکردنی جیاوازیی زار و سەرچاوە «هەڵەی ڕێنووس» ناونەنرێن.
- فۆڕمی نووسینی جێناوی لکاو و نیشانەی کردار لەگەڵ فۆڕمی زاری دیاریکراو بگونجێنرێت؛ نابێت بە یەک فۆڕمی گشتی هەموو زارەکان بسڕدرێنەوە.
- «سەربەخۆ/پشتبەستە» لە تۆماری زاراوەدا وەک فۆڕمی پێشنیارکراو بمێنێتەوە؛ فۆڕمە هاوشێوەکانی «سەربەست/پشبەست» تا بڕیاری یەکگرتوو بە شێوەی گۆڕاو تۆمار بکرێن.
- «هاولک» بە شێوەیەکی گشتی بۆ هەموو پەیوەندیکەرەکان بەکارنەهێنرێت؛ پۆلی ئامرازەکە بە پێی ئەرک دیاری بکرێت.

## ٦. بڕیارەکانی خاوەن پڕۆژە کە پێویستن
پێش گۆڕینی دەقی وانەکان، ئەم خاڵانە دەبێت یەکلا بکرێنەوە:
1. «نیهاد» بۆ Subject بەکاربهێنرێت یان «بکەر»؟ تۆماری ئێستا «بکەر»ی وەک فۆڕمی کار هەڵبژاردووە، بەڵام دەقی وانەی ٣٤ پێویستی بە بڕیارە.
2. «بەرڕستە» یان «ژێرەڕستە» بۆ Subordinate Clause؟
3. «هاوەڵکار» یان «پێکهاتەی زیادە» بۆ Adjunct؟
4. لە چوارچێوەی وانەکەدا وەرگر بە بەرکاری ناڕاستەوخۆ ناودەبرێت، یان تەواوکەری پێشگر؟
5. «کاری بەستەر» و فۆڕمەکانی «ـە، بوو، دەبێت» بە کام پێناسەیەکی دیاریکراو بەکاربهێنرێن؟
6. «هاوبەست/خۆبەست» لە وانەی ٤٦ واتای کام جۆری پێڕستە/ڕستە دەدەن؟
7. شێوەزاری بنەڕەتیی نموونە فێرکارییەکان چییە؟ لە کوێدا شێوەزاری تر بە بەڵگە دەهێڵدرێتەوە؟

## ٧. ڕیزبەندیی کارەکانی چاکسازی
1. بڕیاری زاراوەیی لەسەر ٧ خاڵی بەشی ٦.
2. چاکسازیی زانستیی پێناسەکان و پۆلێنی ڕستە لە ٣٢، ٣٧، ٤٦.
3. چاکسازیی مۆرفۆلۆژیی جێناوی لکاو و ڕێکەوتن لە ٤٢–٤٣.
4. یەکخستنی بەرکار/تەواوکەر/وەرگر لە ٣٦، ٣٩، ٤١.
5. یەکخستنی تێپەڕ/تێنەپەڕ و کارا/نەکارا لە ٤٠ و ٤٤.
6. پشکنینی سیاق و ڕیزبەندی لە ٤٥.
7. پشکنینی ڕێنووسی وردی دەقە خاوەکان بە جیاوازی، بە پاراستنی دەقی ئەدەبی و زاری.
