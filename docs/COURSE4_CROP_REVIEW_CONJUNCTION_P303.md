## ١. بەردەوامیی نموونەکانی پەڕەی پێشوو

لە سەرەتای پەڕەدا سێ ڕستەی نموونەیی دەردەکەون کە بەشی پێشوو، واتە بەکارهێنانی «کە»، تەواو دەکەن. لە یەکێکدا فۆڕمی «کە» لە ناو ڕستەدا دیارە؛ بەڵام وشەکانی دیکە و پەیوەندیی تەواوی ڕستەکان بە دڵنیایی ناخوێندرێنەوە. بۆیە دەقیان بە شێوەی تەواو نەنووسراوەتەوە.

## ٢. تێبینیی مامۆستا مەسعوود محەمەد

لە ناوەڕاستی پەڕەدا سەردێڕێک بە شێوەی «تێبینیی مەسعوود محەمەد» دەردەکەوێت. ئەم بەشە ڕەخنەیەک لە بەکارهێنان و پێناسەکردنی «کە» دەخاتەڕوو.

- دەقەکە ئاماژە بەوە دەکات کە هەندێک لە پێناسە و بەکارهێنانەکان لە نێوان چەند کارکردی جیاوازدا تێکەڵ دەبن.
- لە ڕوونکردنەوەکەدا «کە» بە ڕاناوی کەسی و بە شێوەیەکی دیکەی پەیوەندیی ڕستەیی بەراورد دەکرێت.
- نووسەر دەڵێت لە هەندێ بەکارهێناندا «کە» بە شێوەیەک دەردەکەوێت کە سنووری نێوان ڕاناو و ئامرازی پەیوەندی ڕوون نییە.
- هەندێ وشەی دەقی ڕەخنەکە بەهۆی کوالێتی چاپەوە بە دڵنیایی تەواو ناخوێندرێنەوە؛ بۆیە لێرەدا تەنها ناوەڕۆکی گشتی و جیاوازیی کارکردەکان تۆمار کراون، نەک وەک گواستنەوەی وشەبەوشە.

ئەم بەشە دەبێت وەک ڕای مەسعوود محەمەد/تێبینییەک کە لە سەرچاوەدا گێڕدراوەتەوە تۆمار بکرێت؛ نابێت بە بڕیاری کۆتاییی پڕۆژە لەسەر پۆلێنکردنی «کە» دابنرێت.

## ٣. خشتەی فۆڕمەکان

لە بەشی خوارەوەی پەڕەکە خشتەیەکی دوو ستوونی هاتووە. ستوونی ڕاست فۆڕمی بنەڕەتی/کورتتر و ستوونی چەپ فۆڕمی هاوتا یان درێژکراو پیشان دەدات. لە وێنەکەدا ئەم جووتانە تا ڕادەیەک دەخوێندرێنەوە:

| ستوونی ڕاست — خوێندنەوەی نزیکەیی | ستوونی چەپ — خوێندنەوەی نزیکەیی |
|---|---|
| لەت | لەتکە |
| فڕ | فڕکە |
| بن | بنکە |
| لووت | لووتکە |
| خر | خرکە |
| در | درکە |
| سوور | سوورکە |
| شل | شلەکە |
| شەل | شەلکە |
| دان | دانکە |
| پەل | پەلکە |

**ئاگاداریی خوێندنەوە:** ئەم فۆڕمانە لە خشتەی چاپکراوەوە بە شێوەی نزیکەیی خوێندراونەتەوە. بە تایبەتی لە هەندێ جووتدا جیاوازیی نێوان پیتە هاوشێوەکان و خوێندنەوەی کۆتاییی وشەکە دڵنیایی تەواو نییە. نابێت ئەم خشتەیە وەک لیستی وشەی پەسەندکراو یان بەڵگەی یاسایەکی گشتیی زاراوەیی بەکاربهێنرێت تا لەگەڵ پەڕەکانی دەوروبەر و چاپێکی ڕوونتر بەراورد بکرێت.

## ٤. تێبینیی زاراوەیی و ڕێکخستن

1. پەڕەی ٣٠٣ بەردەوامیی باسەکەی «کە»یە؛ بەشی سەرەکیی پەڕەکە ڕەخنەی مەسعوود محەمەد و خشتەی فۆڕمەکانە.
2. جیاوازیی نێوان «کە» وەک ڕاناو، ئامرازی عەتف و بەشێک لە پێکهاتەی وشە پێویستی بە پشکنینی کارکردی لە ناو ڕستەدا هەیە؛ تەنها هاوشێوەیی دەنگی/نووسینی بەس نییە بۆ یەک پۆلکردنیان.
3. خشتەکە وەک بەڵگەی بینراوی سەرچاوە پارێزراوە، بەڵام فۆڕمەکانی بە دڵنیایی کەم نابنە زاراوەی ستاندارد.
4. ڕای مەسعوود محەمەد لە تۆمارکردنی مێژوویی سەرچاوەدا جیا دەکرێتەوە لە بڕیاری زاراوەیی پڕۆژە.
5. هیچ وانە، کوییز یان چالاککردنی کۆرس لەم پەڕەیەوە دروست نەکراوە.

ئەم بەڵگەنامەیە پشکنینی بینراوی پەڕەی ٣٠٣ ـە، نەک دەقی دپلۆماتیکی تەواو یان پشتڕاستکردنەوەی زانستیی فۆڕمەکان.

پەڕەی ٣٠٤ بۆ بەردەوامی پشکنینی بەشی ئامرازی عەتف.
