# پشکنینی پەڕەی ٣٢٠ — خاڵی ١٧: ئامرازی «بەلکو»

سەرچاوە: `Rezmany_axawtny_kurdy.pdf`، بەشی ٨ (هاوەڵ/ئامرازی عەتف).

## بەردەوامیی ڕوونکردنەوە
سەرەتای پەڕە بە بەردەوامیی خاڵی ١٧ دەست پێ دەکات. نووسەر ئاماژە دەکات کە نووری عەلی ئەمین ئامرازی «بەلکو»ی لە ژێر «عەتف»دا داناوە. دەقی تەواوی پەراگرافی سەرەتایی بەهۆی خوێندنەوەی ناتەواوەوە تۆمار نەکراوە.

## نموونەکان
نووسەر پێنج نموونە بۆ جێگە و دەوری «بەلکو» دەهێنێتەوە:
1. «خۆت بگرە بەلکو ...» — کۆتایی نادڵنیایە.
2. «... دەچێنم بەلکو ... بارانە شین بیت.» — چەند وشە نادڵنیان.
3. «بەلکو هەزار کەس ... لە جادە ڕاوەستانبوون.» — ناوەڕاست نادڵنیایە.
4. «بەلکو واش بیت.»
5. «بەلکو خوا ڕەحمێ پێ بکات.»

هیچ وشەی نادڵنیا بە خەمڵاندن پڕ نەکراوەتەوە.

## واتا و دەورەکان
لیستی چاپکراو سێ دانەیە:
1. **عەتف (ڕبط)**.
2. **احتمال** — لە دەقەکەدا نزیکە لە «کە دەکەشێتەوە سەر گومان».
3. **ناوات** — خوێندنەوەی وشەی سێیەم نادڵنیایە؛ واتای خەمڵێنراوی بۆ دانەنراوە.

نووسەر لە دێڕەکانی کۆتاییدا ئاماژە بەوە دەکات کە ئەم واتایانە لە هەموو حاڵەتەکاندا بە یەک شێوە بەکار نایەن و دەوروبەری ڕستە گرنگە.
