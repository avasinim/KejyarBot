# زیادکراوەی تۆماری پۆششی سەرچاوە — لاپەڕەکانی ٣٣٩–٣٤٤

- **٣٣٩–٣٤١:** کۆتایی بەشی پێشوو لەسەر «هەر»؛ بابەتی ٢١ «ئامرازی (هەرکە)ی عەتف» لە ٣٤١ دەست پێدەکات.
- **٣٤٢–٣٤٣:** بابەتی ٢٢ «ئامرازی (کەچی)ی عەتف»؛ لە ٣٤٢ دەست پێدەکات و لە ٣٤٣دا کۆتایی بە نموونە و ڕوونکردنەوەکانی دێت.
- **٣٤٣–٣٤٤:** بابەتی ٢٣ «ئامرازی (چونکە)ی عەتف»؛ لە ٣٤٣ دەست پێدەکات و لە ٣٤٤دا بەردەوامە.
- **سنووری بەڵگە:** تەنها پشکنینی بینراوی لاپەڕەکانە؛ دەقی دیپلۆماتیکی و پەسەندکردنی زمانەوانی بە جیاوازی پێویستیان بە پشکنینی ورد هەیە.
- **هەنگاوی داهاتوو:** پشکنینی بینراوی لاپەڕەکانی ٣٤٥–٣٥٠، بە پاراستنی ژمارە و ناونیشانی سەردێڕەکان.
