# تۆماری یەکگرتووی زاراوەکانی کۆرسی ٤
>
> **یاسای بەکارهێنان:** زاراوە و شێوەی نووسینی د. ئەوڕەحمانی حاجی مارف بە هەمان شێوەی بەڵگەی سەرچاوە دەپارێزرێت. OCR بە تەنها بەڵگەی کۆتاییی ڕێنووسی چاپکراو نیە. تا وێنەی پەڕەی چاپکراو نەبینرێت، شێوەی نادڵنیا نابێت بە دڵنیایی یەکبخرێتەوە یان نوێ بکرێتەوە.

## ١. زاراوەکانی پشتگیریکراو لە دەقی OCRی سەرچاوە

| زاراوە | بەکارهێنان لە کۆرس | بەڵگە/تێبینی |
|---|---|---|
| قەد | بنەمای کاتی ڕاپۆردوو لە چوارچێوەی ئەم کتێبەدا | بەشی کردار، پەڕەکانی ١٢٥–١٢٦؛ OCR |
| ڕەگ | بنەمای کاتی ڕانەبردوو لە چوارچێوەی ئەم کتێبەدا | بەشی کردار، پەڕەکانی ١٢٥–١٢٦؛ OCR |
| ڕانەبردوو | دابەشکردنی کات | پێڕەوی سەرەتایی و بەشی کات؛ OCR |
| ڕاپۆردوو | دابەشکردنی کات | پێڕەوی سەرەتایی و بەشی کات؛ OCR |
| نێستا، ئایندە | دوو بەشی ڕانەبردوو | پێڕەوی سەرەتایی؛ OCR |
| نزیک، بەردەوام، تەواو، دوور | ناونیشانەکانی ڕاپۆردوو | پێڕەوی سەرەتایی؛ OCR |
| ڕێژە | پۆلێنکردنی تایبەتیی کتێب؛ لەگەڵ کات تێکەڵ ناکرێت | بەشی کردار، پەڕەکانی ١٨٤–١٨٧؛ OCR |
| ئیخباری، داخواز | دوو ناوی جۆری ڕێژە | پەڕەکانی ١٨٤–١٨٧؛ OCR |
| تێپەڕی، تێنەپەڕی | جۆری کردار | پێڕەوی سەرەتایی و پەڕەکانی ٢١–٢٢؛ OCR |
| بەرکار | ئەندامی ڕستە لە پەیوەندی بە کرداردا | OCRی پەڕەکانی ١١ و ١٠١؛ وێنەی چاپکراو هێشتا پشکنراو نیە |
| کارا بڕزی | زاراوەی بەکارهاتوو لە سەرچاوە | OCR؛ پێویستی بە پشتڕاستکردنەوەی وێنەی چاپکراو هەیە |
| لێکدراو | بەشێک لە ناسادە | پێڕەوی سەرەتایی و بەشی کردار؛ OCR |

## ٢. زاراوە و شێوەی نووسینی نادڵنیا

| بابەت | شێوەکان/کێشە | ڕێسای ئێستا |
|---|---|---|
| ناوی جۆری دووەمی ڕێژە | OCR: «ئینیشایی/ئێنیشایی/تێنیشتانی» | «تێنیشتانی» تەنها شێوەی کارییەکی کاتییە؛ لە وانەدا نیشانەی نادڵنیایی دەبێت بمێنێتەوە. |
| ناوی جۆری ناسادەی کردار | OCR: «دابڕژراو»؛ تۆماری یارمەتیدەر: «دارێژراو»؛ لە ڕوونکردنەوەدا «داڕژاو» | هیچ شێوەیەک کۆتایی نیە تا وێنەی پەڕەی ٩ و ٧٩–٨٢ بپشکنرێت. |
| کارا دیار / کارا دیاری | جیاوازیی شێوە لە تۆماری OCR و ناونیشانەکاندا | شێوەی چاپکراو بە وێنە پشتڕاست بکرێتەوە؛ لە ئێستادا شێوەی بەکارهاتوو لە دەقی وانەکە بە یەک شێوە بمێنێتەوە و وەک گۆڕینی نووسەر ناخرێتەڕوو. |
| نموونەکانی «پارسێتن»، «ڕشتن» و هەندێ فۆرمی کردار | OCR دەتوانێت پیت و بۆشایی هەڵە بخوێنێتەوە | هەمان شێوەی OCR بپارێزرێت و بەبێ وێنە ڕێنووسی نوێی بۆ دانەنرێت. |

## ٣. چەمکەکانی ڕوونکردنەوەی ئامادەکەر؛ نەک زاراوەی پشتڕاستکراوی نووسەر

- **ڤالێنسی:** چەمکێکی یارمەتیدەری زمانەوانییە بۆ ڕوونکردنەوەی پەیوەندیی کردار بە بکەر و تەواوکەرەکان؛ لەم کۆرسەدا نابێت وەک زاراوەی حاجی مارف بناسرێت.
- **هۆکارساز:** تا ئێستا وەک ناونانی تایبەتی نووسەر پشتڕاست نەکراوەتەوە؛ لە وانەکاندا بەبێ بەڵگە بەکار نەهێنرێت.
- **گۆڕینی کردار لە ناتێپەڕ بۆ تێپەڕ:** دەربڕینێکی ڕوونکەرەوەی ئامادەکەرە، نەک ناونانێکی پشتڕاستکراوی کتێب.
- **کرداری ناسادەی بە پێشگر/پاشگر:** ناونانی ڕوونکەرەوەی ئامادەکەرە تا ناوی چاپکراوی پۆلەکە بە وێنە پشتڕاست دەکرێتەوە.
- **جیاوازیی واتایی کردار و ناو:** ڕوونکردنەوەی فێرکارییە؛ لە لیستی چوار جیاوازیی سەرەکیی وانەی ٢٥دا جێی جیاوازیی دەنگی ناگرێتەوە.

## ٤. ڕێنماییی نووسین و پشکنین

1. وشە، زاراوە، بۆشایی و نموونەی کتێب وەک خۆی بنووسە؛ هەڵەی گومانلێکراوی OCR بە بێ بەڵگەی وێنە ڕاست مەکەرەوە.
2. زاراوەی نوێ یان هاوتای ئەمڕۆیی بە جیاوازی و بە نیشانی «ڕوونکردنەوەی ئامادەکەر» بنووسە.
3. لە وانەکانی ٢٥–٣٠دا «بەرکار» لە مانای ئەندامی ڕستەدا بەکاربهێنە؛ «بەکار» کاتێک واتای بەکارهێنان دەدات مەگۆڕە.
4. لە وانەی ٢٧دا «ڕێژە» بە واتای aspect ی تەواوبوون/بەردەوامی مەخەڕەڕوو؛ پۆلێنکردنی تایبەتی کتێبە.
5. هیچ یەک لە زاراوە نادڵنیاکان بۆ چالاککردنی کۆرس بە شێوەیەکی قاطع جێگیر مەکە تا پەڕە چاپکراوە پەیوەندیدارەکان بینراون.
6. هەر جار پەڕەی چاپکراو بە چاوی مرۆڤ پشکنرا، شێوەی OCR و شێوەی چاپکراو لە تۆماردا بەراورد بکە و بەڵگەی پەڕەکە زیاد بکە.
