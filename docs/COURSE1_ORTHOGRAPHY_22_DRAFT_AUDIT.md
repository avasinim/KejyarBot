# پشکنینی پێش‌نوسی دەورەی ١ — ٢٢ وانە

## مەبەست
ئەم پەڕگەیە دۆخی فایلە پێش‌نوسەکان لە برانچی تاقیکردنەوە تۆمار دەکات. ئەم پشکنینە بە مانای پەسەندکردنی زانستیی هەموو یاسا و نموونەکان نییە.

## فایلەکان
- ناوەڕۆکی گشتی: `docs/COURSE1_ORTHOGRAPHY_22_LESSONS.md`
- داتای سەرەتایی: `course_data/orthography_foundations.json`
- پێش‌نوسەکانی وانە ١–٢٢: `course_data/orthography_lesson_01_draft.md` تا `course_data/orthography_lesson_22_draft.md`

## دۆخی کار
- ٢٢ فایل بۆ پێش‌نوسی وانەکان ئامادە کراون.
- وانە ١٨ بە داواکاریی بەکارهێنەر لە «کەویار» گۆڕدراوە بۆ «کەژیار» و نموونەی زیاتر بە «فەرزانە» زیاد کراوە.
- وانەکانی ٢٠ و ٢١ بە وریایی باس لە «بزرۆکە» دەکەن؛ پێناسە و شیکردنەوەی بڕگەکان پێویستی بە سەرچاوەی دیاریکراو هەیە.
- وانە ٢٢ جیاوازیی ئەرکی «و» و «ی» بە نموونەکانی «کورد»، «شوان»، «ئەسرین» و «دیار» ڕوون دەکاتەوە؛ پێویستە خوێندنەوە و نووسینی لاتینی لەگەڵ سەرچاوەی کۆرس یەکبخرێتەوە.

## پێویستییەکانی پێش بەستنەوە بە بۆت
1. پشکنینی هەموو فایلەکان لە ڕووی ڕێنووس، دووبارەبوونەوە، پێکهاتە و هاوتایی لەگەڵ یەکدی.
2. پشکنینی زانستیی یاسا و نموونەکان بە سەرچاوەی دیاریکراو؛ ئەو خاڵانەی پشتڕاست نەکراونەتەوە بە ڕوونی نیشانەدار بمێننەوە.
3. دروستکردنی داتای ڕێکخراوی ٢٢ وانە و کویزەکان لە شێوەیەک کە لەگەڵ handler ـەکانی ئێستای بۆت سازگار بێت.
4. زیادکردنی تاقیکردنەوە بۆ ئەوەی کۆرسی نوێ لە کۆرسی ١٠ وانەیی ئێستا جیا بمێنێتەوە و تێکەڵ نەبێت.
5. تاقیکردنەوەی offline و پشکنینی diff لە برانچی تاقیکردنەوە.
6. دوای ڕەزامەندیی بەکارهێنەر، بڕیار لەسەر هەر گۆڕانکارییەکی زیندوو بدرێت.

## سنووری پاراستن
هیچ گۆڕانکارییەک لە `main`، توکنی بۆتی زیندوو، سیستەمی داتای بەرهەمهێنان، یان چالاککردنی دەنگی دینامیکی لەم کارەدا ڕێگەپێدراو نییە.

## پشکنینی دووبارەی فایلەکان — ٢٦ی ئۆکتۆبەری ٢٠٢٦
- فایلەکانی پێش‌نوسی وانە ١ تا ٢٢ بە سەرکەوتوویی لە برانچی تاقیکردنەوە خوێندرایەوە؛ هەموو ٢٢ فایلەکە بوونیان پشتڕاست کرا.
- ناونیشانی فایلەکانی وانە ١٨ و داتای کاتەلۆگ بەراورد کران؛ هەردووکیان ئێستا «کەژیار» بەکار دەهێنن.
- لە فایلەکەی وانە ١٨دا «فەرزانە» هەیە، بەڵام ئەمە بە تەنها پشتڕاستکردنەوەی زانستیی هەموو نموونەکان نییە.
- ئەم پشکنینە تەنیا خوێندنەوە و هاوتاییی ناونیشانەکان دەگرێتەوە؛ تاقیکردنەوەی کۆد یان پشکنینی تەواوی زمانەوانی ئەنجام نەدراوە.
