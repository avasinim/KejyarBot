# Course 3 — Kejyar visual and infographic checklist

Status: release requirement; visuals are not yet complete.

## Brand and layout rules

- Use the approved Kejyar logo/character reference; do not redraw or replace the character with an unrelated mascot.
- Keep a consistent academic visual system across all 66 lessons.
- Palette: forest green, warm off-white, copper/gold accents.
- Kurdish text must render with a legible Arabic-script font and correct right-to-left layout; check letters, diacritics, punctuation, and mixed numerals on mobile.
- Use a clear hierarchy: Kejyar/course identity, lesson number and title, one core rule, carefully selected examples, and a short learner reminder.
- Each visual must teach that lesson's actual topic and use verified examples from the reviewed lesson/book. Avoid decorative clutter and tiny text.
- Make mobile-first vertical infographics; keep contrast high and whitespace sufficient.
- Do not use daily-conversation illustrations for orthography lessons merely because their lesson numbers match.
