# دەورەی ١: ڕێنووسی سەرەتایی — پێکهاتەی ٢٢ وانە

ئەم پەڕگەیە تەنها پێکهاتەی دەورەی ڕێنووسی سەرەتایی تۆمار دەکات. وانەکانی فێربوونی ئاساییی ئێستای KejyarBot ناگۆڕێت و هیچ گۆڕانکارییەک بۆ main، بۆتی بەرهەمهێنان یان داتابەیسی بەرهەمهێنان ناکات.

## کۆتایی دەورە

دوای وانەی ٢٢، دەورەی ١ کۆتایی دێت. لە منووی بۆتەکەدا کلیلێکی جیاواز بە ناوی **«ڕێنووسی زمانی کوردی»** پیشان بدرێت. ئەم کلیلە بەشێکی جیاوازە؛ نابێت وەک وانەی ٢٣ی دەورەی ١ ژمێردرێت.

## یاساکانی جێبەجێکردن

- ئەم دەورەیە لە ٢٢ وانە پێکدێت.
- ناوەڕۆکی هەر وانەیەک پێویستە بە سەرچاوە بپشکنرێت؛ بانگەشەی زمانەوانیی پشتڕاست‌نەکراو نابێت بە ڕاستیی کۆتایی پیشان بدرێت.
- نموونەکان و دەقی سەرچاوەکان بێ بەڵگە ناگۆڕدرێن.
- دەنگی ژنی ئێستای پڕۆژە بە ڕێگەی فایل/سیستەمی دەنگی هەنووکەیی بپارێزرێت؛ دەنگی دینامیکی هەتا ڕێگەپێدانی ڕوون ناچالاک دەمێنێتەوە.
- هێمای بینراو و وێنەڕوونکەرەکان دەبێت RTL و فۆنتی کوردی ڕێز بگرن.
- ئەم پەڕگەیە بە تەنها هیچ دەستکاریکردنێک لە منووی بۆت یان ڕێڕەوی خوێندکاردا جێبەجێ ناکات؛ ئەوە هەنگاوی دواترە و پێویستی بە گۆڕانکاریی کۆد و تاقیکردنەوە هەیە.
