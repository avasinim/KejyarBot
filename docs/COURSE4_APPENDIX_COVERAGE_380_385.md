# زیادکراوەی تۆماری پاشکۆ — لاپەڕەکانی ٣٨٠–٣٨٥

- **٣٨٠–٣٨١:** لیستی ئەلف/ئامراز و بەراوردی سەرچاوەکان؛ لەگەڵ دەقی فەڕەنسی لەسەر پێشگر و پاشگر.
- **٣٨٢–٣٨٣:** پۆلێنکردنی پاشگر، پاشگری فەرمان و پاشگری کردار بە ژمارە و نموونە.
- **٣٨٤–٣٨٥:** پێشگری کردار/فەرمان، لیستی پێشگر و بەراوردی زمانی.
- **سنووری بەڵگە:** پشکنینی بینراوی ڕێکخستن و بابەتە؛ فۆڕمە وردەکان و ناوی سەرچاوەکان پێویستیان بە خوێندنەوەی دیپلۆماتیکی هەیە.
- **سنووری پاشکۆ:** ئەم لاپەڕانە بە وانە سەرەکییەکان تێکەڵ ناکرێن.
- **هەنگاوی داهاتوو:** لاپەڕەکانی ٣٨٦–٣٩١ وەک پاشکۆ پشکنین بکرێن.
