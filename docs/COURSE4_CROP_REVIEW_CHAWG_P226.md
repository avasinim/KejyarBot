# پشکنینی کراپی پەڕەی ٢٢٦ — بەردەوامی چاوگی دەنگی بزوێن

## سەرچاوە و سنووری پشکنین
- کۆرس: ٤ — ڕێزمانی ئاخافتنی کوردی
- بەڵگەنامەی سەرچاوە: `Rezmany_axawtny_kurdy.pdf`
- پەڕە: ٢٢٦
- پشکنین: وێنەی تەواوی پەڕە و کراپی ناوەڕاستی گەورەکراو.
- ئەم تۆمارە پشکنینی بینراویە؛ ترانسکریپشنی دیپلۆماتیکی تەواو یان پەسەندکردنی زانستیی یاساکان نییە.

## بەردەوامی نموونەکان
لە سەرەتای پەڕەدا لیستێکی نموونەکان بەردەوامە. خوێندنەوەی بینراوی وشەکان:
- دان
- نان
- سووتان
- ڕژان
- خشان
- ڕووشان
- خنکان

لە تەنیشت لیستەکەدا تێبینییەکی کورت هەیە، بەڵام بەهۆی ڕوونیی سنوورداری چاپەوە دەقی تەواوی بە دڵنیایی نەخوێندرایەوە.

## ڕوونکردنەوە
- لە نیوەی خوارەوە سەردێڕی «ڕوونکردنەوە» هەیە.
- یەکەم پاراگراف بە «کاری (نان)» دەست پێدەکات و باس لە بەکارهێنانی فۆڕمی چاوگ لە ڕستەدا دەکات؛ چەند فۆڕمی کردار و نموونەی ڕستەیی لە ناو دەقەکەدا هەن.
- پاراگرافی دووەمیش بە «کاری (نان)» دەست پێدەکات و جیاوازییەکی تر لە نێوان فۆڕمەکان و بەکارهێنانیان دەخاتەڕوو.
- دەقی وردی ئەم دوو پاراگرافە لێرەدا بە تەواوی نەگوازراوەتەوە، چونکە هەندێک وشە و پێکهاتەی ڕستەکان بەهۆی کوالێتی چاپەوە بە دڵنیایی دیار نین.

## تێبینیی پشکنین
- پەڕەکە بەشی نموونەکان و ڕوونکردنەوەی جۆری دووەمی چاوگ بەردەوام دەکات.
- نموونە وشەکان وەک خوێندنەوەی بینراو تۆمار کراون؛ پێویستە لەگەڵ پەڕەکانی ٢٢٥ و ٢٢٧ بەراورد بکرێن.
- لە قۆناغی داهاتوودا دەبێت ڕوون بکرێتەوە ئەو سێ جۆرەی پەڕەی ٢٢٥ چۆن بەردەوام دەبن و ناونیشانەکان بە شێوەیەکی یەکگرتوو تۆمار بکرێن.
