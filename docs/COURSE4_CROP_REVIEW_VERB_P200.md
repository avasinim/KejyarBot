# پشکنینی کراپی p.200 — نموونەکانی پاشگری کار

## دۆزینەوەکان

- پەڕەکە بەردەوامی ڕاستەوخۆی بەشی «پاشگر» ـە کە لە p.199 دەستی پێ کرد.
- لە سەرەتادا نموونە و ڕوونکردنەوەی پاشگر بە شێوەی دەق و نموونەی ئەدەبی/ئاخاوتنی هاتووە؛ پاشان نووسەر دەڵێت ئەم پاشگرە لە کوردیدا بەکاردێت و نموونەکان بە ژمارە ڕیز دەکات.
- چوار نموونەی ژمارەکراو بە ڕوونی دیارن:
  1. **کردن — کردنەوە**؛ لەگەڵ واتای عەرەبی «فتح».
  2. **خواردن — خواردنەوە**.
  3. **ڕازاندنەوە**؛ لە ژێر ئەم خاڵەدا چەند فۆڕمی هاوشێوە/داڕێژراو هاتوون، لەوانە «حەسانەوە»، «گڕۆزانەوە» و «پارانەوە». فۆڕمی ناوەڕاست پێویستی بە پشکنینی سەرچاوەی چاپکراو هەیە بۆ دڵنیایی لە نووسینی ورد.
  4. **هاتن — هاتنەوە**.
- لە دوای نموونەی چوارەمدا ڕوونکردنەوەیەک هەیە کە پاشگر لەگەڵ بنەی کار پێکەوە دەبن و لە دروستبوونی واتا/فۆڕمی نوێدا ڕۆڵ دەبینێت؛ دەقەکە بە کۆتایی پەڕەکەدا بەردەوامە.
- لە p.200 سەردێڕی نوێیەکی سەربەخۆ بۆ بابەتێکی تر نییە؛ پەڕەکە هەمووی لە چوارچێوەی پاشگری کاردا دەمێنێتەوە.

## پەیوەندیی پەڕەکان

## سنووری پشکنین
