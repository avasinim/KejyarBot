# پشکنینی کراپی p.199 — خاڵی (١١)ی پێشگر و دەستپێکی پاشگری کار

## دۆزینەوەکان

- سەرەتای پەڕەکە **خاڵی (١١)** ـی لیستی پێشگرەکانی کارە؛ بەردەوامی لیستی p.197–198 ـە. دەقەکە باس لە وشە/توخمێک دەکات کە پێش کار دێت و واتای تازە بە کار دەبەخشێت. چەند نموونەیی لە کەوانەدا هاتوون، بەڵام هەموو فۆڕمەکان لە ئاستی پێویست بۆ گواستنەوەی وشە بە وشە دڵنیا نین.
- بەدوای خاڵی (١١)دا ڕوونکردنەوەیەک هەیە کە کاریگەریی پێشگر لە دروستکردنی واتای تازە و جیاوازیی بەکارهێنان لە شێوەکانی کوردیدا باس دەکات.
- سەردێڕی **«پاشگر:»** بە ڕوونی دەردەکەوێت؛ ئەمە دەستپێکی بەشی پاشگری کارە و بەوە لیستی پێشگرەکان لەم بەشەدا کۆتایی دێت.
- پێناسە/ڕوونکردنەوەی سەرەتایی دەڵێت پاشگر لە کۆتایی کارەوە زیاد دەکرێت؛ بەڵام فۆڕمی وردی هەموو نموونەکان بۆ ترانسکرپشنی قطعی پێویستی بە پشکنینی پەڕەکانی دواتر و کراپی وردی زیاتر هەیە.
- لە ژێر سەردێڕی **«تێبینی:»** نووسەر جیاوازییەک لە نێوان شێوەی پاشگر لە زار/شێوەکانی کوردیدا دەخاتەڕوو و نموونەی بەراوردی دەهێنێتەوە.
- کۆتایی پەڕەکە نموونەیەکی کاری پاشگردار لەگەڵ شیکردنەوەی توخمەکانی ناو کارەکە دەهێنێتەوە؛ ئەم شیکردنەوەیە بەردەوامی بابەتی پاشگرە، نە بابەتێکی نوێی سەربەخۆ.
