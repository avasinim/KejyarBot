# KejyarBot — ژێرپشکنینی تاقیکردنەوەی ڕاستەقینە

ئەم ڕێنماییە بۆ تاقیکردنەوەی دەستی لە **بۆتێکی تاقیکردنەوەی جیاواز**ە، نەک بۆتی بەرهەمهێنان.

## پێش دەستپێکردن

- [ ] بۆتێکی تاقیکردنەوەی تایبەت لە BotFather دروست بکە؛ tokenی بۆتی بەرهەمهێنان بەکارمەهێنە.
- [ ] ئەگەر هەیە، ژینگە/ماکینەی تاقیکردنەوەی جیاواز بەکاربهێنە؛ فایلەکانی بنکەدراوەی بەرهەمهێنان کۆپی یان هاوبەش مەکە.
- [ ] branchی `content-design-polish-2026-10-25` (لەسەر stability branch) وەک کۆدی تاقیکردنەوە بەکاربهێنە؛ `main` مەگۆڕە.
- [ ] token تەنها لە `.env`ی ناوخۆیی یان secretی ژینگەی تاقیکردنەوە دابنێ؛ لە چات، issue، commit یان log دایمەزرێنە.
- [ ] لە تاقیکردنەوەی یەکەمدا dynamic speech ناچالاک بهێڵەوە؛ پێویستی بە پشتڕاستکردنەوەی دەنگی ڕێپێدراو و کوالێتی زمانی کوردی هەیە.

## ڕێکخستنی ناوخۆیی

1. Pythonی گونجاو دابنێ و وابەستەییەکان دابمەزرێنە:
   `python -m pip install -r requirements.txt`
2. tokenی تاقیکردنەوە بە یەکێک لەم ناوانە ڕێکبخە:
   - `TELEGRAM_BOT_TOKEN`
   - `BOT_TOKEN`
3. دڵنیابە هیچ ڕێکخستنێک بۆ بنکەدراوەی بەرهەمهێنان ئاماژە ناکات.
4. بۆت لە ژینگەی تاقیکردنەوەدا بە `python bot.py` هەڵبکە.
5. ئەگەر دەستپێکردن شکستی هێنا، logی token یان زانیاریی نهێنی هاوبەش مەکە.

## لیستی تاقیکردنەوەی دەستی

- [ ] `/start` پەیامی بەخێرهاتن و منووی سەرەکیی کورت بە چوار ڕیز نیشان دەدات.
- [ ] «📚 وانەکان» کاتێبەندیی ناوخۆیی بە ١٠ دوگمە لە دوو ستووندا دەکاتەوە؛ نیشانەکانی 🔓، 🔒 و ✅ لەگەڵ دۆخی وانەکان دەگونجێن.
- [ ] دوگمەی وانەی کراوە لە کاتێبەندیی ناوخۆیی وانەکە دەکاتەوە؛ ناوەڕۆک و ئینفۆگرافیک دەردەکەون.
- [ ] کرتەکردن لەسەر وانەی 🔒 پەیامی داخراوی دەدات و ناوەڕۆکی وانەکە ناکاتەوە.
- [ ] تەواوکردنی وانەی ١ تەنها یەک جار خەڵات دەدات؛ دووبارە کرتەکردن XP/Coin/سندوق دووبارە زیاد ناکات.
- [ ] دوگمەی وانەی دواتر وانەی ٢ دەکاتەوە؛ وانەی قوفڵکراو پێش کاتی خۆی ناکرێتەوە.
- [ ] تاقیکردنەوەی وانەی تەواوکراو دەکرێتەوە و هەڵبژاردەکان کار دەکەن.
- [ ] دوو کرتەی خێرا لەسەر هەمان وەڵام تەنها یەک جار خاڵ زیاد دەکات.
- [ ] دوگمەی پرسیاری کۆن و callbackی نادروست تاقی دەکرێنەوە؛ پرسیاری چالاک و خاڵەکان نابێت تێک بچن.
- [ ] تەواوکردنی تاقیکردنەوە ئەنجامی دروست و خەڵاتی یەکجارە نیشان دەدات.
- [ ] گفتوگۆی ڕۆژانە دەست پێ دەکات و بە `خواحافیز` دەکرێتەوە؛ دوگمەکانی منووی سەرەکی شێوازی گفتوگۆ دەوەستێنن.
- [ ] دووبارە هەڵکردنەوەی بۆت پێشکەوتن و سهمی ڕۆژانەی تۆمارکراو لە SQLite لەناو نابات.
- [ ] ئەگەر dynamic speech بە مەبەست تاقی دەکرێتەوە، تەنها بە ڤۆیسی ڕێپێدراو و دڵنیابوون لە ئەنجامی زمانی کوردی؛ تا ئەو کاتە ناچالاک بمێنێتەوە.

## تۆمارکردنی ئەنجام

بۆ هەر خاڵێک بنووسە: `PASS` / `FAIL` / `BLOCKED`، کاتی تاقیکردنەوە، ژمارەی وانە، و هەنگاوی دووبارەکردنەوەی هەڵە. token، ناوی نهێنی، و زانیاریی کەسی لە تۆمارەکاندا مەنووسە.

**گرنگ:** ئەم فایلە ڕێنماییە، نە بەڵگەی ئەنجامی تاقیکردنەوەی دەستی. هیچ تاقیکردنەوەی ڕاستەقینە بە ئەنجام دانانرێت تا بە کردەوە جێبەجێ بکرێت و ئەنجامەکە تۆمار بکرێت. بڵاوکردنەوە، mergeکردنی PR، یان دەستکاریکردنی ژینگەی بەرهەمهێنان پێویستی بە ڕێگەپێدانی ڕوونی خاوەن پڕۆژە هەیە.
