# پلانى گواستنەوە بۆ چوار دەورەی کەژیار

## مەبەست
ڕێکخستنی وانەکان لە چوار دەورەی جیاوازدا، بە پاراستنی ناسنامەکانی وانە و داتای خوێندکاران.

## دەورەکان
1. دەورەی ١: ڕێنووسی سەرەتایی — وانەکانی بنەڕەتی پیت و دەنگ.
2. دەورەی ٢: وت‌وێژی ڕۆژانە — سڵاو، ناساندن، ژمارە، ڕەنگ، شوێن، خواردن و گفتوگۆ.
3. دەورەی ٣: ڕێنووسی یەکگرتوو — لە قۆناغی پلاندانان؛ وانەکان پێویستیان بە سەرچاوە و پشکنینی زانستی هەیە.
4. دەورەی ٤: ڕێزمان — لە قۆناغی پلاندانان؛ ناوەڕۆک تەنها دوای دابینکردنی خاوەن پڕۆژە ڕێکدەخرێت.

## پاراستنی داتا
- ناسنامەکانی legacy lesson و quiz دەبێت بپارێزرێن.
- هیچ تۆمارێکی پێشکەوتن، XP، Coin، badge یان پاداشت نابێت بسڕدرێتەوە.
- گواستنەوەی وانە لە نێوان دەورەکان نابێت لە کاتی گۆڕینی ناوەڕۆکدا ناڕوون بێت.
- هەر دەورەیەک دەبێت زنجیرەی پێشنیازی وانەکانی خۆی هەبێت؛ تەواوکردنی دەورەیەک نابێت بە خۆکار دەورەی دواتر بکاتەوە.
- دەنگی دینامیکی بە بنەڕەت ناچالاک دەمێنێتەوە.
- هیچ گۆڕانکارییەک لە main، بۆتی بەکارهاتوو، یان ژینگەی بەرهەمهێناندا نابێت تا مۆڵەتی ڕوونی بەکارهێنەر.

## پێشنیاری ڕێڕەوی جێبەجێکردن
1. پشکنینی ناسنامەی وانەکان و ناونیشانی ڕاست لە فایلەکانی ناوەڕۆک.
2. زیادکردنی پەڕەی دەورەکان و هەڵبژاردنی وانە لە چوارچێوەی دەورەی هەڵبژێردراو.
3. جیاکردنەوەی ڕێڕەوی قفڵکردن/کردنەوەی وانەکان بۆ هەر دەورەیەک.
4. دوای وەرگرتنی ناوەڕۆک لە خاوەن پڕۆژە، ڕێکخستن و پشکنینی وانەکانی دەورەی ٣ و ٤ بە سەرچاوە و تاقیکردنەوە.
5. تاقیکردنەوەی migration و سازگاری پێشکەوتنی کۆن پێش هەر بڵاوکردنەوەیەک.

## تێبینی گرنگ
فایلەکانی ناوەڕۆکی کۆن لە هەندێک ژێرەوەی GitHub جیاوازن لە clone ـی ناوخۆی بەکارهێنەر. پێش overwrite کردنی وانەکان، پێویستە ئەو جیاوازییە ڕوون بکرێتەوە؛ ئەمە ڕێگری دەکات لە لەدەستچوونی کارە نوێکانی ناوخۆ.


## سنووری ناوەڕۆک
- هیچ ناونیشان، ئامانج، نموونە، ڕاهێنان یان ڕیزبەندیی وانەی داهاتوو بە خۆکار دانانرێت.
- دەورەی ٣ و ٤ بەتاڵ و لە پلانداناندا دەمێننەوە تا خاوەن پڕۆژە ناوەڕۆکەکانیان دابین بکات.

## تصحیح جێگیر بۆ ناسنامەی وانەی ١ — ٢٠٢٦-١٠-٢٦
- بەپێی ڕێنمایی ڕاستەوخۆی خاوەن پڕۆژە، ناونیشانی وانەی ١ «پیتەکان و دەنگەکان»ە و بابەتەکە ناسینی ئەلفبێیە؛ وانەکە «سڵاو و ناساندنی خۆ» نییە.
- وێنەی نێردراوی خاوەن پڕۆژە بۆ وانەی ١ دیاری کراوە. وێنەی دیکە نابێت بە خۆکار جێی بگرێتەوە؛ وێنەی وانەکانی دیکەش تەنها بە دیاریکردنی خاوەن پڕۆژە هەڵدەبژێردرێت.
- دەورەی ١ تەنها ڕێنووسی سەرەتاییە؛ دەورەی ٢ وت‌وێژی ڕۆژانەیە و بابەتی سڵاو و ناساندن دەبێت لەو دەورەیەدا بێت.

- پشکنینی `bot.py` نیشانی دا کە ناسنامەی وێنەی وانەی ١ هێشتا `assets/infographics/lesson-01-greetings.svg` ـە و خۆی بە «سڵاو و ناساندنی خۆ» ناساندووە؛ ئەمە لەگەڵ بڕیاری خاوەن پڕۆژە ناکۆکە. وێنەی نێردراوی خاوەن پڕۆژە هێشتا وەک فایلێکی جێگیر لە ناو شاخەی GitHub ـدا دانەنراوە، بۆیە mapping ـەکە بە خەمڵاندن ناگۆڕدرێت و پێویستە پێش گۆڕانکارییەک، وێنەکە بە شێوەی فایل بخرێتە ناو شاخە و ناوەڕۆکی وانەش پشتڕاست بکرێتەوە.
- پشکنینی شاخەی ئەم بەڵگەنامەیە جیاوازییەکی ڕاستەوخۆی تۆمار کرد: لە `lessons.json` ـی ئێستادا `وانە_1` هێشتا «سڵاو و ناساندنی خۆ» و `وانە_2` «ئەلفبێی کوردی»یە. ئەمە تەنها وەسفی دۆخی ئێستای فایلەکەیە، نەک پشتڕاستکردنەوەی ڕاستیی ناوەڕۆک.
- **پێش هەر گۆڕانکارییەک لە `lessons.json`، `learning_path.json`، پەیوەندیی وێنەکان یان ناسنامەکانی وانە، دەبێت دەقی تەواوی وانەی ١ کە خاوەن پڕۆژە پێشکەشی کردووە لە بەڵگەی بەردەستدا بێت.** نابێت ناوەڕۆک، نموونە، ڕاهێنان یان ڕیزبەندی بە خەمڵاندن دروست بکرێت، و نابێت تەنها بە گۆڕینی ناونیشان، ناوەڕۆکی کۆن بە وانەی نوێ بناسرێتەوە.
- ئەم تۆمارە تەنها لە شاخەی تایبەتی تاقیکردنەوەدا زیاد کراوە؛ هیچ گۆڕانکارییەک لە `main`، بۆتی بەرهەمهێنان یان داتای بەرهەمهێنان نەکراوە.
