## p.179 — ڕیزەکانی فۆڕمی کردار

لە بەشی نموونەکانی پەڕەکە، ئەم ڕیزانە بە شێوەی خوارەوە دەخوێندرێنەوە. لە ڕیزە دووانەکاندا ڕیزبەندی لە ڕاستەوە بۆ چەپە:

| فۆڕمی تاک | فۆڕمی کۆ |
|---|---|
| دەخۆم | دەخۆین |
| دەخۆیت | دەخۆن |
| دەخۆن | — |
| دەکەم | دەکەین |
| دەکەیت | دەکەن |
| دەکەن | — |
| دەفڕم | دەفڕین |
| دەفڕیت | دەفڕن |
| دەفڕن | — |

### سنووری دڵنیایی
- وشەکانی ڕیزەکان لە کراپی گەورەکراودا بە ڕوونی دەردەکەون.
- ئەم خشتەیە تەنها ڕیزبەندیی نووسراوی سەرچاوە دەگوازێتەوە؛ ناوی کەس/ژمارە یان ڕوونکردنەوەی ڕێزمانیی زیادەی بۆ دانەنراوە.
- ڕیزە تاکەکان لە سەرچاوەدا بە شێوەی سەربەخۆ نووسراون؛ بۆیە لە خشتەکەدا بە هەمان شێوە پارێزراون و خانەی بەرامبەریان بە «—» نیشان دراوە.

## p.180 — دەستوری یەکەم و دەستوری دووەم
- سەردێڕی **«دەستوری یەکەم»** لە کراپی ورددا دیارە.
- نموونەکان لە چەند ستووندا ڕیزکراون؛ هەندێک ناوی کردار و شێوەی دەربڕین لە کراپەکەدا بە تەواوی بێ‌گومان نین. بۆیە لەم بەڵگەنامەیەدا ترانسکرپشن نەکراون.
- لیستی فۆڕمەکانی دواتر بە شێوەی ستوونی هاتووە؛ لە پشکنینی ئێستادا بۆ دانانیان لە وانەدا پشتڕاستکردنەوەی کراپی بەرزتر پێویستە.
- سەردێڕی **«دەستوری دووەم»** لە کۆتایی پەڕەدا دەست پێدەکات و دەقەکەی بۆ پەڕەی 181 بەردەوام دەبێت.

## ڕێنمایی بەکارهێنان
- فۆڕمەکانی p.179 دەتوانرێت وەک ترانسکرپشنی هەڵبژێردراوی کراپ بپارێزرێن، بەڵام پێش دروستکردنی وانە دەبێت لەگەڵ سیاقی پەڕە و پەڕەکانی پێش و دوا بەراورد بکرێن.
- فۆڕمە نادیارەکانی p.180 نابێت بە گومان پڕ بکرێنەوە.
- ئەمە ترانسکرپشنی هەڵبژێردراوە، نە ترانسکرپشنی تەواوی پەڕە و نە validationی زمانەوانی.
