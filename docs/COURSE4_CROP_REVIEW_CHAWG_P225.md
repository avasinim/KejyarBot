# پشکنینی کراپی پەڕەی ٢٢٥ — جۆرەکانی چاوگ

- بەڵگەنامەی سەرچاوە: `Rezmany_axawtny_kurdy.pdf`
- پەڕە: ٢٢٥

- ئەم تۆمارە پشکنینی بینراویە، نە ترانسکریپشنی دیپلۆماتیکی تەواو یان پەسەندکردنی زانستیی ڕێزمان.

## بەردەوامی جۆری دووەمی چاوگ
- سەرەتای پەڕە بەردەوامی بابەتی چاوگی پەڕەی ٢٢٤ە.
- چەند نموونە لە سەرەوەی پەڕە هاتوون؛ خوێندنەوەی بینراویان لەوانەیە «هاتن»، «یاسین» (ناڕوون)، «خەوتن» و «ڕشتن» بێت. بەهۆی بچوکی چاپ و نەبوونی کراپی وردتر، ئەم فۆڕمانە نابێت وەک خوێندنەوەی دڵنیای سەرچاوە بەکاربهێنرێن.
- پاشان دەقەکە ڕوونکردنەوەیەک لەسەر جیاوازیی بەکارهێنان و فۆڕمەکان لە شێوەزارەکانی کرمانجی دەدات. وردەکاریی ڕستەکان لێرەدا بە تەواوی نەگوازراوەتەوە.

## دەستپێکی جۆری نوێ
- سەردێڕی نوێ لە نیوەی خوارەوە: «دووەم — چاوگی دەنگی بزوێن» (خوێندنەوەی بینراو).
- دەقەکە دەڵێت ئەم جۆرە چاوگە سێ جۆری هەیە.
- جۆری (أ) بە شێوەی بینراو «چاوگی تەڵفی» دەخوێندرێتەوە؛ ئەم زاراوەیە پێویستی بە بەراوردی پەڕەی دواتر هەیە بۆ دڵنیابوون لە خوێندنەوە و واتا.
- نموونەکان لە خوارەوە بە شێوەی بینراو نزیکن لە: «کێلان»، «شێلان»، «پێوان». لەبەر ئەوەی هەندێک پیت بە ڕوونی دیار نین، ئەمانە تەنها خوێندنەوەی سەرەتایین.

## تێبینیی پشکنین
- پەڕەکە گواستنەوەیەک لە بەردەوامی جۆری پێشووەوە بۆ جۆری دووەمی چاوگ دەکات.
- لە پەڕەی ٢٢٦دا دەبێت ئەو سێ جۆرە و ناونیشانی جۆری (أ) بەراورد بکرێن؛ هیچ یەکێک لەم خوێندنەوانە لەم قۆناغەدا نابێت وەک زاراوەی کۆتایی پەسەند بکرێت.
