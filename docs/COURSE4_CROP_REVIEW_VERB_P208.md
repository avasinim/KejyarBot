## دۆزینەوە سەرەکییەکان
- p.208 بەردەوامی ژێربەشی «ناوی بەکار»ە کە لە p.207 دەستی پێکردووە؛ لە پەڕەکەدا سەردێڕێکی نوێ بۆ جۆری سێیەم نابینرێت.
- لە سەرەوەدا دوو ڕیزی نموونە بە شێوەی سێ ستوون هەن. لەوانەدا فۆڕمەکانی «نووسین — نووس — نووسەر» و «کەوتن — کەوت — کەوتوو» دەردەکەون؛ بەهۆی پەیوەندیی ڕیزەکان بە نموونەکانی ناوی بەکار، نابێت بەبێ پشکنینی بەراوردی زیاتر هەموو خانەکان بە یەک شێوازی مانایی لێکبدرێنەوە.
- دەقی دواتر باس لە فۆڕمی ناوی بەکار و پەیوەندییەکەی بە کردارەکان دەکات. نموونەکان بە چوار ستوون ڕیزکراون و چەند فۆڕمی جیاواز پیشان دەدەن. فۆڕمە ڕوونەکان لە ڕیزەکاندا بریتین لە:
  - کوژران / کوژرا / کوژراو
  - خۆران / خۆرا / خۆراو
  - کیران / کیرا / کیراو
  - سووتان / سووتا / سووتاو
  - پشکان / پشا / پشاو
  - خلیسکان / خلیسکا / خلیسکاو
  لە هەندێک خانەدا فۆڕمی ناوەڕاست یان کۆتایی لە چاپەکەدا پیتی وردی هەیە؛ پێویستی بە پشکنینی سەرچاوەی چاپی ڕوونتر هەیە پێش بەکارهێنانی وەک زاراوەی کۆتایی.
- «تێبینی یەکەم» جیاوازیی شێوەی کرمانجیی سەرەوە و خوارەوە لە دارشتنی فۆڕمەکانی ناوی بەکار دەخاتەڕوو. دوو ڕیزی نموونەی هاتن لەگەڵ شێوە جیاوازەکان دانراون؛ خوێندنەوەی هەندێک خانە ڕوونە، بەڵام بۆ نەگۆڕینی فۆڕمی سەرچاوە لێرەدا تەنیا بوونی بەراوردەکە تۆمار کراوە.
- «تێبینی دووەم» باس لە شێوەی کرمانجیی خوارەوە و پاشگری «ـی» دەکات؛ لەژێریدا سێ فۆڕمی نموونە بە ڕیز هەن: «خواری»، «دیتراوی»، «کوژراوی». دەقەکە لە کۆتایی پەڕەدا بەردەوامی ڕوونکردنەوەی ئەم فۆڕمانەیە و ئاماژە بە جیاوازیی بەکارهێنانیان دەکات.

## سنووری دڵنیایی
پەیوەندیی پەڕەکە بە «ناوی بەکار» و دوو تێبینییەکە ڕوونن. فۆڕمەکان تەنیا وەک خوێندنەوەی بینراو تۆمار کراون؛ ئەو شوێنانەی پیتی وردییان هەیە پێویستیان بە بەراوردی چاپی ڕوونتر هەیە. هیچ فۆڕمێکی ناڕوون بە گومان چاک نەکراوەتەوە.
