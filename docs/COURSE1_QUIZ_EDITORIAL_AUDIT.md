# پشکنینی سەرەتاییی کویزی دەورەی ١ — ٢٦ی ئۆکتۆبەری ٢٠٢٦

## کورتەی ئەنجام
فایلی `course_data/orthography_foundations_quiz_draft.json` خوێندرایەوە و ٢٢ پرسیار، یەک بۆ هەر وانە، هەبوونی پشتڕاست کرا. پێکهاتەی JSON و ژمارەی پرسیارەکان بە تاقیکردنەوەی CI پشکنراون؛ ئەمە بەڵام پەسەندکردنی زانستیی پرسیار و وەڵامەکان نییە.

## دۆزراوە گرنگەکان
1. ڕوونکردنەوەی هەموو ٢٢ پرسیارەکە هەمان دەقی گشتییە: «پێش بەستنەوە بە بۆت، وەڵام و ڕوونکردنەوەکە لەگەڵ دەقی پەسەندکراوی وانەکە بپشکنەوە.» ئەمە ڕێنماییی پشکنەرە، نە ڕوونکردنەوەی فێرکاریی تایبەت بە هەر وەڵامێک.
2. هەندێک پرسیار لەبری تاقیکردنەوەی زانیاریی وانەکە، لەسەر شێوازی پشکنینی سەرچاوە دەپرسی؛ بۆ نموونە پرسیارەکانی ٣، ٤، ١٣ و ٢٠. ئەم جۆرە پرسیارانە بۆ ڕاهێنانی ڕەخنەی زانستی بەسوودن، بەڵام نابێت هەموو کویزەکەیان پێکبهێنن.
3. پرسیاری ١٨ بە شێوەیەکی سادە ناونیشانی دروستی وانەکە «کەژیار» لە «کەویار» جیا دەکاتەوە. ئەمە دەتوانێت وەک پرسیاری پشکنینی ناو/ناونیشان بمێنێتەوە، بەڵام بە تەنیا پێوانەی فێربوونی بابەتی وانە نییە.
4. پرسیاری ٢٢ وشەی «شوان» وەک نموونەی «و»ی نەبزوێن هەڵدەبژێرێت؛ پێویستە ئەم وەڵامە لەگەڵ شیکردنەوە و خوێندنەوەی پەسەندکراوی وانەی ٢٢ بپشکنرێتەوە.
5. هیچ پرسیارێک نابێت بە پەسەندکراو ناونرێت تا ناوەڕۆکی وانەکە و سەرچاوەی پشتگیریی هەمان یاسا پشکنراون.

## چاکسازیی پێشنیارکراو پێش runtime
- بۆ هەر وانەیەک: پرسیارێکی زانیاری‌پێوەر، هەڵبژاردەی ڕاست و هەڵبژاردە هەڵە بە هۆکاری دیاریکراو دابنرێت.
- ڕوونکردنەوەکان لە یەکدی جیاوازن و بە زمانی فێرکاری بنووسرێن؛ هەڵبژاردەی ڕاست تەنیا بە پێی دەقی وانە و سەرچاوەی پشتڕاستکراو دیاری بکرێت.
- پرسیارەکانی ڕەخنەی زانستی لە ژێر ناونیشانی ڕاهێنانی جیاوازدا بمێننەوە، نەک جێگرەوەی زانیاریی سەرەکیی هەر وانە.
- لە داتادا خانەی سەرچاوە/لاپەڕە بۆ پرسیارەکان زیاد بکرێت یان لە تۆماری پشکنین بە شێوەیەکی پەیوەست هەڵبگیرێت.
- تاقیکردنەوەی runtime تەنیا دوای پەسەندکردنی ناوەڕۆک زیاد بکرێت؛ تا ئەو کاتە کویزەکە پێش‌نوس بمێنێتەوە.

## سنووری ئەم پشکنینە
ئەم پشکنینە پێکهاتە و کوالێتیی سەرەتاییی پرسیارەکان دەگرێتەوە. هیچ کتێب یان لاپەڕەی بنەڕەتی لەم هەنگاوەدا نەبەراورد کراوە؛ بۆیە هیچ یاسای زمانەوانییەک لێرەدا وەک پشتڕاستکراوە دانانرێت.

## پاراستنی پڕۆژە
- کۆرسی کۆنی ١٠ وانەیی دەستکاری نەکرێت.
- `KEJYAR_ENABLE_DYNAMIC_SPEECH=false` بمێنێتەوە.
- هیچ گۆڕانکارییەک لە `main`، توکنی بۆتی زیندوو یان داتای بەرهەمهێنان ئەنجام نەدرێت.
