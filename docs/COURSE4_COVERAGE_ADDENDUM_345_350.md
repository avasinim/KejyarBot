# زیادکراوەی تۆماری پۆششی سەرچاوە — لاپەڕەکانی ٣٤٥–٣٥٠

- **٣٤٥–٣٤٦:** بەردەوامی بەشی ئامرازی عەتف؛ لیستی فۆڕمە سادە و ناسادەکان و نموونەکانیان، لەگەڵ تێبینی و بەڵگەی نووسراو.
- **٣٤٧–٣٤٨:** ڕوونکردنەوەی گشتی و کۆتایی بەشی پێشوو؛ پۆلەکانی ڕێزمان و هاوتاکانی ئینگلیزی لە دەقەکەدا باس دەکرێن.
- **٣٤٩:** دەستپێکی بەشی ٩ بە سەردێڕی «ئامرازی تعجب»؛ ئەم بەشە لە پلانی کۆرسدا بە ناونیشانی «ئامرازی سەرسووڕمان» ناسراوە، بۆیە یەکسانی ناونیشانەکان لە تۆماری وانەکاندا پێویستی بە پاراستن هەیە، بەڵام دەقی سەرچاوە نابێت بێ بەڵگە بگۆڕدرێت.
- **٣٥٠:** بەردەوامی بابەتی ٩ و نموونە و بەڵگەکانی.
- **سنووری بەڵگە:** پشکنینی بینراوی لاپەڕەکانە؛ دەقی دیپلۆماتیکی و پەسەندکردنی زمانەوانی بە جیاوازی پێویستیان بە پشکنینی ورد هەیە.
- **هەنگاوی داهاتوو:** پشکنینی بینراوی لاپەڕەکانی ٣٥١–٣٥٦.
