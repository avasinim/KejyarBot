# تۆماری پشکنینی سەرچاوە — دەورەی ١: ڕێنووسی زمانی کوردی

ئەم خشتەیە ڕێنمایی پشکنینە، نە بەڵگەی ئەوەی ناوەڕۆکەکان پشتڕاستکراونەتەوە. هیچ وانەیەک تا سەرچاوە، لاپەڕە/چاپ و نموونەکان پشکنین نەکرێن، نابێت بە «تەواو» نیشان بکرێت.

|---:|---|---|
| 1 | پیتەکان و دەنگەکان | جیاوازیی پیت، دەنگ و بزوێن؛ پێناسەکان و ژمارەکان بە سەرچاوە پشتڕاست بکرێنەوە. |
| 2 | بزوێنەکان | پێناسەی بزوێن، شوێنی دروستبوونی دەنگ و جیاوازیی نێوان دەنگ و نیشانەی نووسراو. |
| 3 | یاسای بزوێنەکان | یاساکانی نووسینی بزوێن؛ هەر بانگەشەیەک دەبێت بە نموونە و بەڵگە پشتگیری بکرێت. |
| 4 | لە ئەلفبێی کوردیدا تەنیا یەک (ت، ز، س) مان هەیە | بەراوردی پیتە هاوشێوەکان لە وشەی وەرگیراودا؛ پێویستی بە پشتڕاستکردنەوەی ڕێنووس و ڕەچەڵەک هەیە. |
| 5 | نووسینی بزوێن لە سەرەتای وشە | ڕۆڵی ئـ لە سەرەتای وشە؛ جیاکردنەوەی شێوەی ڕێنووسی کوردی لە نموونەی زمانانی تر. |

| 9 | سێ دەنگی گرینگ | بەراوردی نیشانە و دەنگەکان؛ نموونەی فارسی تەنها بە سەرچاوەی پشتڕاستکراو. |
| 10 | پیتی ە | جیاوازیی ە و هـ و پێناسەی فۆنۆلۆژی؛ نموونەی ڕێنووسی پشتڕاستکراو. |
| 11 | پیتی ێ | کارکردی ێ لە کوردیدا؛ بەراوردی شێوەی نووسین بەبێ تێکەڵکردنی سیستەمەکان. |
| 12 | پیتی ۆ | کارکردی ۆ لە کوردیدا؛ نموونەی کوردی و بەراوردی زمانانی تر بە جیا. |
| 13 | چەڵەمە (ٚ) | ناوی نیشانەکە، شێوەی نووسین و ئەو پیتانەی لە سەرچاوەدا پێکەوە دێن. |

| 21 | بزرۆکە لە نموونەکانی گیان و شوان | شیکردنەوەی «گیان» و «شوان» بە پێی شێوازی ڕێنووسی دیاریکراو. |
| 22 | پیتەکانی و و ی: بزوێن و نەبزوێن | کورتەی کۆتایی و پێداچوونەوەی کارکردی و و ی؛ تاقیکردنەوەی تێگەیشتن. |

## تێبینیی پشکنینی ناوەڕۆکی کویز — ٢٦ی ئۆکتۆبەری ٢٠٢٦

لە پشکنینی دەستیی پێش‌نوسی `course_data/orthography_foundations_quiz_draft.json` ئەمانە دیار بوون:

- ٢٢ گروپی وانە و ٢٢ پرسیار هەیە؛ بۆ هەر وانەیەک تەنیا یەک پرسیار دانراوە. ئەمە بۆ تاقیکردنەوەی قووڵ و هەڵسەنگاندنی فێربوون بەس نییە.
- ڕێکخستنی فایل پشکنرا و بۆ هەموو پرسیارەکان ID، هەڵبژاردە، ژمارەی وەڵامی ڕاست لە سنووری هەڵبژاردەکان و ڕوونکردنەوە هەبوو؛ ئەمە تەنها پشکنینی ڕێکخستنە، نە پشتڕاستکردنەوەی دروستی زانستی.
- پرسیاری وانەی ١٨ تەنیا ناونیشانی «شیکردنەوەی کەژیار» دەپشکنێت؛ پێش بەکارهێنانی فێرکاری، باشترە بە پرسیارێکی شیکاریی ناوەڕۆکی وشە جێگۆڕکێی بکات.
- پرسیاری وانەی ٢٢ «شوان» وەک نموونەی «و»ی نەبزوێن بەکاردهێنێت، بەڵام ئەم نموونەیە لە تۆماری بەڵگەدا هێشتا پشتڕاست نەکراوەتەوە. تا پشتڕاستکردنەوە، نابێت وەک وەڵامی کۆتاییی پشتبەستراو بەکاربهێنرێت.
- هەموو پرسیارەکان پێش بەستنەوە بە runtime پێویستیان بە پشکنینی ناوەڕۆک و سەرچاوە هەیە؛ هێشتا هیچ گۆڕانکارییەک لە runtime یان بۆتی بەرهەمهێنان نەکراوە.

## یاساکانی پشکنین
1. بۆ هەر بانگەشەی زانستی، ناوی سەرچاوە و ژمارەی لاپەڕە تۆمار بکە.
2. نموونەی زمانانی تر لە نموونەی کوردی جیا بکەرەوە؛ شێوەی وشەی بیانی بە یاسای کوردی مەناسێنە.
3. جیاوازیی شێوەزار و جیاوازیی ڕێنووس بە بەڵگە تۆمار بکە؛ بە بێ بەڵگە ڕێنووس یان گرامەر مەگۆڕە.
4. بۆ هەر وانەیەک: ئامانج، پێناسە، نموونە، ڕاهێنان، و کویزێکی کورت دابنێ.
5. تەنها دوای پشکنینی مرۆیی و تاقیکردنەوەی کۆد، دۆخی وانە بگۆڕە بۆ «ئامادەی بەکارهێنان».
6. دەنگی ئافرەت و ڕێڕەوی دەنگی ئێستا بپارێزە؛ گۆڕینی دەنگی دینامیکی تا ڕێگەپێدانی ڕوون ناچالاک بمێنێتەوە.
7. ئەم دەورەیە ٢٢ وانەی هەیە؛ دوای وانەی ٢٢ دەورەکە کۆتایی دێت و وانەی ٢٣ یان دوگمەی جیاواز دروست ناکرێت.

## تێبینیی نوێکردنەوە — ٢٦ی ئۆکتۆبەری ٢٠٢٦
- ناونیشانی وانەی ١٨ دەبێت «شیکردنەوەی کەژیار» بێت؛ ئەو شوێنانەی لەم خشتەیەدا «کەویار» ماونەتەوە، تەنها بۆ تۆماری شێوەی کۆنی پێش‌نوسە و دەبێت لە بەراوردی ناوەڕۆکدا بە «کەژیار» بگۆڕدرێن.
- پێش‌نوسی کویزێکی جیاواز لە `course_data/orthography_foundations_quiz_draft.json` هەیە، ٢٢ پرسیار تێدایە، بەڵام هێشتا پێویستی بە پشکنینی زانستی هەیە و بە runtime نەبەستراوەتەوە.
- ئەم خشتەیە پێویستی بە بەروزرسانیی دۆخەکان هەیە؛ ئەو ڕستەیەی دەڵێت «کویز ... هێشتا دروست نەکراون» بە «کویز هەیە بەڵام پێش‌نوسە» دەگۆڕدرێت.

## دۆخی ئێستا
- پێکهاتەی ٢٢ وانە: دیاریکراو.
- ناوەڕۆکی وانەکان: پێویستیان بە پشکنینی سەرچاوە و دەستکاریی زانستی هەیە.
- کویز: پێش‌نوسی `course_data/orthography_foundations_quiz_draft.json` هەیە؛ ٢٢ گروپی وانە و ٢٢ پرسیار (یەک پرسیار بۆ هەر وانە) تێدایە.
- پشکنینی ڕێکخستنی JSON ئەنجام درا: ٢٢ ژمارەی وانەی جیاواز، هەموو پرسیارەکان ID، هەڵبژاردە، `correct_option_index`ی لە سنووری دروست و ڕوونکردنەوەیان هەیە؛ هیچ کێشەی ڕێکخستنی لەم پشکنینەدا نەدۆزرایەوە.
- ئەم پشکنینە تەنها ڕێکخستن دەگرێتەوە؛ ڕاستیی وەڵام، گونجانی پرسیار لەگەڵ وانەی کۆتایی و بەڵگەی سەرچاوە هێشتا بە شێوەی زانستی پشکنین نەکراون.
- کویز بە runtime نەبەستراوەتەوە؛ دەنگ و وێنەی فێرکاریی تایبەت بە ئەم دەورەیە هێشتا تەواو نەکراون.
- پەیوەستکردنی تەواوی وانەکان بە ڕێڕەوی runtime: هێشتا پێویستی بە کار هەیە.
