# پشکنینی کراپی پەڕەی ٢٢٧ — جۆرەکانی چاوگ

## سەرچاوە و سنووری پشکنین
- کۆرس: ٤ — ڕێزمانی ئاخافتنی کوردی
- سەرچاوە: `Rezmany_axawtny_kurdy.pdf`
- پەڕە: ٢٢٧
- پشکنین: وێنەی تەواوی پەڕە و کراپی گەورەکراو.
- ئەمە پشکنینی بینراوی پەڕەیە؛ ترانسکریپشنی دیپلۆماتیکی تەواو یان پەسەندکردنی زانستیی زاراوەکان نییە.

## بەردەوامی دەقی سەرەوە
سەرەتای پەڕە بەردەوامی ڕوونکردنەوەی پەڕەی ٢٢٦ە. چەند وشە و فۆڕمێک لەو پاراگرافانەدا بەهۆی وردیی چاپەوە بە دڵنیایی ناتوانرێت بخوێندرێنەوە؛ بۆیە لێرەدا وەک دەقی ڕاستەوخۆ نەنووسراون.

## ب- چاوگی واوی
- سەردێڕی بەشی دووەم بە ڕوونی وەک «ب- چاوگی واوی» دەردەکەوێت.
- پاش پێناسەیەکی کورت، نموونەکان لە ژێر دوو ناونیشانی گرووپییەوە ڕیزکراون. خوێندنەوەی ناونیشانەکان بە شێوەی بینراو «وێنە بۆ تیپەڕ» و «وێنە بۆ تی ناپەڕ»ە؛ پێویستی بە پشتڕاستکردنەوەی نووسینی وردیان هەیە.
- نموونەکانی دیار:
  - گروون (خوێندنەوەکە نادڵنیایە)
  - دروون
  - سوون
  - چوون
  - بوون

## ج- چاوگی یایی
- سەردێڕی بەشی سێیەم بە ڕوونی وەک «ج- چاوگی یایی» دەردەکەوێت.
- پێناسەکە بە پێشکەشکردنی چاوگ و پاشگری چاوگ دەست پێدەکات؛ دەقی وردی پێناسەکە بە تەواوی لێرەدا نەگوازراوەتەوە.
- هەمان شێوازی دابەشکردنی نموونەکان بۆ دوو گرووپی تیپەڕ و ناتیپەڕ بەکارهاتووە.
- نموونەکانی بینراو:
  - نووسین
  - کرین
  - برین
  - درزین
  - فرین
  - وڕین (خوێندنەوە نادڵنیایە)

## تێبینییەکانی وردبینی
1. ناونیشانەکانی «چاوگی واوی» و «چاوگی یایی» بە ڕوونی دیارن.
2. هەندێک نموونەی لیستەکان لەبەر وردیی چاپ و شێوازی پیتەکان پێویستیان بە بەراوردکردن لەگەڵ پەڕەی پێشوو و دواتر هەیە.
3. لە بەڵگەنامەی کۆتاییدا نابێت فۆڕمە نادڵنیایەکان بە بێ نیشانەی نادڵنیایی بگوازرێنەوە.
4. دابەشکردنی نموونەکان بۆ تیپەڕ/ناتیپەڕ تەنها وەک ڕێکخستنی سەرچاوە تۆمار کراوە؛ پێویستی بە پشکنینی زمانەوانیی سەربەخۆ هەیە.
