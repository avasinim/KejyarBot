# وانەی ٢١ — ژمارەی پەلەیی و کەرتی؛ دووپاتکردنەوەی ژمارە

**کۆرس:** ڕێزمانی زمانی کوردی  
**یەکە:** ژمارە و ئاوەڵکردار  
**دۆخی دەق:** پێشنیاری ئەکادێمیک بۆ پشکنین؛ ناچالاک  
**سەرچاوەی بنەڕەتی:** د. ئەوڕەحمانی حاجی مارف، *ڕێزمانی کوردی*، بەشی ژمارە و ئاوەڵکردار.

---

## ئامانجی فێربون

لە کۆتایی وانەکەدا فێرخواز بتوانێت:
1. ژمارەی پەلەیی لە ژمارەی بنجی جیا بکاتەوە.
2. واتای ڕیز و پلە و ئەرکی فۆرمە پەلەییەکان ڕوون بکاتەوە.
3. ژمارەی کەرتی وەک دەربڕینی بەشێک لە تەواوەتی بناسێت.
4. دووپاتکردنەوەی ژمارە لە ژمارەی بنجی و ئاوەڵکرداری دابەشکار جیا بکاتەوە.
5. نیشانە و پێکهاتەی فۆرمەکان بە پێی بەڵگەی سەرچاوە شیکاتەوە.
6. جیاوازییە دیالێکتییەکان و سنووری دڵنیایی تۆمار بکات.

## ١. جیاوازیی بنەڕەتیی جۆرەکان

ئەم سێ جۆرە لە ڕووی واتا جیاوازن:

- **پەلەیی:** شوێن، ڕیز یان پلەی شتێک لە زنجیرەیەکدا دیاری دەکات.
- **کەرتی:** بەشێک لە تەواوەتییەک نیشان دەدات.
- **دووپاتکردنەوەی ژمارە:** لە هەندێک کۆنتێکستدا شێوازی ئەنجامدانی کردار وەسف دەکات و ئاوەڵکردارە، نەک ژمارە.

پرسیاری یارمەتیدەر بۆ ناسینەوە:
- پەلەیی: «چەندەم؟»
- کەرتی: «چەند بەش لە تەواوەتی؟»
- دووپاتکردنەوە: «چۆن/بە چ شێوەیەک؟»

ئەم پرسیارانە ڕێنمایی شیکردنەوەن، نەک جێگرەوەی پشکنینی فۆرم و کۆنتێکست.

## ٢. ژمارەی پەلەیی

ژمارەی پەلەیی ڕیز و پلەی شتێک لە ناو زنجیرە یان کۆمەڵەیەکدا دیاری دەکات. لە جیاوازی لە ژمارەی بنجی، کە بڕی دانەکان دەژمێرێت، ژمارەی پەلەیی شوێنی ئەو شتە لە ڕیزەکەدا پیشان دەدات.

**نموونە:**
- یەکەم
- دووەم
- دەیەم

لە «یەکەم قوتابی»دا، ژمارەکە پلەی قوتابییەک لە ڕیزێکدا دیاری دەکات؛ لە «سێ قوتابی»دا، ژمارەکە بڕی قوتابییەکان دیاری دەکات.

### ٢.١ نیشانە و دروستبوونی فۆرم

لە نموونەکانی وەک «یەکەم»، «دووەم» و «دەیەم»، نیشانەی «ـەم» بەشێکە لە فۆرمی پەلەیی. لە شیکردنەوەی مۆرفۆلۆژیدا دەبێت:
- بنەمای ژمارە دیاری بکرێت؛
- نیشانەی پەلەیی لە بنەما جیا بکرێتەوە؛
- گۆڕانی دەنگی یان نووسینی فۆرم تۆمار بکرێت؛
- نموونەکە بە پێی دیالێکت و شێوازی نووسینی سەرچاوە بپشکنرێت.

نابێت لە نموونەیەکی کەمەوە یاسایەکی بێ‌هەڵە بۆ هەموو ژمارەکان دروست بکرێت؛ فۆرمە تایبەتەکان دەتوانن ڕێسای جیاواز یان گۆڕانی بنەڕەتییان هەبێت.

## ٣. ژمارەی کەرتی

ژمارەی کەرتی بەشێک لە تەواوەتییەک نیشان دەدات. لە ڕووی واتاییەوە، پەیوەندیی نێوان بەش و تەواوەتی گرنگە.

**نموونەی فێرکاری:**
- نیوەی نان
- چارەکی شتێک
- یەک لە سێ بەش

لە «نیوەی نان»دا، دەربڕینەکە بەشێک لە تەواوەتیی نان نیشان دەدات. لە «سێ نان»دا، ژمارە بڕی تەواوی شتەکان دەژمێرێت. بۆیە ئەم دوو پێکهاتەیە لە ڕووی واتا یەکسان نین.

### ٣.١ شیکردنەوەی دەربڕینی کەرتی

لە شیکردنەوەدا ئەم خاڵانە دیاری بکە:
1. تەواوەتییەکە چییە؟
2. بەشەکە چەندە یان چۆن دیاری کراوە؟
3. دەربڕینەکە فۆرمێکی وشەییە یان پێکهاتەیەکی فرەوشەیی؟
4. پەیوەندیی بەش و تەواوەتی چۆن لە ڕستەدا دەردەکەوێت؟
5. ئایا فۆرمەکە لە سەرچاوەدا بە هەمان شێوە هاتووە؟

ژمارەی کەرتی لە ڕێزماندا تەنها ژمارەیەکی حیسابی نییە؛ دەربڕینێکی زمانە کە پەیوەندیی بەش و تەواوەتی ڕێکدەخات.

## ٤. دووپاتکردنەوەی ژمارە و ئاوەڵکرداری دابەشکار

ژمارەی دایەش دابەشکردنی بڕێک بەسەر ئەندامانی کۆمەڵەیەکدا دەردەخات. گرنگە لە ژمارەی بنجی جیا بکرێتەوە: ژمارەی بنجی بڕی گشتی دیاری دەکات، بەڵام دایەش شێوازی بەشکردن یان بڕی هەر بەشێک دەردەخات.

**نموونەی ڕوونکردنەوە:**
- هەر قوتابییەک دوو پەڕەی وەرگرت.
- بۆ هەر منداڵێک یەک دانە دیاری کرا.

لەم نموونانەدا واتای دابەشکردن بە ڕستە و دەربڕینی «هەر» دەردەکەوێت. بەڵام نابێت هەر ڕستەیەکی دابەشکاری بە خۆکارانە بە فۆرمی ژمارەی دایەش دابنرێت؛ دەبێت فۆرمی وشە و پۆلێنکردنی نووسەر بپشکنرێت.

## ٥. بەراوردی نموونەکان

| دەربڕین | واتای سەرەکی | جۆری ژمارە |
|---|---|---|
| سێ کتێب | بڕی سێ دانە | بنجی |
| یەکەم کتێب | پلەی یەکەم لە ڕیز | پەلەیی |
| نیوەی کتێب | بەشێک لە تەواوەتی | کەرتی |
| هەر قوتابییەک دوو پەڕەی وەرگرت | دابەشکردنی بڕ بۆ هەر کەس | واتای دایەش لە ڕستەدا |

خشتەکە نموونەی ڕوونکردنەوەییە؛ فۆرمە تایبەتەکانی ژمارەی دایەش دەبێت لە کتێبەکەدا بە وردی پشتڕاست بکرێنەوە.

## ٦. پەیوەندیی فۆرم، واتا و ئەرکی ڕستەسازی

پۆلێنکردنی ژمارە تەنها لەسەر بنەمای واتا بەس نییە. هەمان دەربڕین دەکرێت لە ڕستەدا ئەرکی جیاواز بگرێتە ئەستۆ. بۆ شیکردنەوەی تەواو:
- پۆلی وشەی ژمارەکە دیاری بکە؛
- واتایەکەی لە کۆنتێکستدا بنووسە؛
- پەیوەندیی بە ناو یان پێکهاتەی دەوروبەری ڕوون بکەرەوە؛
- ئەرکی ڕستەسازیی پێکهاتەکە دیاری بکە؛
- فۆرمی مۆرفۆلۆژی بە بەڵگەی سەرچاوە پشتڕاست بکەرەوە.

## ٧. هەڵە و تێکەڵکردنە باوەکان

- تێکەڵکردنی «سێ» و «سێیەم»: یەکەم بڕ دەژمێرێت، دووەم ڕیز دیاری دەکات.
- تێکەڵکردنی «نیوە» و ژمارەی بنجی: یەکێک بەشە، ئەوی تر بڕی تەواو دەژمێرێت.
- دانانی هەر ڕستەیەکی دابەشکاری بە ژمارەی دایەش، بەبێ پشکنینی فۆرم.
- گشتاندنی نیشانەی «ـەم» بۆ هەموو فۆرمەکان بەبێ بەڵگە.
- تێکەڵکردنی پۆلێنکردنی ڕێزمانی و حیساب.
- لەبەرچاونەگرتنی پەیوەندیی بەش و تەواوەتی لە ژمارەی کەرتیدا.
- گشتاندنی فۆرمێکی دیالێکتێک بۆ هەموو شێوەزارەکان.

## ٨. مۆدێلی شیکردنەوە

| خانە | پرسیاری شیکاری |
|---|---|
| فۆرم | وشە یان دەربڕینەکە چییە؟ |
| جۆر | پەلەیی، کەرتی، دایەش یان جۆرێکی تر؟ |
| واتا | ڕیز، بەش یان دابەشکردن؟ |
| پێکهاتە | سادە، دروستکراو یان فرەوشەیی؟ |
| نیشانە | کام نیشانە بەڵگەی هەیە؟ |
| پەیوەندی | بە کام ناو یان کۆمەڵەیەکەوە پەیوەستە؟ |
| ئەرکی ڕستەسازی | لە ڕستەدا چ ئەرکێک دەبینێت؟ |
| سەرچاوە | کام لاپەڕە و کام دیالێکت پشتگیری دەکەن؟ |

## ٩. پرسیارەکانی هەڵسەنگاندن

1. جیاوازیی ژمارەی بنجی و پەلەیی چییە؟
2. نیشانەی «ـەم» لە نموونەکانی «یەکەم» و «دووەم»دا چ ئەرکێک هەیە؟
3. ژمارەی کەرتی چ پەیوەندییەک لە نێوان بەش و تەواوەتی دروست دەکات؟
4. بۆچی «نیوەی نان» لە «دوو نان» جیاوازە؟
5. ژمارەی دایەش چۆن لە ژمارەی بنجی جیا دەکرێتەوە؟
6. بۆچی نابێت هەر ڕستەیەکی دابەشکاری بە ژمارەی دایەش دابنرێت؟

## ١٠. تاقیکردنەوەی کردارەکی

ئەم دەربڕینانە شیکەرەوە و جۆری ژمارە دیاری بکە:

- «دووەمین بەشی کتێب»
- «چارەکی نانەکە»
- «هەر قوتابییەک دوو نموونەی نووسی»
- «پێنج کتێب لەسەر مێزەکە بوون»

بۆ هەر نموونە:
1. فۆرمی ژمارە دیاری بکە؛
2. واتای بڕ، ڕیز، بەش یان دابەشکردن ڕوون بکەرەوە؛
3. پەیوەندیی بە ناوەوە بنووسە؛
4. پێکهاتەی مۆرفۆلۆژی ئەگەر بەڵگەی هەیە شیکەوە؛
5. ئەو بەشانە دیاری بکە کە پێویستیان بە پشکنینی دیالێکتی هەیە.

## تێبینیی سەرچاوە و سنووری پشتڕاستکردنەوە

ئەم وانەیە بە بنەمای پۆلێنکردنی ژمارەی پەلەیی، کەرتی و دایەش لە کتێبی د. ئەوڕەحمانی حاجی مارف ڕێکخراوە. نموونەکان بۆ ڕوونکردنەوەی جیاوازیی واتایی نووسراون و وتەی ڕاستەوخۆی نووسەر نین. نیشانەی مۆرفۆلۆژی، فۆرمە تایبەتەکانی ژمارەی دایەش و جیاوازیی دیالێکتی دەبێت لە وێنەی پەڕە چاپکراوەکاندا بپشکنرێن؛ تا ئەو کاتە نابێت فۆرمێکی نموونەیی وەک یاسای گشتی پێشکەش بکرێت.

**سەرچاوە:** د. ئەوڕەحمانی حاجی مارف، *ڕێزمانی کوردی*، بەشی ژمارە و ئاوەڵکردار.
