## چاکسازیی تەکنیکی لە برانچی کاری
- `bot.py`: ژمارەی چاوەڕوانکراوی وانەکانی کۆرسی ٤ لە ٨ بۆ ١ گۆڕدرا؛ پشکنینی سنووری پەڕەی ٣٤٢ی کتێبی کۆن لابرا.

- ئەم گۆڕانکارییانە لە GitHub نووسراون، بەڵام تا کاتی نووسینی ئەم فایلە تاقیکردنەوەکانی Python بە شێوەی CI یان لە ژینگەی کاردا ڕانەکراون. هیچ بانگەشەیەک لەسەر سەرکەوتنی test مەکە تا بە ڕاستی ڕابکرێن.
- `validate_activated_course_runtime()` ئێستا ژمارەی ١ چاوەڕێ دەکات و هێشتا ناوەڕۆکی وانە و دۆخی owner-review پشکنین دەکات.
